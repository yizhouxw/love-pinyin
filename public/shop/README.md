# 小卖部商品图集

`products-photo-atlas.png` 为2026-10-27使用内置 image_gen 生成的无品牌写实商品图集，并非真实商品拍摄。原图1536×1024，12列×8行、每格128×128，共96件；界面按格显示，未使用外部商品图片或参考页面内嵌素材。商品名称及价格由界面绘制。素材作为项目资产按MIT许可提供。

生成风格为自然棚拍、真实食材与包装材质、无文字和商标；八行分别为零食、饮料、水果、面包、蔬菜、玩具、趣玩和文具。实际提示保存在[photo-generation-prompt.txt](photo-generation-prompt.txt)。

旧卡通版图集已移出当前素材包，历史版本保留在Git；旧提示保存在[生成提示](generation-prompt.txt)。

`store-interior.jpg` 为 2026-11-10 使用内置 image_gen 生成的便利店背景，按项目 MIT 许可提供。生成提示要求采用暖白灯光和橙色装饰、两侧浅景深货架、中间留白，无可辨识文字、商标、人物及界面控件。前景货架的背板、立柱与橙色搁板由 CSS 绘制，以配合不同屏宽下的商品排列。

`alipay-receipt.wav` 与 `wechat-receipt.wav` 为本地 Qwen3-TTS CustomVoice 生成的模拟到账提示，沿用 `content/voice-build.json` 固定参数与项目既有模型许可；不是支付平台官方录音，不连接真实支付。

2026-11-16：当前使用 `products-cutout-atlas.png`，由内置 image_gen 以旧图集为参考重新生成，保留十二列八行商品顺序，1536×1024 RGBA 透明背景，改善材质细节并移除底色，使商品能直接陈列在立体搁板上。素材按项目 MIT 许可提供。`checkout-guide.wav` / `confirm-guide.wav` 同样使用上述固定本地开源 TTS 配置生成结账与确认引导。全部声音明确为模拟购物，无官方到账录音或真实交易。

透明图集生成约束：以旧写实图集为参考，保持全部96件身份、12×8等大方格及行列次序；高保真棚拍材质，独立透明抠图，无底板、品牌、文字、水印，商品完整保留在各自方格内。实际检查所有格子与目录对应，图片带 alpha 通道。
