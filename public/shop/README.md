# 小卖部商品图集

`products-photo-atlas.png` 为2026-10-27使用内置 image_gen 生成的无品牌写实商品图集，并非真实商品拍摄。原图1536×1024，12列×8行、每格128×128，共96件；界面按格显示，未使用外部商品图片或参考页面内嵌素材。商品名称及价格由界面绘制。素材作为项目资产按MIT许可提供。
