# 爱拼音 · Love Pinyin

![爱拼音：四线格上的 bā](public/logo.svg)

爱拼音帮助一年级孩子跟着学校进度学习汉语拼音。孩子可以听示范、做有声练习、观察笔顺，也可以在游戏里巩固。题目有声音引导，孩子不必先认识题目中的汉字。课程按中国大陆统编人教版课序组织，无广告、排行榜或云账号。

## 安装

桌面用户可从 [GitHub Releases](https://github.com/yizhouxw/love-pinyin/releases) 下载安装包。桌面和 iOS 应用将课程和声音保存在本机，日常学习可离线进行。

- **Mac（Apple 芯片）**：下载 `LovePinyin-arm64.dmg`，打开后把“爱拼音”拖入“应用程序”，再打开它。暂不支持 Intel Mac。
- **Windows（x64）**：下载 `LovePinyin-windows-x64-setup.exe`，运行安装程序后从开始菜单打开。需要 Windows 10 或 11 和已安装的 Microsoft Edge。Windows 安装包请以下载页面实际提供为准。

- **iPhone / iPad**：从源码准备离线资源，使用 Xcode 签名并安装到自己的设备。详见 [iOS 工程说明](deploy/ios/README.md)。GitHub Release 提供桌面安装包和 iOS 源码。
- **浏览器**：在家用电脑运行服务，再从本机或家庭局域网打开网页。详见[局域网部署](docs/engineering/local-deployment.md)。

桌面安装包未签名，Mac 安装包未公证。系统可能提示无法验证开发者或未知发布者，请确认文件来自上面的官方下载页面，再按系统安全提示操作。

## 开始学习

1. 打开爱拼音；浏览器访问可以先选择访客体验，访客进度仅保存在当前页面，退出后清除。
2. 桌面应用会自动建立本机家庭档案。iOS 应用直接建立设备档案。浏览器要保存家庭进度时，先生成配对码并完成配对。进入“家长管理”选择孩子正在学习的课程。
3. 首页可进入课堂学习、天天练和游戏乐园。孩子可以点击声音按钮重听，听不清或播放失败时可以重试或跳过。
4. 家长可在家长管理中查看学习记录和调整游戏时长。桌面与 Web 家庭档案支持备份与恢复；iOS 家长可通过「文件」导出与恢复同课程版本的 iOS 学习档案。

## 可以做什么

- **听、写、练**：跟随 14 课学习声母、韵母和拼读，听标准音、观察四线格笔顺，再通过有声题目练习。
- **词语天天练**：按一年级上册38课练习词语拼读、纸笔听写与课文背诵；按单元点选课程，选词查看情景插图；可逐词听读或连读，调节词间停顿、开关语音引导，隐藏正文并查看本课生字词。练习标记仅保存在当前设备。
- **天天练拼音**：选择每日练习，逐条听读或连播；可以调整跟读间隔，也可以选择录音回放。
- **游戏乐园**：在跑酷、划船、节奏和投递游戏中练习拼音。家长可设置每天和每次的游戏时长。
- **拼音小卖部**：挑商品、听示范、读拼音，再确认入车。支持本机自动识别或人工确认，不记录学习成绩。

家庭安装默认使用新版素材。两版词语天天练共用教材课序和词表，新版提供自编拓展朗读。家长可在「家长管理 → 高级设置 → 学习素材」切换旧版家庭素材。浏览器设备在重新打开后读取家庭设置，各独立 App 保存自己的选择。iOS 公开包只随附新版。

## Android 独立版

Android App 随包提供课程、声音、词语与每日练习、四款游戏和本机学习记录，可离线使用，并带有自适应应用图标。安装构建与备份说明见 [Android 说明](deploy/android/README.md)，实际测试范围见 [Android 验收记录](docs/engineering/android-product-acceptance.md)。Android 暂不提供本地识别；使用听读与人工确认。覆盖安装保留数据，卸载前请导出 Android 备份。

## 可选的跟读识别

Apple 芯片的 Mac 和iPhone 和 iPad 原生 App 可用 Qwen3-ASR 0.6B 为天天练和小卖部进行本地识别。家长可在当前设备的「家长管理 → 本地语音识别模型」主动下载，各约 1.01 GB。安装包不含权重。下载完成后，当前设备可独立离线识别。未下载或设备不支持时，可听读并人工确认。

课堂答题无需麦克风。课程跟读可直接听示范，也可以在浏览器和桌面应用展开「录音回放」听自己的声音。课程录音留在当前页面内存。

识别只用于音节对照，**不评价四声或专业发音准确度**；听不清或识别不可用时不会判孩子错误。录音只在设备和本机服务的内存中处理，不保存到家庭档案。

## 家庭数据与其他设备

浏览器的家庭进度保存在提供服务的电脑上。桌面应用和 iOS 应用将进度保存在各自设备。桌面或浏览器中的家长可定期下载家庭备份。

- Mac 应用数据位于 `~/Library/Application Support/LovePinyin/`。
- Windows 应用数据位于 `%LOCALAPPDATA%\LovePinyin`。

更新或卸载应用不会删除这些目录。桌面应用默认只供本机使用。如需 iPad 或手机通过家庭网络连接，请参阅[家庭局域网部署说明](docs/engineering/local-deployment.md)；完整移动设备、家庭网络和家庭试用验收仍在进行。

桌面应用和独立部署的 Web 版本使用各自的数据和会话，可通过家庭备份手动迁移。iOS 的到期复习和与 Web/桌面的备份互导分别由 [#36](https://github.com/yizhouxw/love-pinyin/issues/36) 与 [#37](https://github.com/yizhouxw/love-pinyin/issues/37) 跟踪。
