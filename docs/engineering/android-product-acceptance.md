## 本轮发现并修复

- 场景不展示课堂插图时，提交不再等待不存在的图片加载，解决星际投递命中后卡住。
- MediaPlayer 定位在完成回调后返回位置；前端阻止同一手势重复发送控制，并拒绝旧轮询覆盖较新的控制结果。
- Android 音频焦点中断同时暂停游戏；暂停存储失败会在下次 API 重试并显式报告失败。
- 调试验证档案的 WebView 数据目录在进程内只初始化一次，主 Activity 单实例，避免重建崩溃。
- 小练习标记改为 SQLite 事务保存并纳入备份；备份系统交互期间避免重复打开选择器。

## 证据与范围

可复跑脚本见 `deploy/android/README.md`、`test-contracts.sh`、`verify-device.mjs`。本机原始结果和实际截图位于 `build/android/verification/`（不提交测试档案）；终端全量日志在 `/tmp/android-*.log`。真机音频解码与实际播放通过，用户另明确确认「能听到，声音清晰」。

不把桌面浏览器手机视口测试称为真机测试；不把 SQLite 重开等同于强杀进程。本轮只覆盖一台实际 Android 16 手机，未声称所有厂商/最低 API 或真实来电场景通过。Android 不提供语音识别或发音评分，不支持 Web/iOS 备份互导；家庭长期使用与教学效果仍需真实观察。后续手机课堂紧凑布局按用户新需求在独立会话完成，不纳入本次 Android 移植范围。
