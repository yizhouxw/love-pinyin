# 拼音小卖部接入与维护

当前以 SPEC-019 SHOP-07/08 与 ADR-0035 最新修订为准。入口：学习首页 → 游戏乐园 → 拼音小卖部。

## 商品、练习与金额

`content/pinyin-shop.json` 维护八个货架，每架十二件，共九十六件商品。所有商品从首课可浏览；每件有商品名、整数分价格和唯一图集格号，绝不绑定拼音。价格只为虚拟购物趣味，没有真实购买或支付，也不参与匹配、解锁或掌握度。

独立 targetIds 目录引用 `content/illustrations.json` 的77个去重拼音与真实示范；运行时仅取当前已学课，优先当前课再轮换此前内容。选不同商品依次取独立练习目标；重试保持当前目标。首课虽只有三个练习音，仍可逛全部九十六件商品。

每篮最多六件，每件只入车一次，随时可结算；合计用整数分求和，最后统一格式化为元，空篮为 ¥0.00。结算展示商品图、单价、件数与总金额。篮子与音频仅在本轮内存，退出清除，不写客观题成绩。

商品图片位于 `public/shop/products-photo-atlas.png`，1536×1024，十二列八行，每格128像素。由内置 image_gen 工具生成，浏览器按格显示，不使用 emoji 代替商品图、不访问远程素材；生成说明与提示见同目录 README。发布门禁验证八架/九十六件、每架十二件、唯一商品/图片、价格、独立目标引用、PNG实物及格尺寸。

## 自动录音与五秒窗口

真实服务模式下，点商品立即显示独立拼音，并从点击手势打开麦克风，无开始/完成录音按钮。窄屏自动滚到拼音区。首轮浏览器权限等待不记为孩子超时；麦克风就绪起，采音和识别共享严格五秒截止时间，没有额外推理等待。

真实服务模式的 `BrowserShopRecorder` 使用原生 Web Audio 单声道 PCM 回调，只在内存保留最多五秒数据；输出静音，不监听回放麦克风。首次650毫秒后取累积快照，`ShopReadingSession` 串行调用 MATCH-10 `match`，每次返回后450毫秒再取更长的音频；转换为16kHz单声道PCM16 WAV。不并发排队，不把 MediaRecorder 不完整媒体块送给解码器。原天天练 MediaRecorder 与录音转换行为不变。

匹配结果必须版本/请求/目标一致；正式 matched/retry 必须有 acoustic 证据。matched立即停麦并入车；retry明确提示重试；uncertain继续听，五秒仍无成功则提示超时，不记错误。unavailable/异常立即说明不可用。截止时间会取消卡住的推理；服务即使忽略取消或延迟返回，也不能入车。没有发音分数，toneAssessed=false不声称声调正确。

切商品、换货架、重听、取消、暂停、额度、后台与退出都清除 PCM、流、音频图、定时器和请求。界面有“再读一次”“听示范”帮助；示范先停止采音，播放后由孩子主动重试，避免设备把自己的声音录成答案。

## 全局引导

店铺顶部只放一个全局语音引导开关，接收App已解析的家庭默认/设备偏好；返回首页与天天练沿用同一选择。没有逐条“听操作提示”。开启时自动读入店、结果、故障和结算说明；关闭即时停音，状态文字仍显示。真实服务模式选择商品先停止声音并直接录音，采音期间不播放引导或示范；模拟模式不请求麦克风，结果提示明确为模拟。

## 模拟体验与真实服务

根据用户2026-10-27要求，`content/pinyin-shop.json` 中 `recognitionMode: "mock"` 显式将**小卖部**设为模拟模式，正式构建也按此配置可玩。无需URL参数，也无需麦克风；点击商品后通过MATCH-10模拟端口返回标记为mock的成功，自动加入临时购物车。页面、成功反馈和结算清单都注明不是实际识别；语音提示同样说“模拟”，不能把它算作儿童识别成绩。模拟不发音频、不请求麦克风，也不写学习掌握度。

组装入口为 `src/platform/audio/shop-pronunciation.ts`：只按显式模式选择mock或unavailable，真实服务不可用、拒判或超时不会触发自动降级。`MockShopCapture` 提供空内存Blob，MATCH-10 mock有意忽略输入；真实模式使用 `BrowserShopRecorder`，不会复用模拟输入。React识别属性允许测试注入受控真实接口。未来接入验收合格的真实服务时，修改配置/组装，提供`PronunciationService`、声明`mock:false`，并恢复本页五秒采音流程；不得把此前模拟购物当质量证据。

家庭游戏时长复用原heartbeat，没有新数据库迁移或依赖。真实录音需localhost或受信任HTTPS，拒绝权限、设备不可用、网络和模型故障不判孩子错。模拟只能证明购物交互可用，真实儿童识别、移动真机、家庭LAN与儿童理解度仍独立验收。
