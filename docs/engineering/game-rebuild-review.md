## 问题与实装

截图中的空白来自系统或家庭“减少动态效果”分支：它卸载了SceneWorld，只显示答案按钮。现改为始终绘制场景，静态模式停止移动并在场景目标上使用原生按钮；仍等待真实声音完成，遵守暂停、网络和提交锁。模式切换保留题目与世界状态。

| 游戏     | 场景内操作                    | 保留的游戏规则                                               |
| -------- | ----------------------------- | ------------------------------------------------------------ |
| 森林跑酷 | 点击/滑动跑道换道，点狐狸跳跃 | 树根、灌木、收集路线、拱门；辅助模式在目标前等待             |
| 河湾划船 | 点击/滑动水面定向，点小船划桨 | 礁石、前进惯性、水流；限制横向惯性累积，辅助模式明确划桨靠岸 |
| 节奏鼓岛 | 点击鼓面击鼓                  | 热身节拍、移动音符、击打窗口、放过音符、辅助等待             |
| 星际投递 | 点击星球瞄准，点飞船发射      | 陨石、投递弹道、目标移动及命中判定                           |

方向键、键盘主动作和大按钮继续可用。定向纯函数只修改位置和横向速度，不推进路线、不越过声音锁、不直接作答。手滑、撞障碍和没打中仍只影响游戏，不生成拼音错误。

重新绘制狐狸、飞船细节及场景装饰；近处的拼音标牌上移，避免被角色遮挡。收集、鼓点及抵达反馈留在场景内，移除整屏闪色。场景与触摸层共用固定坐标和比例。桌面工具栏并排、手机横屏控制分列两侧，说明放在场景下方，故事与设置按需打开。
