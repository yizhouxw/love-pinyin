# 设置交互复核（2026-11-13）

对应 SPEC-016 UX-11。参考 Apple HIG [Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers)。

| 入口                   | 调整与保留                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| 家长管理               | 保留学习与体验、设备与数据、信息与记录顺序；设置分组使用独立圆角行组；高级和危险操作继续默认折叠 |
| 天天练、词语练习、书写 | 播放设置改为紧凑入口及覆盖面板，避免展开挤动主要内容；窄屏固定底部，完成和 Escape 关闭后回到入口 |

| 设备、模型、备份与重置 | 保留原权限、下载确认、备份预览和删除确认；这些持久操作继续在家长管理内完成                       |

无新增依赖或数据迁移。新增浏览器回归检查 1280、390、320px 的面板边界、内容布局、Escape 焦点和即时语音偏好保留。真机触摸、VoiceOver、200% 字号以及家庭试用仍需独立验收，不能将本次浏览器测试视为完成这些项目。

## 真机证据

iPhone 13 与 iPad Air（第 4 代）分别安装本次离线构建，以独立测试档案运行家长设置顺序/许可与快捷设置横竖屏测试，两台各 2 项通过。报告位于本机 `build/ios/settings-phone-fixed.xcresult` 和 `build/ios/settings-ipad.xcresult`；截图已导出并目视检查。iPhone 首轮发现横屏关闭按钮不可触达，已通过矮屏底部布局与宽屏自动向上展开修复，复验通过。此前段落的真机待验范围更新为：本次两项设置流程已验证；VoiceOver、完整家庭试用与扬声器听感仍不属于此次已完成项目。
