# 设置交互复核（2026-11-13）

对应 SPEC-016 UX-11。参考 Apple HIG [Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers)。

| 入口                   | 调整与保留                                                                                       |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| 家长管理               | 保留学习与体验、设备与数据、信息与记录顺序；设置分组使用独立圆角行组；高级和危险操作继续默认折叠 |
| 天天练、词语练习、书写 | 播放设置改为紧凑入口及覆盖面板，避免展开挤动主要内容；窄屏固定底部，完成和 Escape 关闭后回到入口 |
| 播放间隔               | 快捷面板内展开编辑，不再叠加第二层模态窗口；保留范围校验、精细调整和显式应用                     |
| 游戏乐园卡片           | 难度和速度保留当前值摘要，选项浮层就近打开；一次只打开一个                                       |
| 游戏过程中             | 保留暂停、取消和应用的事务语义与失败提示；防重复提交；窄屏采用底部面板                           |
| 设备、模型、备份与重置 | 保留原权限、下载确认、备份预览和删除确认；这些持久操作继续在家长管理内完成                       |

无新增依赖或数据迁移。新增浏览器回归检查 1280、390、320px 的面板边界、内容布局、Escape 焦点和即时语音偏好保留。真机触摸、VoiceOver、200% 字号以及家庭试用仍需独立验收，不能将本次浏览器测试视为完成这些项目。

## 真机证据

iPhone 13 与 iPad Air（第 4 代）分别安装本次离线构建，以独立测试档案运行家长设置顺序/许可与快捷设置横竖屏测试，两台各 2 项通过。报告位于本机 `build/ios/settings-phone-fixed.xcresult` 和 `build/ios/settings-ipad.xcresult`；截图已导出并目视检查。iPhone 首轮发现横屏关闭按钮不可触达，已通过矮屏底部布局与宽屏自动向上展开修复，复验通过。此前段落的真机待验范围更新为：本次两项设置流程已验证；VoiceOver、完整家庭试用与扬声器听感仍不属于此次已完成项目。

工程单元测试 200 项、服务器测试 563 项、本地端到端 36 项通过；格式、lint、类型检查、构建及发布资产检查通过。完整 live 回归 74 项通过，2 项因旧脚本依赖设置持续展开而失败；同步显式关闭/重开路径后，最新词语与录音专项 32 项全部通过，游戏乐园专项 4 项全部通过。保留原语音、权限、保存和成绩断言。没有将中途失败的 verify:all 记为一次全绿。

## UX-12 全局布局复核

本轮修正 UX-11 仅改变展开方式、未清理页尾信息层级的问题：

| 页面                 | 最终位置与取舍                                                                                        |
| -------------------- | ----------------------------------------------------------------------------------------------------- |
| 首页                 | 学习帮助紧邻标题；课程目录、实际学习进度继续留在正文                                                  |
| 词语拼读、听写、背诵 | 播放设置与播放/停止同组；顶部帮助合并玩法、语音提示、记录规则与来源；删除原页尾三个辅助入口           |
| 天天练选材           | 帮助位于顶部导航，设置在标题区域；声音缓存与记录说明收入帮助                                          |
| 天天练跟读           | 设置并入示范/连播操作组；录音与家长判断保留独立学习操作                                               |
| 书写                 | 设置紧邻笔顺播放，手机用有无障碍名称的 48px 齿轮入口，避免挤窄前后项按钮                              |
| 课堂听读             | 录音来源使用就近帮助；真正的知识卡和教学内容保留                                                      |
| 游戏乐园             | 总体玩法与时长说明归入顶部帮助；各游戏难度/速度仍贴近对应卡片；真实学习记录保留                       |
| 游戏内、小卖部       | 复核现有就近工具栏、暂停和取消/应用语义，保留，不额外增加页尾设置                                     |
| 家长与访客           | 保留学习体验、设备数据、信息记录分组与权限边界；统一模型下载/取消按钮样式；不将备份或删除藏入儿童帮助 |

新增跨页面真实服务回归，对首页、词语、天天练、游戏、课堂、书写、家长分别检查 1280/820/390px 的溢出、入口归属及截图。实际目视核对页面，并通过 200% 字号回归发现、修复手机标题帮助入口横向溢出。

UX-12 验证结果：200 项单元测试、563 项服务器测试、36 项本地端到端通过；完整 live 运行 76 项通过，2 项中途失败分别是重建 dist 时测试服务启动找不到 assets，以及旧脚本未先关闭浮层。最终布局/词语 20 项、语音/拼读 16 项专项全部通过；课堂体验和游戏首页各 4 项通过；最后单色图标构建的跨页面布局 2 项再次通过。lint、类型检查、格式与发布资源校验通过。额外 open-voice 用例仍因旧数量断言（1614，当前2777）失败，未修改声音资产或放宽该声音门禁。
