# Web 屏幕调试与交互验收

2026-11-14；SPEC-025 WEB-DEBUG-01～03。工作区 `love-pinyin-web-debug`，分支 `codex/web-screen-debug`。无新增依赖、教学规则或数据库迁移。

## 功能与修复

- 本机 Web 家长高级设置可打开同源页面，选择 390×844 手机、320×568 小屏、1280×800 桌面及横竖屏；切换尺寸不重载预览。预览继续访问真实 API，写入当前家庭档案，不伪造原生桥接或识别能力。
- 使用系统 modal dialog 限制键盘焦点，关闭后返回入口，并刷新外层家庭状态。预览内不再嵌套调试入口。没有家庭旧素材包时 Web 仍可使用调试入口；独立原生 App 不显示此入口。
- 修复边框占用导致标称 390px、实际 386px 的尺寸误差。
- 窄屏课堂听/写/练切换栏固定可达，切换后在提交新布局时定位到活动标题，修复 WebKit 留在旧内容底部的问题。桌面不自动定位。

## 验收方法与边界

使用本机 FastAPI、真实内容及真实声音文件，每项自动测试建立独立家庭数据库。桌面覆盖 Chromium/WebKit，手机覆盖 Pixel 5 与 iPhone 13 的浏览器设备参数；专项还覆盖 320/390/820/1280px、横屏及大字号。后者是浏览器模拟，不能作为真机验收。

| 范围       | 验证内容                                                                               |
| ---------- | -------------------------------------------------------------------------------------- |
| 家庭与数据 | 配对、家长权限、内容升级、下载恢复、删除后恢复、服务重启、待确认作答与重复提交         |
| 课堂       | 听写练切换、标准音、笔顺播放/取消、拼读、首答成绩、失败重试、练习总结                  |
| 两类天天练 | 选课、词语图片、听写隐藏正文、连读、标记、旋转、逐字注音、独立滚动、声音失败与设置焦点 |
| 四款游戏   | 开始、真实动作过关、设置、暂停、恢复、退出与存档、拖动取消及点击替代                   |
| 小卖部     | 商品与货架、人工逐件确认、短句/汉字切换、播放取消、暂停、购物车和结算                  |
| 调试窗口   | 真实 iframe、精确视口、旋转、平台标记不伪造、Escape 与焦点恢复                         |

手机配置排除旧 SHOP-05 桌面键盘/合成麦克风契约测试：该测试假设录音面板展开后货架仍可直接操作，与手机分步购物不相符。其桌面契约另行运行；手机使用 SHOP-10/17/22 和真实服务的权限拒绝测试。合成麦克风及受控识别结果只证明 UI 状态机，不证明识别准确率。安装 Qwen 的专项测试须有固定模型和显式环境开关；本次不下载模型。

视觉检查读取实际截图，检查了桌面首页、手机首页、调试窗口、320px 课堂与天天练、WebKit 课堂切换后的内容。自动验收不能证明儿童理解、游戏趣味、真实扬声器听感、系统安全区、原生桥接、来电/耳机中断或家庭 LAN；这些门禁仍单独保留。

完整旧 product 套件的尝试发现旧素材测试查找 `ā`，新版默认显示 `a`，因此未把该套件标为全通过；本次功能覆盖使用上述当前内容与界面专项，不把旧测试超时解释为儿童答题错误。

## 工程结果

- `npm run verify:all` 通过：221 项前端单元、564 项后端、36 项六项目视口基础回归、86 项真实服务桌面回归。日志 `/tmp/lp-delivery-verify.log`。
- `npm run validate:release` 通过；14 课、785 条天天练、38 课词语与 1152 个词语声音 ID。日志 `/tmp/lp-delivery-release.log`。
- 手机矩阵 126 项中首轮 120 通过、5 跳过、1 项旧购物测试假设不适配手机：改为先选商品，再在阅读面板检查人工确认，每件商品通过「继续挑商品」返回货架。修正后 `--last-failed` 的 1 项通过，另 SHOP-10 双浏览器 4 项复验通过。合计 121 个用例已通过，5 个有条件专项未执行。日志 `/tmp/lp-delivery-screens{,-recheck}.log`、`/tmp/lp-phone-shop-final.log`。
- 桌面交互专项 45 通过、15 跳过：覆盖四游戏、笔顺、课堂、小卖部及受控麦克风状态。跳过项是 WebKit 不运行的 Chromium 合成麦克风用例，以及未启用的本机 Qwen 模型实测。日志 `/tmp/lp-delivery-interaction.log`。
- 桌面新增功能及词语专项另 22 项通过；截图证据保存在工作区 `build/web-screen-proof/` 与 `test-results/`。未执行真实移动设备或新增家庭 LAN 验收。
