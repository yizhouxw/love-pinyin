# 儿童数据与本地运行边界

调研日期：2026-09-25。此文件记录工程要求及发布检查，不声称完成具体运营模式的法律审查。

《儿童个人信息网络保护规定》覆盖不满十四周岁儿童，要求必要性、清晰告知、监护人同意、删除和委托处理管理。[国家网信办原文](https://www.cac.gov.cn/2019-08/23/c_1124913903.htm) 《未成年人网络保护条例》自2024-01-01施行，含个人信息保护及防沉迷要求。[国务院条例原文](https://app.www.gov.cn/govdata/gov/202310/24/508651/article.html)

工程决策：首版仅家庭LAN，自托管不自动等于免除数据责任；开源代码发布与运营公开儿童服务分开。未来公网服务、学校部署、云同步或商业发行需重新审查告知、备案、运营规则和安全配置，不沿用家庭假设。

| 数据                     | 位置/期限                                | 行为                                                   |
| ------------------------ | ---------------------------------------- | ------------------------------------------------------ |
| 家庭档案、昵称、学习事件 | Mac SQLite，家长可清除                   | 允许随机头像，避免真实姓名/学校/生日                   |
| 本次录音                 | 浏览器与Mac进程RAM，完成/退出/异常即释放 | 仅本机LAN，无声纹、无第三方上传、默认不下载            |
| 评分摘要                 | Mac SQLite                               | 仅目标ID、维度分、可信度与版本；不存原始声学特征       |
| 会话                     | HttpOnly cookie/服务端hash               | 可撤销；不出现在导出文件                               |
| 学习备份                 | 家长指定本机私有目录                     | JSON不含录音和凭据；删除在线数据不自动删除家长既有导出 |
| 日志                     | 仅错误码/耗时/版本                       | 不记请求body、音频、昵称、cookie、指纹                 |

首次录音前家长看到录音去向、用途、不保存原音与删除操作；孩子能明确开始/停止。拒绝麦克风权限可继续非录音游戏，但不伪称完成评分目标。录音期间示范音停止，离开页面停止所有MediaStream track。

网络证明：正式验收在WAN断网、LAN可用环境跑完整学习；检查浏览器和Mac进程的出站请求，除指定本机同源API外无第三方流量。供应商离线SDK若要求周期联网/遥测，必须单独验证可禁用，不能仅凭“离线”营销词合入。

运行时 Content-Security-Policy 至少限制 default-src/connect-src为self，音频blob和Worker按实际最小配置添加。FastAPI的Swagger默认CDN页面当前禁用，以免断网依赖；用本地OpenAPI JSON。
