# 数据与本地运行边界

首版只有学生和家长，家庭模式使用一个匿名档案。无外部账号、外部语音上传、专业发音评分或遥测 SDK。SPEC-008/009每日跟读例外允许主动录音，只在当前浏览器页面内存保留，换条/后台/退出清除；停止录音后仅发送家庭Mac内存做识别匹配，不落盘、不进入SQLite或备份。此处记录实际工程行为，不等于公网或学校运营的法律审查。

| 数据                               | 保存与清理                                                                                   |
| ---------------------------------- | -------------------------------------------------------------------------------------------- |
| 当前课、设置、作答、会话与复习计划 | Mac `private/` 内 SQLite；家长可删除学习记录或重置家庭                                       |
| 配对与设备会话                     | 数据库保存令牌摘要；会话Cookie为HttpOnly、SameSite=Strict，HTTPS时加Secure；30天有效，可撤销 |
| 访客练习                           | 浏览器sessionStorage临时快照；服务端请求级内存库处理后销毁，不写家庭数据库                   |
| 中文声音、标准音及课程录音         | Mac私有文件，通过固定ID资源接口读取；不随MIT源码分发                                         |
| 家庭JSON导出                       | 不包含声音文件、Cookie或配对令牌；删除在线数据不会删除家长已下载的副本                       |
| SQLite运维备份                     | 包含数据库中的设备/令牌摘要等运行信息，须作为私有数据保管；默认保留7份                       |
| 服务日志                           | Uvicorn可记录访问路径、状态及异常；不应开启请求体/Cookie日志，分享诊断前检查并脱敏           |

DEVICE-01另在家庭Mac保存设备型号、最后认证连接时间与已消耗的配对码，仅家长列表可读。型号可由家长填写或以明确标注的浏览器推测补全，不保留完整UA或采集硬件指纹；已用码不能重新配对。设备元数据随SQLite运维备份保留，不进入学习JSON导出。详见[ADR-0022](../adr/0022-device-connection-metadata.md)。

## 访问保护及限制

家长权限由服务端配对角色校验，界面的成人确认仅防误触。修改家庭数据需CSRF令牌；提供Origin时检查同源，缺少Origin并非统一拒绝。配对码5分钟、一次使用有效，失败次数在进程内限流。导入与访客请求限制1MiB，其他接口使用各自字段校验，不声称所有请求都有统一总量限制。

访客教学资源接口无配对要求，包括已安装的课程录音。家庭数据接口仍需配对；不要把局域网教学资源当作受家长身份保护的私人文件分享系统。

服务设置 `X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`、仅允许同源麦克风，禁止摄像头/定位的 `Permissions-Policy`，API使用 `Cache-Control: no-store`。Swagger/ReDoc页面关闭，本地OpenAPI JSON保留。**尚未设置 Content-Security-Policy**；这是待完成的安全加固，不能因没有外部资源而声称已实施CSP。没有service worker缓存家庭数据。

## 待完成的验证

正常学习没有自动下载模型或第三方语音回退。真实声音自动化已记录无第三方请求，但仍需在实际家庭网络断WAN、保留LAN时观察浏览器与Mac出站请求，完成跨设备操作。家庭HTTPS信任、设备丢失后的撤销及实际家庭删除/备份习惯须在交付时说明。

未来若改为公网、学校、多家庭或云同步，必须重新设计认证、资源访问与数据保护，不能直接沿用家庭网络假设。
