# SOAK-01 音频长时运行结果

2026-10-05，内容2026.10.05.15。SOAK-01已通过两引擎完整时长验收。观测器v2修复后的代码对应2a9d86a，真实音频/API/UI均通过，标准音样本完整。下文保留v1漏采样及失败历史，最终结论以v2为准。入口为npm run test:e2e:soak，默认每引擎至少1200秒；还须满足标准音采样完整性、completed=true、qualifiesFor20MinuteRun=true及进程成功退出，中断、短跑或仅经过20分钟不计通过。

## 固定统计口径

- 实际安装Chrome与Playwright WebKit均以无头模式各自使用独立FastAPI/SQLite，在同一Mac并发运行。只比较这次本机工作负载，不用于宣称Safari真机、移动端或家庭LAN性能。
- 逐课六题、听中文指令/标准音/反馈、确认拼读、提交真实答案、回到路线及经过两轮休息。数据由UI生成，最终真实导出条数须等于提交题数。
- 标准音首次延迟：第一条standard=true的原生play调用到playing事件间隔。所有播放和标准音分别报告样本数、p50/p95/最大值；分位数用nearest-rank（升序第ceil(p×n)个样本）。空样本写不可用，不填零。切题延迟是点击继续至下一题编号可见，包含测试观察开销；不等于扬声器物理出声延迟；首次标准音也不代表清空操作系统文件缓存后的冷启动。
- 每轮闲置点要求src移除、readyState/networkState为0、加载中的媒体、播放中的媒体、未关闭AudioContext及未撤销Blob URL计数均为0。currentSrc可保留旧地址，该字符串不等于仍加载媒体。用WeakRef观测，不以强引用保留已播放对象。
- Chrome在轮末显式GC后记录JSHeapUsedSize、DOM节点、监听器与文档数。展示逐轮值及第3至7轮、末5轮中位数变化（不足10轮则不作两窗口结论）；原始前两轮同时保留，不隐藏暖机增长。WebKit无该CDP指标，标不可用。任何增长必须结合原始样本解释，不能只凭平均值或活动资源归零就宣称所有原生内存无泄漏。
- 本次正式测试期间不额外运行构建/完整回归等重负载任务；两个测试引擎本身仍有并发负载。原始JSON、日志与截图保存于本机private或test-results，公开文档只写聚合结果及局限。

## 历史失败与修正

初始烟测把currentSrc旧地址误计为加载；诊断确认src为空、readyState/networkState为0后修正。第一轮正式运行在第2轮后因过早打开家长页、被随后到达的休息页替换而卡住，已主动中止，证据在private/soak01-interrupted。后续烟测表明ui-rest长5.565秒，资源归零等待5秒不足，调整为与朗读一致的20秒。单次操作15秒上限和完成状态判定保留。修正后Chrome232秒/WebKit245秒，各4轮24题通过，只是烟测。

## 观测器v2：修复和重跑

v1在play调用后收到音频初始化排队的emptied事件，错误撤销了playing监听，导致实际已完成的57次标准音全部漏记延迟。v2只在src清空时把emptied视为取消；重播前清理前次观测，保留原生play及拒绝结果。新增断言要求标准音playing样本数等于standardPlays且大于零，缺样本不再能标记完成。

修复后90秒目标烟测：Chrome实际112,361ms、WebKit118,695ms，均2轮12题，均6次标准音和6个延迟样本，首次标准音分别23.4ms / 29ms。两者completed=true、qualifiesFor20MinuteRun=false；日志和JSON在private/soak01-latency-smoke。这个结果证明修复在短测有效，不代替完整时长。新的完整运行已成功结束，记录为private/soak01-v2-full.log；结果独立汇总如下，不把不同运行样本混为一次实验。
