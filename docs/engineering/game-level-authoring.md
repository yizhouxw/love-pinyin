# 场景关卡数据与维护

对应SPEC-017 KEY-01 / LEVEL-01～04、ADR-0033。游戏的一整关是三个章节和十二个任务，单个拼音命中只是检查点；每种游戏六关，共24关、72章、288个任务槽。通过后短语音反馈并自动续段，P键或“连续旅程”可停留。

## 三层边界

| 层                 | 文件                     | 保存什么                                                       |
| ------------------ | ------------------------ | -------------------------------------------------------------- |
| 游戏目录/难度/控制 | content/games.json       | 四游戏入口、推荐阈值、物理难度、速度与键位                     |
| 关卡与路线         | content/game-levels.json | levels、chapters、segments、patterns、themes；没有拼音标准答案 |
| 教学内容           | content/curriculum.json  | 教材课序、知识点、题目、真实标准音和唯一答案                   |

src/domain/scene-game.ts只接收EngineConfig、时间和输入，输出运动/碰撞状态；引擎不导入上述JSON。src/domain/game-levels.ts解析前端类型，server/game_levels.py负责严格校验/冻结；src/app/scene-game.tsx仅协调绘制、适配器、声音、原作答接口和接续。

关卡章节有各自地名和路线顺序，首两关偏启蒙、三四关偏熟练、五六关偏挑战。关卡可自由选择；实际难度/速度由独立设置决定，已学教材范围始终由家长当前课决定，不能靠选第六关解锁未学拼音。

## 路线格式

每个level引用一个theme和三个chapter；每章四个segment，每段引用一个pattern。48种共享pattern描述长度、目标位置、障碍、收集物或节拍；主题提供四个受校验的颜色。修改这些数据即可改路线，无需改React组件。

- `length/choiceAt/choiceGap`：本段长度、拼音目标位置、鼓岛目标音符间距。后者保证四个候选音符都能进入击打区。
- `obstacles`：id、at位置、lane跑道、kind、size。root可跳、bush需换道、reef需绕行、asteroid可躲避或发射击碎。`lane=-1`仅用于横跨跑道的根木；0～3按当前候选数量映射到跑道。
- `pickups`：固定数量和坐标的沿途收集物；未收集不会判拼音错误，无无限奖励。
- `beats`：鼓岛的热身鼓点谱；命中反馈仅属于运动游戏，随后候选拼音音符才触发客观作答。
- `currentStrength/travelScale`：该路线水流与基础运动倍率；游戏速度、辅助和实际物理难度作为独立EngineConfig传入。

所有障碍在拼音目标之前，位置/尺寸有界、ID唯一、引用与场景一致。脚本集中在content/narration.json，level.voiceId必须有真实中文声音。声音沿既有固定Qwen构建，不允许运行时TTS或把拼音字母交给中文TTS当示范。

## 教学绑定与恢复

POST /sessions选择gameId和gameLevelId；服务器按当前课与之前的真实可用题目安排十二道不同任务，优先当前课/待巩固并轮转历史。题选项完整保留，答案只在服务器。gameRun冻结level、用到的patterns、theme和逐段instanceId绑定；SQLite迁移10和schema5可选字段保存同一数据。刷新接续尚未完成检查点；旧版六题会话显示兼容旅程，可退出重新选择完整关卡。

家庭导入限制16MiB、访客快照4MiB，仍有结构校验和事件数边界；不把运动轨迹、儿童录音或身份写入关卡数据。

## 验证

执行`uv run --locked python -m scripts.validate_game_levels --release`全量检查；`validate:content`与`validate:release`已集成同一检查。`tests/server/test_game_levels.py`逐关验证12道真实已学任务、至少3个知识点和声音目标、冻结/恢复/恶意绑定/迁移回滚与超过旧容量的档案往返。物理边界与四路目标可达在scene-game.test.ts；实际键盘焦点、跨任务和完整12段通关在product用例验证。

这证明软件功能，不替代真机操作、儿童理解和家庭LAN试用。
