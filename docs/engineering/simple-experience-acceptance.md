# SPEC-016 交互整改与验收

2026-10-24，产品版本0.2.0。需求见[SPEC-016](../specs/SPEC-016-simple-family-experience.md)，组织原则见[ADR-0029](../adr/0029-task-focused-family-interface.md)。

## 问题与整改依据

此前按功能逐项叠加控件，没有先定义孩子完成一次任务的最短路径。材料选择、当前任务、辅助说明、录音及家长设置在同一层展开；多个独立声音按钮又要求用户理解播放状态。这使功能虽然存在，孩子仍需寻找下一步，家长也需要解释。另一处不足是只检查单个状态，没有同时检查准备、播放、跟读、反馈之间的位置和焦点变化。

本次按任务组织入口，以合理默认值完成连续动作；常用操作直接可见，低频细节按需展开。固定主要状态区域，统一取消、语音偏好和返回焦点。保留全部课程、声音、题型和数据边界；精简不能依靠删除能力或放宽成绩规则。

## 证据

本轮完整工程检查通过：`npm run verify:all`，127项前端/工具测试、379项Python、30项视口、40项真实服务GUI。日志：本机忽略目录`private/spec016-verify-final.log`。

发布检查通过：`npm run validate:release`，14课/83知识项/476题/79朗读目标；14份/840条每日材料、600份标准音。日志：`private/spec016-release-final.log`。

完整声音产品回归覆盖100个场景，全部取得通过记录。运行已构建产物，使用`config/playwright.product.config.ts`，Chromium/WebKit两引擎、真实FastAPI/SQLite与实际声音文件；故障注入只用于中断/拒绝/不可用边界。为减少长音频等待，按浏览器与文件分组并行；原全套任务在转交剩余分组后中断，未把中断算通过。以Playwright列出的100个项目/文件/场景为准，对照各组及修复后的记录去重核对，结果100/100、缺失0；机器明细在本机`private/spec016-product-coverage.json`。

产品日志：`private/spec016-product-final.log`、`private/spec016-product-webkit-final.log`、`private/spec016-product-webkit-remaining.log`及`private/spec016-device-gap-rerun.log`。最终构建后，受目录焦点、家长布局和书写窄屏调整影响的24项全部补跑通过，记录`private/spec016-product-final-targets.log`；最终真实服务40项复跑通过，记录`private/spec016-live-final-layout.log`。最终前端工程/构建复查通过，记录`private/spec016-ui-final-verify.log`。

初次回归暴露了旧测试仍通过已折叠的入口操作、仍假定标准音必须再点一次，以及首页精简后误删天天练语音帮助的问题。已更新用户路径、保留原有业务断言，将帮助恢复至选材页折叠区。WebKit返回焦点差异改为明确记录课程入口；目录循环测试遵循返回时保留的展开状态，节奏测试展开保存后重新挂载的精细设置，并从真实bootstrap核对学习设备权限。失败日志保留，不以删测试或放宽成绩/权限断言处理。

页面截图见[页面预览说明](../screenshots/README.md)。九张预览由隔离临时家庭访问真实API与资源拍摄，截图任务通过，记录`private/spec016-readme-capture-final.log`；已目视检查桌面、390/320px的主要页面及版本弹窗。已在实际Mac Chrome打开当前本机服务，核对课程听/写/练、返回焦点、天天练选材/连播/停止及静态提示占位；此为本机桌面观察。
