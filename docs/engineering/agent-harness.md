# Agent harness：并行需求与交付

2026-11-13 用户确认；取代此前直接 main 开发约定。

- 每项需求创建独立 Git worktree 和 codex/ 分支。先检查 git status、worktree list 与活跃任务，不搬走、暂存、清理或提交其他任务改动。
- 源码、测试、构建输出、临时档案与工具缓存按工作区隔离；不得共享可写 dist、SQLite 或测试家庭档案。只读 SDK 与固定依赖缓存可复用。

- 验收完成后合并 main 并普通 push；禁止强推。无需默认创建 PR。合并后从确定提交更新本机 Web 和 Mac App，串行验证再清理旧程序及安装包，保留家庭数据、备份、证书和模型。
- 报告工作区、分支、提交、验证范围和剩余真机门禁。未完成切片继续开发，不把环境探针或骨架称为产品交付。
