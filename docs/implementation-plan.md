## 工作约定

先更新需求和SPEC再改实现，每次提交对应清晰验收编号；多个独立切片可持续执行到用户目标完成，不以一个小测试通过结束整个目标。领域规则、内容ID和答案保留在content/与服务端，浏览器不生成教学规则。新增依赖锁版并记录官方来源/许可/安装；尽量使用已装依赖和系统工具。每个切片可独立提交，不自动推送或发布。

`verify:all` 证明工程回归；真实服务与实际音频验收证明产品链路；真实设备证明实际兼容性。桌面和真机证据不能互相替代。模拟 API、合成测试正弦和视口模拟仍可用于特定边界，但不得作为真实语音或真机结论。

## 外部证据

用户已提供课程录音，可用于其家庭私有素材准备，不必等公开许可才允许本机处理。代码MIT不覆盖这些录音或Mac系统声音生成文件。标准音直接信任cmguo/PinYinSound，取消审音台及人工审批机制；公开发行素材的许可记录独立于家庭使用。家庭实际设备验收记录明确具体设备及结果。

## 课程能力追踪

SPEC-002 CURR-01已建立[课标能力与产品证据表](research/curriculum.md)。后续完整课堂内容除补题和精确标准音外，还须制作四线三格/逐笔观察与纸笔引导，以及生活词图义迁移；两者均需中文语音与内容依据核对，不能把现有选择题作为书写或口头能力的替代证明。2022基线原件已核验相关页，2025日常修订条款仍待官方原件或合法纸本逐项核对。

## 标准音落地

按[ADR-0008](adr/0008-trusted-standard-audio.md)直接信任cmguo/PinYinSound。205个目标映射与私有安装适配器已纳入阶段3/4。用户仅学生和家长；审音台、审核角色和审核状态全部取消。标准音可用性由安装、文件完整性和目标映射决定，运行时仅从本机配对API提供。
