# 实际可用产品实施计划

当前目标是家庭实际可用产品，范围见[PRD](product/PRD.md)与[产品重审](product/reimplementation-review.md)。按[ADR-0005](adr/0005-voice-first-product.md)提供语音引导，按[ADR-0008](adr/0008-trusted-standard-audio.md)直接采用PinYinSound。用户仅学生和家长；原课程不录音或评分。2026-10-13新增[SPEC-008每日跟读](specs/SPEC-008-daily-reading.md)，允许浏览器内存录音回放；用户随后要求不训练，以识别结果判断；[SPEC-009](specs/SPEC-009-asr-reading-match.md)接入已有本地Whisper，提供音节识别匹配，不作专业发音/四声评分。

## 后续执行顺序

1. 在家长确认的真实客户端网络准备可信HTTPS，先运行部署预检，再用真实设备配对、听题、作答和读共享进度。
2. 断开WAN但保留LAN完成学习；测试真实网络中断、返回和待确认作答恢复，记录出站请求。
3. 补移动/桌面兼容与可访问性，执行Mac登录、重启、休眠及目标版本回滚演练。
4. 家庭试用验证儿童理解和家长操作；公开发行前独立检查素材许可、安全报告渠道与CSP加固。

可以连续完成多个验收切片，但每次提交对应明确编号。纯文档整理不改变未完成要求。`verify:all`、真实声音GUI和真机验收分别证明不同范围，不能互相替代。PinYinSound缓存、模型、证书、数据库与测试家庭数据留在忽略目录，儿童录音仅内存处理；授权课程/PDF/Qwen声音按SPEC-010/011入库并保留独立许可；按用户授权直接在main提交并推送远端，不新建分支或走PR流程；不自动公开发布。
