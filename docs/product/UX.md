# 体验、页面与跨端验收

状态：2026-10-24按SPEC-016完成儿童/家长交互简化；本文跨端矩阵是验收要求，完成范围见[STATUS](../STATUS.md)。业务范围以 [PRD](PRD.md) 为准。原课程不请求麦克风、不录音、不做发音评测；天天练按SPEC-008/009允许主动录音与本地音节匹配，仍不评四声或发音分数。

## 1. 信息结构

| 页面     | 核心内容                             | 主要操作                        | 退出/异常路径                          |
| -------- | ------------------------------------ | ------------------------------- | -------------------------------------- |
| 配对页   | Mac 地址/连通状态、一次性配对码输入  | 配对、重试连接                  | 无权限不能读取儿童进度                 |
| 家长初设 | 固定教材说明、当前课                 | 保存并开始                      | 不填真实姓名                           |
| 儿童首页 | 当前课、今天建议、继续上次、课程入口 | 开始 6 题、继续、选课           | 无待练内容时可自选，绝不空白或自动循环 |
| 课程地图 | 课名与图标、知识点状态、复习角标     | 进入课程                        | 进度不使用颜色作为唯一信息             |
| 知识卡   | 拼音字形/调号、标准音、简短说明      | 听一听、练一练                  | 资源缺失有原因及返回按钮               |
| 练习页   | 单个任务、2–4 项输入、当前第几题     | 再听、回答、提示、跳过          | 固定位置退出；已答题保留               |
| 本次小结 | 已练内容、独立首次正确数量、下一建议 | 结束、再练一轮                  | 第一按钮为结束；连续两轮展示休息页     |
| 家长进度 | 逐知识点状态、样本量、复习到期       | 选课、导入/导出、删除、设备管理 | 敏感操作需要管理授权与确认             |

儿童区固定三个常见操作位置：左上返回，中央任务，底部主操作。题目反馈后由儿童点击「下一题」，不因自动跳转抢走阅读和听音时间。跳过或退出不扣除奖励；网络等待有取消/返回入口。

首页先展示当前课程与开始练习、课堂学习、天天练入口；完整学习路线按需展开。课程页通过听一听/写一写/练一练切换活动，图片逐张浏览。天天练分为选材与练习，学习时固定保留播放/跟读提示区，录音比较按需展开。所有课与活动仍通过语义按钮和键盘进入。

## 2. 布局与输入

- 手机从 320 CSS px 起单栏可用；平板竖屏单栏或两列卡片；电脑内容最大宽度 1120 px。横屏不强制锁定，安全区留白用环境变量。
- 常用可点区域至少 48 × 48 CSS px，相邻主要选项至少 8 px 间距；正文默认 18 px 以上，拼音目标 40–64 px。文字放大到 200% 后仍可操作。
- 使用语义化 `button`、表单标签和可访问组。Tab 按视觉顺序移动，Enter/Space 激活，Esc 关闭可关闭的对话框；焦点返回触发按钮。
- 当前拼读点选完整合法候选、预览、撤销和确认，不提供逐格组装或拖拽；键盘可聚焦卡片后确认。必要操作不依赖悬停、长按、双击、精细划线或设备晃动。
- 正确/需要再试同时用文字、图标和颜色表达。动画遵循 `prefers-reduced-motion`。错误后允许重试，不用失败音效或嘲讽。
- 听辨题在揭晓前的辅助说明不得泄露目标答案；不能把完整目标拼音写入播放按钮的可访问名称。

控件间距统一为同组默认12px、独立组18px，按钮至少48px高。声音和主操作分别成组；家长危险操作独立呈现，窄屏字段/按钮可换行；焦点、选中/播放、禁用状态明确。

## 3. 练习状态

`准备资源 → 可答 → 首次反馈 → 修正或下一题 → 已完成`。资源失败进入「资源未就绪」，不能显示可计分的选项。首次回答提交后短暂禁用重复提交；失败使用同一请求 ID 重试。

提示需在使用前注明「看看提示」。错误答案显示「再听一次，再选选看」，正确反馈说明孩子认出了目标。跳过不算错误；小结区分完成、跳过与独立首次正确。退出保留已提交记录，未确认的拼读选择不算进度；保存请求进行中须等待结果，不能提前关闭小结。

会话显示「第 2 题 / 共 6 题」，不使用倒计时。任何题都能提前结束，不扣已有奖励。刷新后从服务器恢复会话，已完成题不重复计分。

## 4. 音频播放

中文指令、家庭课程录音和标准音遵循 `等待播放手势 → 加载 → 播放 → 结束`。切题、离开页面、播放失败或取消时停止并释放当前媒体资源。全站共用一个播放协调器；播放、暂停和重播均可由键盘、鼠标、触摸操作。PinYinSound标准音未安装或文件损坏时显示「标准音待准备」，不使用 TTS 冒充拼音。中文指令允许本机预生成语音；用户家庭课程录音独立显示为课程录音，范围见 ADR-0005。

原课程不提供麦克风或发音评分。天天练录音比较为可选折叠区域，主动点击才请求麦克风，内存处理、离开清除；识别失败不判错。正式发音评测仍须独立SPEC。

## 5. 家长操作

进度卡显示样本量，例如「最近 5 次独立练习，4 次首次答对」，不能只给无解释的百分比。无记录时显示下一步，不画零分曲线。

导入预览列出文件版本、导出时间、记录总数、当前课变化和覆盖范围；确认按钮为「替换家庭学习记录」。预览后其他设备写入导致版本不一致时，提示重新预览。删除确认说明会影响所有已配对设备；取消无副作用。

## 语音优先儿童路径（R-022）

第一次点击开始后自动听题；视觉上保留一句短指令与大号拼音目标，扬声器按钮可随时重播/停止。拼音目标不交给中文TTS读成英文。带汉字的选项用单独扬声器按钮朗读，选择和听读不嵌套，不误提交；纯拼音选项是识别目标。提示用声音说明并高亮目标卡，结果/小结/休息皆可听。浏览器阻止自动播放时仍可点击大号听题按钮恢复。切题/离开/后台时停止，错误能重试且不产生作答。

拼读完整候选使用试选台：先点卡片，在预览区看完整拼音，中文声音提示点勾确认或回转箭头撤销。选择后焦点移到确认，撤销回到原卡片；试选、换选、撤销和刷新未确认草稿不记成绩。只有确认会提交原选项ID，故障重试沿用同一请求号，修正不增加计分。两题复习刷新后仍标明复习，不误报课程只准备了两道题。

学生与家长界面不显示待审、教学审校或审核角色。课程卡使用“播放标准音”，家长只需查看音频是否可用；标准音来源固定为cmguo/PinYinSound。

## SPEC-016统一交互

语音偏好在各学习场景共享，就近开关保持同步；点击天天练拼音/目录或书写目标直接开始示范，开关只控制附加引导。游戏有标准音的题目在说明后顺序播放标准音，说明失败不会阻塞标准音；未完整听完必要标准音仍不能作答，停止取消整条队列。重听不清除已完成的听音状态。

家长首屏提供学校当前课和学习概览。声音与播放、详细记录、设备、备份恢复、删除重置分别展开；导出显示下载成功，JSON放技术详情。节奏默认展示三个预设，精细调整展开使用。错误显示中文原因与对应操作，技术代码收起。学习页与家长页可打开本机版本/更新说明，产品版本与教材内容版本分开。

视觉验收关注实际任务：桌面、390/320px主操作可达，正常播放状态切换不挤动操作区，常用设置不埋在长列表之后，详细信息仍可展开并有键盘等价操作。浏览器截图和自动化不替代儿童/家长试用或移动真机。
