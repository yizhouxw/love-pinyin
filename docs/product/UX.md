# 体验、页面与跨端验收

状态：下一阶段实施规范。业务边界和规则以 [PRD](PRD.md) 为准；本地评分指家庭 Mac 处理，录音只经局域网传送，不得调用第三方。

## 1. 信息结构

| 页面     | 核心内容                                 | 主要操作                              | 退出/异常路径                            |
| -------- | ---------------------------------------- | ------------------------------------- | ---------------------------------------- |
| 配对页   | Mac 地址/连通状态、一次性配对码输入      | 配对、重试连接                        | 无权限不能读取儿童进度                   |
| 家长初设 | 教材版本、当前课、录音评分说明           | 保存并开始                            | 不填真实姓名；跳过录音启用可完成其他练习 |
| 儿童首页 | 当前课、今天建议、继续上次、课程入口     | 开始 6 题、继续、选课                 | 无待练内容时可自选，绝不空白或自动循环   |
| 课程地图 | 课名与图标、知识点状态、复习角标         | 进入课程                              | 进度不使用颜色作为唯一信息               |
| 知识卡   | 拼音字形/调号、标准音、简短说明          | 听一听、练一练                        | 资源缺失有原因及返回按钮                 |
| 练习页   | 单个任务、2–4 项输入、当前第几题         | 再听、回答、提示、跳过                | 固定位置退出；已答题保留                 |
| 跟读页   | 标准音、录音状态、录音时长               | 录音、停止、回放、发送到自家 Mac 评分 | 权限/证书/连接异常可退出，不判错         |
| 本次小结 | 已练内容、独立首次正确数量、下一建议     | 结束、再练一轮                        | 第一按钮为结束；连续两轮展示休息页       |
| 家长进度 | 逐知识点状态、样本量、复习到期、跟读摘要 | 选课、导入/导出、删除、设备管理       | 敏感操作需要管理授权与确认               |

儿童区固定三个常见操作位置：左上返回，中央任务，底部主操作。题目反馈后由儿童点击「下一题」，不因自动跳转抢走阅读和听音时间。任何网络等待均有可操作的取消/返回入口。

## 2. 布局与输入

- 手机从 320 CSS px 起单栏可用；平板竖屏单栏或两列卡片；电脑内容最大宽度 1120 px，学习区不无限拉宽。横屏不强制锁定，安全区留白用环境变量。
- 常用可点区域至少 48 × 48 CSS px，相邻主要选项至少 8 px 间距；正文默认 18 px 以上，拼音目标 40–64 px。文字放大到 200% 后仍可顺序阅读与操作，不遮挡固定底部按钮。
- 使用真正的 `button`、表单标签和可访问组。Tab 按视觉顺序移动，Enter/Space 激活，Esc 关闭可关闭的对话框；焦点返回触发按钮。键盘不能陷在动画或卡片内。
- 拖拽只是可选增强。拼读组成允许依次点选「声母/韵母/声调」和撤销；键盘可以聚焦卡片后确认。描红可使用触摸/鼠标轨迹，但无轨迹输入也可完成该知识点核心练习。
- 不依赖悬停；悬停提示必须也能通过焦点或点击出现。禁止仅靠长按、双击、精细划线或设备晃动触发必要操作。
- 正确/需要再试同时用文字、图标和颜色表达。反馈音可关闭；动画遵循 `prefers-reduced-motion`。播报简短结果使用 `aria-live="polite"`，不重复朗读整屏。
- 拼音读音的学习不能完全由屏幕阅读器等价替代，但导航、选项、结果、设置和错误必须可读。听辨题在揭晓前的辅助说明不得泄露目标答案；不能把完整目标拼音直接写进播放按钮的可访问名称。

## 3. 练习状态机

`准备资源 → 可答 → 首次反馈 → 修正或下一题 → 已完成`。

准备资源失败进入「资源未就绪」，不能显示可计分的选项。首次回答提交后按钮进入短暂提交状态，防止双击；失败时展示未保存并使用同一请求 ID 重试。答案错误显示「再听一次，再选选看」，正确显示「你认出来了」；不用笼统夸赞天赋或失败嘲讽。

提示会在提供前注明「看看提示」。多次改答只更新本题反馈，不改变首次答题事件。跳过必须可用且不算错误；小结明确区分完成、跳过与独立首次正确。退出确认仅在当前有未提交输入或录音时出现，否则直接退出。

会话条使用「第 2 题 / 共 6 题」，不使用倒计时。对于精力不足的儿童，任何题都能提前结束，不扣除已有奖励。刷新后从服务器恢复会话；已完成题不因页面重复渲染再次计分。

## 4. 音频和评分状态机

标准音：`等待播放手势 → 加载 → 播放 → 结束`；切题/离开页面/开始录音立即停播，避免把扬声器的标准音录入评分。各页面共用单个播放协调器。

录音：`未启用 → 家长启用 → 浏览器授权 → 就绪 → 录音中 → 预览 → 上传自家 Mac → 评分中 → 结果`。用户每次明确点击开始；10 秒自动停止；停止后仍需明确发起评分。允许重录，重录会销毁前一段内存录音。若页面隐藏或屏幕锁定导致录音被中断，应停止轨道并显示「录音中断，请重新开始」，不偷偷恢复麦克风。

评分结果分为：

| 结果          | 显示                                                   | 记录方式                                             |
| ------------- | ------------------------------------------------------ | ---------------------------------------------------- |
| `scored`      | 经模型版本校准的 0–100 分、允许的维度和一条可操作建议  | 保存目标、模型/规则版本、分数摘要；不保存录音        |
| `uncertain`   | 「这次没听清，可以靠近一点再说」或经规则允许的具体原因 | 不给分，不判错；可仅计一次尝试，不影响掌握度         |
| `unsupported` | 「这部分还不能可靠评分」或「请在支持的浏览器打开」     | 无分；应在发布矩阵内消除此类必做任务                 |
| `unavailable` | 「这次没有完成评分」，带重试/重录/返回                 | 无分；允许同一请求 ID 查询最终结果，避免重复评分记录 |

评分必须在自家 Mac 上完成。Mac 地址与处理方式放在家长说明中，儿童只看到简明的「正在听你读」。Mac 服务断连显示「还没连上家里的学习电脑」，不能显示随机鼓励分。标准音回放与自己的录音回放分别命名，防止混淆。

## 5. 家长操作

进度卡必须给出样本量，例如「最近 5 次独立练习，4 次首次答对」，不能只给无解释的百分比。跟读评分使用单独区域，并可见模型版本/目标范围的简要说明。无记录时显示下一步，不画零分曲线。

导入预览列出文件版本、导出时间、记录总数、当前课变化和覆盖范围；确认按钮为「替换家庭学习记录」。预览后别的设备写入导致版本不一致时，提示重新预览。导出成功应明确文件已由浏览器下载，不能暗示自动云备份。删除确认说明会影响所有已配对设备；取消必须无副作用。

## 6. 真实跨端验收矩阵

正式发布前在实际硬件登记型号、系统版本、浏览器完整版本、屏幕尺寸、证书信任方式、日期和结果。以下为产品支持目标，不是已经完成的测试，也不承诺尚未验证的浏览器版本。目标最低系统版本在 SPEC-000/006 实测后锁定，发布前未锁定属于阻塞。

| 环境               | 自动化覆盖                      | 必须真实验收的内容                                                | 必做输入             |
| ------------------ | ------------------------------- | ----------------------------------------------------------------- | -------------------- |
| Mac 桌面 Safari    | Playwright WebKit 近似覆盖      | HTTPS 信任、麦克风、音频互斥、跨页取消、评分                      | 鼠标、完整键盘       |
| Mac/Windows Chrome | Playwright Chromium             | Mac LAN 地址访问、权限拒绝后恢复、声卡输入、导入导出              | 鼠标、完整键盘       |
| Windows Edge       | Chromium 近似覆盖               | 实际浏览器配对、录音及下载备份                                    | 鼠标、键盘           |
| 桌面 Firefox       | Playwright Firefox              | 录音编码、标准音解码、上传与评分                                  | 鼠标、键盘           |
| iPad Safari        | 平板 viewport/WebKit 近似覆盖   | 竖横屏、触摸、软键盘、证书信任、锁屏中断、后台恢复、录音编码      | 触摸、外接键盘       |
| iPhone Safari      | 手机 viewport/WebKit 近似覆盖   | 安全区、320 px 等效可用宽度、耳机/扬声器、来电中断、下载/导入文件 | 触摸、VoiceOver 抽查 |
| Android Chrome     | 手机 viewport/Chromium 近似覆盖 | 实际麦克风、蓝牙/扬声器、系统权限、文件选择器、横屏               | 触摸、TalkBack 抽查  |

所有行必须完成：配对 → 选课 → 四类客观题 → 跟读评分 → 退出重进恢复 → 从另一设备看到进度。再断开 Mac 的互联网，保留 LAN，重复跟读和保存；抓取网络证据确认无第三方请求。最后断开 LAN 或停 Mac，验证无假成功、重连后幂等恢复。

自动化还覆盖 320/375/768/1024/1440 px、200% 文字缩放、减弱动画、键盘无鼠标、API 超时/429/503/无权限、错误 MIME/超大录音/静音、损坏备份、双设备并发更新。WebKit 模拟通过不能填写「iPad 实测通过」。
