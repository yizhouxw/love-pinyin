# 体验、页面与跨端验收

状态：下一阶段实施规范。业务范围以 [PRD](PRD.md) 为准。首版不请求麦克风、不录音、不上传语音、不做发音评测。

## 1. 信息结构

| 页面     | 核心内容                             | 主要操作                        | 退出/异常路径                          |
| -------- | ------------------------------------ | ------------------------------- | -------------------------------------- |
| 配对页   | Mac 地址/连通状态、一次性配对码输入  | 配对、重试连接                  | 无权限不能读取儿童进度                 |
| 家长初设 | 教材版本、当前课                     | 保存并开始                      | 不填真实姓名                           |
| 儿童首页 | 当前课、今天建议、继续上次、课程入口 | 开始 6 题、继续、选课           | 无待练内容时可自选，绝不空白或自动循环 |
| 课程地图 | 课名与图标、知识点状态、复习角标     | 进入课程                        | 进度不使用颜色作为唯一信息             |
| 知识卡   | 拼音字形/调号、标准音、简短说明      | 听一听、练一练                  | 资源缺失有原因及返回按钮               |
| 练习页   | 单个任务、2–4 项输入、当前第几题     | 再听、回答、提示、跳过          | 固定位置退出；已答题保留               |
| 本次小结 | 已练内容、独立首次正确数量、下一建议 | 结束、再练一轮                  | 第一按钮为结束；连续两轮展示休息页     |
| 家长进度 | 逐知识点状态、样本量、复习到期       | 选课、导入/导出、删除、设备管理 | 敏感操作需要管理授权与确认             |

儿童区固定三个常见操作位置：左上返回，中央任务，底部主操作。题目反馈后由儿童点击「下一题」，不因自动跳转抢走阅读和听音时间。跳过或退出不扣除奖励；网络等待有取消/返回入口。

## 2. 布局与输入

- 手机从 320 CSS px 起单栏可用；平板竖屏单栏或两列卡片；电脑内容最大宽度 1120 px。横屏不强制锁定，安全区留白用环境变量。
- 常用可点区域至少 48 × 48 CSS px，相邻主要选项至少 8 px 间距；正文默认 18 px 以上，拼音目标 40–64 px。文字放大到 200% 后仍可操作。
- 使用语义化 `button`、表单标签和可访问组。Tab 按视觉顺序移动，Enter/Space 激活，Esc 关闭可关闭的对话框；焦点返回触发按钮。
- 拖拽只是可选增强。拼读组成允许依次点选「声母/韵母/声调」和撤销；键盘可聚焦卡片后确认。必要操作不依赖悬停、长按、双击、精细划线或设备晃动。
- 正确/需要再试同时用文字、图标和颜色表达。动画遵循 `prefers-reduced-motion`。错误后允许重试，不用失败音效或嘲讽。
- 听辨题在揭晓前的辅助说明不得泄露目标答案；不能把完整目标拼音写入播放按钮的可访问名称。

## 3. 练习状态

`准备资源 → 可答 → 首次反馈 → 修正或下一题 → 已完成`。资源失败进入「资源未就绪」，不能显示可计分的选项。首次回答提交后短暂禁用重复提交；失败使用同一请求 ID 重试。

提示需在使用前注明「看看提示」。错误答案显示「再听一次，再选选看」，正确反馈说明孩子认出了目标。跳过不算错误；小结区分完成、跳过与独立首次正确。只在存在未提交答案时要求退出确认。

会话显示「第 2 题 / 共 6 题」，不使用倒计时。任何题都能提前结束，不扣已有奖励。刷新后从服务器恢复会话，已完成题不重复计分。

## 4. 音频播放

标准音和题干音频遵循 `等待播放手势 → 加载 → 播放 → 结束`。切题、离开页面、播放失败或取消时停止并释放当前媒体资源。全站共用一个播放协调器；播放、暂停和重播均可由键盘、鼠标、触摸操作。没有经授权和审校的资源时显示「标准音待准备」，不能用系统 TTS、ASR 或网上下载文件替代。

首版不提供麦克风权限流程、录音状态、儿童录音回放或评测结果页。若未来重启评测，先按新 SPEC 补齐权限和隐私设计，再实现 UI。

## 5. 家长操作

进度卡显示样本量，例如「最近 5 次独立练习，4 次首次答对」，不能只给无解释的百分比。无记录时显示下一步，不画零分曲线。

导入预览列出文件版本、导出时间、记录总数、当前课变化和覆盖范围；确认按钮为「替换家庭学习记录」。预览后其他设备写入导致版本不一致时，提示重新预览。删除确认说明会影响所有已配对设备；取消无副作用。

## 6. 真实跨端验收矩阵

正式发布前登记真实型号、系统、浏览器版本、屏幕尺寸、证书信任方式、日期与结果。视口模拟不等同真机验证。

| 环境               | 自动化覆盖                      | 必须真实验收的内容                         | 必做输入             |
| ------------------ | ------------------------------- | ------------------------------------------ | -------------------- |
| Mac 桌面 Safari    | Playwright WebKit 近似覆盖      | HTTPS 信任、标准音解码、跨页播放释放       | 鼠标、完整键盘       |
| Mac/Windows Chrome | Playwright Chromium             | Mac LAN 访问、配对恢复、音频播放、导入导出 | 鼠标、完整键盘       |
| Windows Edge       | Chromium 近似覆盖               | 实际浏览器配对与下载备份                   | 鼠标、键盘           |
| 桌面 Firefox       | Playwright Firefox              | 标准音解码与资源释放                       | 鼠标、键盘           |
| iPad Safari        | 平板 viewport/WebKit 近似覆盖   | 竖横屏、触摸、软键盘、证书信任、音频播放   | 触摸、外接键盘       |
| iPhone Safari      | 手机 viewport/WebKit 近似覆盖   | 安全区、窄屏、耳机/扬声器、下载/导入文件   | 触摸、VoiceOver 抽查 |
| Android Chrome     | 手机 viewport/Chromium 近似覆盖 | 音频播放、文件选择器、横屏                 | 触摸、TalkBack 抽查  |

所有行必须完成：配对 → 选课 → 四类客观题 → 退出重进恢复 → 从另一设备看到进度。断开 Mac 的互联网但保留 LAN 后重复练习与保存；最后断开 LAN 或停 Mac，验证无假成功、重连后可恢复。
