# 产品方案：一年级拼音练习 App

状态：2026-10-05 按实际可用产品重新收敛；以真实服务、真实音频和儿童独立操作验收。产品工作名「爱拼音」。面向中国大陆小学一年级学生及陪伴学习的家长。本文的会话长度、掌握阈值与复习间隔均为可验证的产品初始假设，不是教育科研结论，也不承诺学习效果。

## 1. 目标、证据与范围

本期交付可在家庭 Mac Studio 实际运行的网页产品：安装与启动、14课学习、语音引导、客观游戏、跨设备进度、家长备份恢复形成完整闭环。测试替身只验证边界，不能作为任何功能已可用的唯一证据。已存在的真实存储与接口保留，按 [重审方案](../product/reimplementation-review.md) 修复缺口。

产品目标：帮助儿童按学校正在学习的课程练习拼音的音、形、调与拼读；用短会话、可重复听和明确反馈支持专注学习；让家长知道学过什么、什么需要继续练。

课程依据、教材版本、课序和知识点范围以仓库课程研究及内容数据为准。学校实际教学时间可有差异，因此不绑定「开学第几周」。首次由家长选择教材版本和当前课，此后可随学校进度调整。默认教材映射仅是首个受支持的内容版本，不宣称覆盖所有地区、教材或学校。

成功标准首先是可用性与内容正确性：标准音来源可追溯、课程及知识点完整映射、同一项任务可由键盘/鼠标/触摸完成、无网时明确说明可用范围、进度能恢复和删除。学习效果需要后续教师与家庭小规模试用验证，不能由产品规则推断。

本期不做：发音评测、浏览器录音与上传、外部账号/第三方云同步、学校管理后台、广告、付费、好友/排行榜、无限刷题奖励、AI 自由聊天、生成式讲解、Android/iOS 打包发布。学习以标准示范音播放、听辨选择、拼读、字形和声调等客观练习为主；首版没有录音和发音分数。未来是否加入发音评测需重新立项并验证模型、隐私、教师审校与真机表现。

系统采用 B/S 架构：React + TypeScript 浏览器端；Mac 上 FastAPI + SQLite 保存进度和提供本地课程资源。电脑、iPad、手机通过配对后的会话访问同一个家庭档案，无外部注册登录。本文「离线」专指 Mac 与浏览器仍处于同一局域网，但没有互联网；Mac 停机或局域网断开时不能保存新学习记录，须明确提示服务不可用。

## 2. 用户和核心场景

| 用户       | 目标                   | 产品支持                                                         |
| ---------- | ---------------------- | ---------------------------------------------------------------- |
| 一年级儿童 | 听清、看懂、知道下一步 | 一屏一任务；标准音可重复播放；图形与文字配合；无阅读能力前置要求 |
| 家长       | 与学校同步、看出薄弱点 | 选择当前课；查看知识点及练习类型；手动复习；本地备份             |

主流程：家长初设 → 儿童首页「今天练什么」→ 选择当前课学习或到期复习 → 标准音/口形说明 → 4–6 题练习 → 温和反馈 → 本次小结 → 回首页或结束。

默认一次安排 6 题，目标约 5–8 分钟，仅作为设计目标；无倒计时，允许随时结束，最多连续两轮后主动显示休息页且默认焦点为「结束学习」。儿童可以继续，但不能靠连续天数、失去奖励等机制施压。

## 4. 教学与内容策略

将「跟课学习」和「巩固复习」分开呈现。课程地图可以提前浏览，当前课以前的内容可复习，超过当前课的内容需家长明确选择后才加入自动推荐。家长更改当前课只是修改推荐范围；不能撤销已学记录。

每个知识点包括稳定 ID、所在课程、类型、标准呈现、必要规则、容易混淆项、学习目标、可用练习模式、题目与音频引用。课程所包含的知识点不等同于教学周数。汉字/图示只提供辅助语境，不把儿童认字能力当作拼音掌握度。

字母呼读音、音素本音、完整音节及词语的录音必须有明确标签，不得同一个音频文件混用。音节拆分与声调展示必须遵循内容规则；不通过机械拼接辅音/韵母音频合成目标标准音。声调涉及变调、轻声或语境时，题目必须明确是单字调值还是词语自然读音。拼音显示使用 Unicode 规范化文本并保留有调/无调形式，不依赖儿童输入组合键。

每道题只定义一个 `primaryKnowledgeId` 用于计分，其余作为辅助知识点。提示文字与正确答案均来自版本化内容；不得运行时让大模型生成答案。标准音文件缺失或损坏时不提供对应听辨题，不以文字题替代声音。

## 5. 练习与游戏

| 模式                 | 玩法与输入                                                                             | 教学目标                       | 防止能力混淆                                                   |
| -------------------- | -------------------------------------------------------------------------------------- | ------------------------------ | -------------------------------------------------------------- |
| 听辨 `listen-choice` | 听标准音，从 2–4 张拼音卡选一张；显式「再听一次」                                      | 声音与书面形式对应             | 不要求识字；目标文本不在视觉提示中提前揭晓                     |
| 声调 `tone-choice`   | 有 audioRef 时听音选调；无 audioRef 时根据规则选标调形式                               | 分别训练声调听辨或视觉标调规则 | 视觉题不能算作声调听辨证据；可重复听、不按反应时间计分         |
| 拼读 `blend-choice`  | 按音节结构逐格点选或试选合法完整候选、预览、撤销和确认；有整音资源时再听完整标准音验证 | 分解/合成与拼写规则            | 当前种子题可只做视觉拼读；正式发布补整音验证，禁止机械拼接音频 |
| 字形 `symbol-choice` | 找同形、辨易混字母、按示范选择正确构件                                                 | 识别拼音字形                   | 无精细拖拽要求；描红轨迹只作可选练习，不进入掌握度             |

游戏视觉可采用原创「拼音花园」：完成会话为一个小花盆加一片叶子。成长只表达完成，不绑定付费、不衰减、不产生失败损失。不以动画时长作为奖励门槛；反馈动画可跳过且遵循系统减弱动画设置。

本期不采集麦克风、不上传语音、不进行发音评分。需要听觉刺激的客观题使用登记的cmguo/PinYinSound标准音；资源缺失时显示待准备状态，不使用系统 TTS 替代。

练习模式不对所有知识点一概适用。每个知识点的 `requiredModes` 必须由内容包明确配置，只允许四种客观题模式并能生成足够合法题目。单个字母可能要求听辨和字形，拼读知识点可要求拼读及声调；不强行给每个知识点套全部游戏。朗读目标目前只是未来内容研究清单，不进入首版课程练习与掌握度计算。

题目还需区分刺激来源：有 audioRef 的听觉任务与无 audioRef 的视觉规则任务。`tone-choice` 的视觉标调题只能证明应用中的标调规则练习结果，不能宣称儿童已会声调听辨。当前种子题库的视觉题可用于开发；正式发布的声调听辨覆盖和拼读整音验证须经扩库与音频播放验证，未补齐前保持发布阻塞。

## 6. 掌握度规则 v1

这些参数是便于实现、解释和测试的产品假设，根据家庭试用结果再调；变更必须修改规则版本并提供迁移。

### 6.1 事件与有效计分

1. 每次展示生成稳定的题实例 ID；首次选择、提交组合或主动揭晓时提交一次 `Attempt`。同一实例重复提交幂等。音频尚未准备好时不可提交听辨答案。
2. `firstTryCorrect = true` 当且仅当第一次提交就是正确答案，并且此前没有使用内容提示或揭晓。重复播放标准音不算提示。
3. 使用提示后首次选择正确，或首次答错后改对，均保留首次未独立答对的结果。首次答错立即生成计分事件；后续修正是反馈行为，不再添加一次掌握度事件。提示后离开且未提交不生成事件；主动揭晓生成未独立答对事件。
4. 跳过、页面关闭、仅播放音频和被取消的题目不计分。未做的题不等同于错误。
5. 对同一知识点、同一题目模板/题目 ID、北京时间自然日，仅首个完成事件进入掌握度窗口；再次练习仍可显示反馈和本次完成数。不能通过连续反复同一题快速刷满掌握度。
6. `occurredAt` 由 Mac 接收事件时生成；按该时间升序、相同时间再按事件 ID 字典序排列；保存 UTC 时间，所有日期判断使用 `Asia/Shanghai`。引擎显式注入 `now`，不信任各浏览器设备时间。服务器对并发会话先原子记录事件，再重算状态。

### 6.2 状态计算

取某知识点最近最多 8 条有效计分事件作为窗口 W。状态分别为：

- 未开始：没有有效事件。
- 练习中：有有效事件，但未满足下列全部条件。
- 已掌握：`|W| >= 5`，`正确条数 / |W| >= 0.8`，最近 2 条均独立首次正确，且每个客观必需题型在 W 内至少有 1 条独立首次正确。首版课程不包含 `read-aloud` 模式。

比较使用整数 `正确条数 × 5 >= |W| × 4`，不使用舍入后的百分数。objectiveRequiredModes 集合为空属于内容校验失败。内容包修改模式集合必须通过内容迁移，不隐式改变已发布历史规则。

例：5 题中 4 题独立正确且最近 2 题正确、覆盖要求模式，可以已掌握；8 题中 6 题正确仍在练习；8 题中 7 题正确但最近一次错误，也在练习。页面可以显示整数百分比供理解，判定必须使用原始整数。

「待复习」是到期标记，不是第四种掌握状态。历史上掌握但最近窗口不满足条件的知识点会回到「练习中」，用「再练一练」表示，不出现降级惩罚。指标不是考试成绩或能力诊断。

### 6.3 复习计划

- 首次达到掌握，记录阶段 `0`，到期日为本次业务日 + 1 天。
- 到期复习按知识点安排 2 道不同题目，均需属于当天尚未计分的题目；每题都有唯一实例和主知识点。两道均独立首次正确才算通过；跳过/中途退出不形成复习完成事件，原到期日不变。
- 通过：阶段加一，上限为 `3`；以完成日为基准，阶段 `1/2/3` 的下一间隔分别为 `3/7/14` 天，后续保持 14 天。若复习两题使掌握条件不成立，按失败处理。
- 失败：阶段重置为 `0`，次日到期。不会要求当天无限重做。一个知识点一天最多完成一次推进计划的到期复习。
- 提前主动练习仍更新掌握窗口，但不推迟已经安排的到期日。窗口从掌握变为练习中时，推荐再次练习；如果此前无复习计划，重新达到掌握才建立计划。
- 当天已计分题不足以形成 2 道新题，显示「今天这部分已经练过了」并保留计划；不在运行时生成新题。内容发布校验需保证每个可复习知识点至少有 2 道合法独立题。
- 自动推荐：当前课及以前，先取逾期天数最多的知识点，再按课程顺序、知识点 ID 排序；最多 3 个知识点、每点 2 题，共 6 题。未到期时推荐当前课中未开始/练习中的知识点。家长仍可自行选课。
- 会话开始时冻结本次任务清单、内容版本和业务日；跨午夜时不改变当前题。完成时间决定下一到期日，单题去重仍用各自发生时的业务日。

Mac 系统时间回退超过 5 分钟时暂停复习计划推进并提示家长检查服务器时间；允许练习，但标记新记录为待校时、不进入掌握计算。恢复合理时间后不自动改写时间戳，由家长选择丢弃待校时练习记录或保留为不计分练习。该规则只避免偶发时钟错误，不用于反作弊。

## 7. 家长与家庭服务器数据

新设备由 Mac 上家长管理入口提供一次性配对码，配对后得到局域网应用会话，不需要外部账号。配对码有效期 5 分钟、成功使用后作废，连续错误 5 次后该入口冷却 1 分钟。服务器限流及会话保护以安全实现文档为准。可在 Mac 管理页撤销设备。儿童区进入家长查看页有可读的成人确认步骤，仅防误触；删除、导入、配对与撤销设备需要真正的家长管理授权，不把成人确认当作权限校验。

Mac 的 SQLite 仅保存匿名家庭档案：教材/内容版本、当前课、设置、客观题事件、会话与复习记录。默认不采集姓名、学校、年龄、位置、联系人、照片或语音；无第三方分析埋点。首版不请求麦克风，也没有语音上传接口。

导出是由 Mac 生成的带 `schemaVersion`、`contentVersion`、导出时间及数据校验信息的 JSON 文件，包含学习记录但不含录音、音频二进制、配对令牌和网络密钥。导入仅支持「全量替换」，先校验、显示记录数量和当前课差异，家长确认后一次 SQLite 事务替换。禁止静默合并或部分导入。格式/版本/引用/大小不合法时保持原数据完全不变。导入失败、磁盘不足或中断均可恢复到旧数据。预览返回绑定文件摘要和数据版本的短时令牌；确认时版本已变化则重新预览，避免覆盖另一设备刚产生的记录。

删除分成两个明确入口：「删除学习记录」删除所有设备共享的客观练习数据，保留公共课包、配对及设置；「重置家庭档案」再删除设置并撤销所有浏览器配对会话。分别列出影响并需二次确认。删除服务器记录不能替用户撤销已经下载的备份文件，应在确认页简短说明。浏览器清理站点数据只会退出设备会话，不清除 Mac 上的学习记录；Mac 磁盘故障仍可丢失数据，因此提供手动备份，不承诺永不丢失。

## 8. 状态与异常

| 对象     | 必须覆盖的状态                                             | 恢复方式                                                 |
| -------- | ---------------------------------------------------------- | -------------------------------------------------------- |
| 应用     | 初次打开、加载、就绪、更新可用、数据迁移、迁移失败         | 更新延至会话结束；迁移前保留可下载旧数据                 |
| 课包     | Mac 未安装、安装中、可用、部分失败、校验失败、版本不兼容   | 管理入口支持重试/取消；文件及清单校验通过才原子切换      |
| 音频     | 待手势、加载、播放、暂停/结束、网络失败、解码失败          | 显式播放与重试；单播放器；失败不提交计分                 |
| 题目     | 准备、可答、提示、首次反馈、修正、已完成、已跳过           | 答错提示再试；切题先停音；计分幂等                       |
| 数据库   | 可用、写入失败、磁盘不足、版本迁移、数据损坏               | 明确未保存；暂停新提交并提供重试/管理入口；旧数据不覆盖  |
| 网络     | 互联网及局域网正常、互联网断但局域网正常、Mac/局域网不可达 | 第二种正常学习；第三种显示服务不可用，不伪称保存成功     |
| 内容引用 | 稳定、删除/替换、当前包不认识历史 ID                       | 通过迁移表解释；无法映射的历史保留为只读，不伪造对应关系 |

服务器事务提交成功后才提示「已保存」。网络断开导致响应不确定时保留相同请求 ID，重连后查询/重试该请求，禁止生成新 ID 重算一次。刷新从 Mac 恢复到下一未完成题或上一题反馈页，不重发计分事件。用户可放弃未完成会话，已完成的学习事件保留。并行设备可各有一场会话，但事件由服务器统一计分；相同知识点/题目/业务日的去重键在数据库唯一约束中落实。

## 9. 验收和发布边界

必须满足每个 P0 需求及 [跨端验收矩阵](UX.md)。发布包需要内容校验、实际声音验证及真实 iPad/iPhone 浏览器测试；自动化浏览器模拟不能代替真实设备验证。发音评测不属于首版验收范围。

后续试用应由成年人组织并先完成适用的隐私与同意流程。试用观察任务理解、误触、无法退出、音频听清度以及会话长度；不默认记录儿童音视频或上传点击流水。隐私实施和适用法律的来源及结论以工程隐私文档为准。

## 2026-10-05 语音优先要求

儿童不需要认识题干汉字。所有客观题提供中文语音引导，大号拼音/图示呈现待判断目标，汉字选项有独立听读按钮，听读不能提交答案。中文引导可由 Mac 本地预生成，客户端只播放同源文件；禁止把拼音字母直接交给中文/英语 TTS 冒充示范。拼音示范必须使用实际语音素材并区分呼读、本音、整音。首次开始动作开启声音，浏览器阻止播放时出现大号重播按钮；切题/跳页/隐藏页面停止旧音。

家庭用户自行提供的课程录音可以存放私有目录并通过已配对 API 使用，不要求先公开再分发许可才允许家庭自用。它与PinYinSound逐目标标准音不同，界面和资源元数据必须保留该区别；MIT 仓库不包含这些录音。外部素材再分发许可由维护者单独记录，家庭使用不要求审核或签名。
