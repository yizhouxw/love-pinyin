# 2026-10-05 产品重审与重新实施

用户要的是家庭中可直接使用的拼音学习产品。目标用户刚开始上一年级，读汉字不能成为读懂题目的前提。首版继续不含发音评测。

## 审计结论

现有 FastAPI、SQLite、配对、幂等作答、恢复、家长数据操作是真实实现，不能把它们误称为 mock。大量浏览器测试使用模拟 API 和 Audio，掩盖的是完整产品链路尚未接通：

| 问题                       | 当前证据                                                 | 修正及验收                                                             |
| -------------------------- | -------------------------------------------------------- | ---------------------------------------------------------------------- |
| 文档目标停留在方案和基线   | PRD/实施计划仍将实际产品放到下一阶段                     | 本期目标改为真实家庭使用，验收按功能而非测试数量                       |
| 儿童必须读汉字             | App 题干/选项/提示/反馈主要是文字；promptAudioRef 未播放 | 全部117道客观题配中文语音，大字视觉目标；汉字选项单独听读              |

## 实施次序与交付物

1. 更新 PRD、ADR-0005、SPEC-003/004/006 和开发规则，使本期可运行产品与语音优先成为唯一现行目标。
2. content/narration.json 覆盖全部客观题及中文选项，拼音作为大号视觉目标；普通话合成不得直接读拉丁拼音。内容校验锁定覆盖与引用。
3. 实现私有资源准备、固定ID配对API、摘要/Range与真实中文音频制作；导入用户已有13份课程录音。所有文件留在 private/。
4. 界面接入听题、听中文选项、提示/反馈语音、课程录音和单播放器停止行为，家长可下载备份。停止把未实现的能力隐藏在纯文字或mock后面。
5. 连接真实服务、真实SQLite与真实语音文件跑完整浏览器用例，包含中文朗读成功/失败、独立听读不提交答案、作答和下载恢复；保留mock仅用于边界注入。
6. 继续补准确单音、可玩的听辨/拼读和题库数量；完成家庭实际设备的音频、触摸、LAN与无WAN验收。内容/资产有真实证据再签核，不自行伪造教师或声音授权。

## 完成定义

- 14课均能按学校进度先听课程、再进入至少6道可听懂的不同练习；每个知识点的复习题数和题型覆盖满足原规则。
- 儿童不需家长代读题干或选项；进入一轮后有听题/重复/跳过/提示/纠正/小结/休息完整声音与图形引导。
- 实际听辨依赖正确目标音，准确性未核对不能用ASR结果或合成英文字母代替。
- 使用真实家庭Mac和真实音频完成电脑、iPad、手机流程，断互联网仍工作；停Mac时正确报错并可恢复。
- 家长能选课、配对/撤销设备、查看进度、下载/恢复备份、删除记录，重启仍保留进度。
- 代码MIT且可复现；私有素材不入Git，公开音频、教师审校与设备证据各自可核对。

本次重新实施不推倒已有效的存储层，不把纯测试替身当成产品依赖。每项状态以真实功能和运行证据为准，尚未达到的项持续实施，不以“开发预览”替代用户要求的交付。
