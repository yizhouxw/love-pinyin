# 产品重审与整改结论

2026-10-05开始的重审将目标从开发基线改为真实家庭产品：一年级初学儿童必须能听懂题目，首版无发音评测。本文按当前实现维护整改结论；当时的详细问题与阶段题量可从Git历史查看。

| 原问题                        | 当前整改                                              | 尚需验证                    |
| ----------------------------- | ----------------------------------------------------- | --------------------------- |
| 文字题依赖识字、语音仅有引用  | 全部客观题、汉字选项、提示/反馈和导航接入本机中文声音 | 儿童实际能否听懂            |
| 模拟Audio/API掩盖声音链路缺口 | 标准音、中文声音、课程录音各自有真实文件/API及GUI验收 | 移动真机及家庭网络          |
| 旧13课录音与新14课不一致      | 显式映射，第2/9课共用旧录音，注明旧页码边界           | 家长试用说明是否清楚        |
| 听辨缺资源、题库不足          | 固定PinYinSound目标映射和题库覆盖已通过发布检查       | 数量不能证明教学效果        |
| 错答后不能再试、拼读直接判分  | 提示/讲解/修正、试选/撤销/确认完成；首次结果不改写    | 真机触摸与全键盘            |
| 导出仅有文本框                | 下载JSON、原生文件选择、预览恢复已有Chrome/Safari证据 | 移动文件选择器              |
| 部署步骤分散                  | 一次资源准备、npm start、LAN预检、备份/恢复工具与文档 | 可信家庭HTTPS、系统生命周期 |

FastAPI/SQLite、配对和幂等进度是真实实现；测试替身保留用于故障和布局边界，不作为实际产品链路的唯一证明。标准音按[ADR-0008](../adr/0008-trusted-standard-audio.md)直接信任cmguo/PinYinSound，不设教师或审音审批。家庭私有素材与公开再分发许可分开处理。

## 完成定义仍然适用

14课各可完成至少一轮六道不同练习，每知识点题量与题型满足规则；每题可听、可重听、可提示/跳过/纠正，网络或声音失败不计孩子错误。家长可选课、管理设备、查看记录、备份恢复与删除，重启后数据可用。

最终需真实Mac、桌面、iPad和手机在家庭网络上完成学习，断WAN可用、停Mac明确失败并能恢复；不能把视口模拟或localhost结果扩展为真机交付。代码MIT、可复现，私有素材不入Git。当前证据及剩余门禁统一见[状态表](../STATUS.md)与[交付核对](../engineering/delivery-audit.md)。
