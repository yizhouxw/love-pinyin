# 本阶段交付与真实状态

日期：2026-09-26。当前交付含方案、研究、内容基础、开发环境和本机 B/S 学习流程；它仍是未完成发布门禁的开发预览。

## 当前实现增量（2026-09-25 至 2026-09-26）

现在已有可运行的本机 B/S 学习流程，状态是**开发预览/家长陪伴草稿**，不可作为已审校儿童产品：

- FastAPI 同源站点、首次家长配对和后续一次性设备配对；HttpOnly 会话 Cookie、CSRF/Origin 校验、失败限流和配对撤销。
- SQLite 家庭档案、迁移表、题目实例、会话、客观作答、请求收据和复习计划；答案由服务端判定、重复提交幂等、上海业务日去重。schema 建表、增列与版本登记现以单一事务完成，故障注入验证迁移回滚保留旧库。数据库目录权限设为仅当前用户。
- 配对页、课程路线、短时视觉选择练习、提示、服务器掌握度/进度、会话刷新恢复；家长可选当前课、导出 JSON、删除练习记录和退出设备。
- LAN 启动要求调用者显式提供 HTTPS 证书。网页不请求麦克风；音频播放题过滤为不可用，评分 API 只返回不可用且不读取录音请求体。
- 当前服务端可出的题只覆盖无需标准音频的视觉选择题。对需要 `listen-choice` 覆盖的知识点，掌握度会保持未完成，不因音频缺失降低门槛。
- 练习支持持久化跳过并在刷新后恢复；跳过不成为客观作答或掌握事件。完成小结分别列独立答对、提示后答对和跳过，家长 JSON 导出带会话及跳过记录。
- 课程地图现在按内容包的知识点映射呈现服务端掌握状态；到期复习作为独立标记显示，不另写前端掌握算法。
- 课程卡可浏览内容包里的规范拼音符号、分组、进度和折叠家长提示；标准音入口明确标记待准备。当前课之后允许预览，但练习入口保持禁用，直到家长调整当前课。
- 若旧家庭档案所选课程 ID 已不在当前课程包中，首页提示家长重选，路线保留浏览，练习/复习接口以 409 拒绝创建会话；重新选课前不回退首课或丢弃历史记录。
- 家长页列出已配对设备的标签和日期，并可二次确认撤销次设备；撤销后其会话失效，下次访问会回到配对界面。
- 拼读组合题单独提示选择题库中的完整音节候选，并为候选卡提供键盘/触摸选择；标准示范音缺失时说明当前仅做视觉拼读。
- 配对后的课程目录与会话题目不再包含标准答案或提示内容；服务器只在孩子提交选项或请求提示后返回对应结果。
- 连续完成两轮完整会话后由 Mac Studio 持久化休息门槛，后端拒绝继续开新会话；休息页可结束或休息后继续，没有强制计时。家长减少动态效果开关已持久化，页面同时尊重系统减少动态效果设置。
- 作答请求在当前标签页保存短期幂等键；网络结果不确定时重试沿用原选项与请求号，重载时先按服务端当前会话恢复并重放同一请求。拒绝把未确认提交误作答错或另生成计分事件。
- 首页已加入原创拼音花园：每个完整答完/跳过的会话增加一片叶子，服务端从会话、作答和跳过记录计算总数，家庭多设备一致；提前结束不增长，删除学习记录后归零，备份恢复由会话重建。E2E 检查了 320 CSS px 与花园文字放大 200% 的横向布局。
- 三种视觉题型现有各自的答题卡呈现：字形卡显示四线格，声调卡显示由调号识别出的调型线，拼读卡从课程声母清单切分完整合法候选；正确答案仍由服务端以原 option ID 判定。单测覆盖 zh、ü、四声和无法安全拆分的内容。
- 家长导出升级为版本化 schema v4，包含严格字段白名单的已完成练习实例、复习会话标记、减少动态效果偏好和休息轮次；导入预览限制 1 MiB/50,000 次作答并校验版本、引用和事件一致性，显式迁移 schema v2/v3 备份；服务端确认 API 绑定文件 SHA-256 与家庭 revision，在单 SQLite 事务中整体替换并回滚故障。家长页已接入文件选择、预览计数、输入确认词后替换。
- 到期复习现有独立两题会话 API 与孩子端入口：仅取当前课程范围内不同、当日未获得复习 credit 的客观题；两题独立首答正确且掌握仍成立才推进 3/7/14 日阶段，完整两题但失败则次日重试，跳过/不完整不改计划。同一知识点同一北京时间日期最多推进一次；没有两道合适题时明确拒绝开场。
- 进度与复习的自然日现在统一经带时区的 `business_date()` 转为 Asia/Shanghai 日期，锁定 UTC 跨北京时间午夜以及拒绝无时区输入的回归。
- 家长页将“删除学习记录”与“重置家庭档案”分开：前者删除练习/会话/复习/评分摘要但保留设置与设备；后者重置设置、撤销全部设备、清除未用配对码并使当前浏览器退出。两个动作均有二次确认，已下载备份不能由 Mac 远程抹除。
- Mac 运维新增 SQLite online backup 命令：完成快照后校验完整性和迁移表，原子保存到权限为 0700/0600 的备份目录并滚动保留 7 份；恢复步骤和升级前备份指引已补入部署文档。尚未安装定时 LaunchAgent 或完成真实恢复演练。
- `serve:lan` 启动器现要求选择 Mac 当前已分配的 LAN IPv4、HTTPS 证书和私钥，只绑定指定接口；不会像 `0.0.0.0` 那样监听所有网卡。用临时证书/数据库在 Mac 的 `192.168.1.2:18443` 实际启动并确认网页和 health 均返回 200，`lsof` 证实只有该地址监听，随后正常停止和清理。尚需维护者准备受信任证书并验证其他家庭设备、路由/防火墙及 iPad 信任链。

2026-09-26 本地 UI 手动验收（临时 SQLite 数据目录，完成后已在 UI 删除记录）：首次家长配对、视觉题作答/提示、作答后刷新恢复、家长切课、导出、记录删除、另一浏览器来源的次设备配对、权限边界、次设备撤销，以及次设备刷新后看到新课序和家长删除后的 0 条记录均已走通。首次配对的 `ORIGIN_REJECTED` 已通过 Vite 代理显式传递原始 Host 修复；家长导出曾遇到 `CSRF_HEADER_MISSING`，现只读 GET 用配对家长身份校验、写操作仍验证 CSRF。触摸视口以 390×844 响应式模拟检查并从该视口用 Enter 键完成一题；没有实际 iPad/iPhone 触屏硬件证据。

本轮通过 `npm run verify`、`npm run verify:server`、`npm run test:e2e:local`：前端内容/单测/构建通过，5 个隔离临时 SQLite API 测试通过，5 个 Chromium/WebKit 桌面/平板/手机模拟项目、10 个 E2E 场景通过。E2E 用 API mock 验证配对、课程知识卡（包括 ü 字形和禁用未就绪音频）、后续课程预览、拼读完整候选的键盘/触摸选择、作答/跳过小结、掌握/复习状态、设备撤销及过期会话回配对页；真实 SQLite 跳过/恢复、导出与设备权限另由 API 用例验证。尚未做家庭真机 HTTPS/断网验收。PoC 基准工具尚无真实样本、预测或授权证据。实现切片尚未标记 SPEC 全部验收完成。近期提交均仅在本地，未推送。

最重要的可行性风险是儿童拼音本地评分，不能承诺靠一个现成开源包即可解决。较低成本模型可以直接按SPEC完成确定的软件切片；教师审校、声音授权、真实样本与评分研究需要相应外部交付。本阶段已把这些依赖放到最前面，而没有掩盖成“后期接个API”。

2026-09-26 评分数据源补充核验发现 UY/CH-CHILD（4–8 岁维吾尔族中文二语儿童、音节/声调与拼音标注）是值得申请研究许可的候选，但论文未提供可商用/再分发许可文本，数据页本轮访问超时；它也不能代表目标普通话母语一年级儿童。因此未下载或纳入开发。UY/CH-CHILD-MA 论文称将在发表后公开数据，当前同样未核验许可和实际下载。详情与来源见[PoC状态记录](research/assessment-poc-status.md)。这没有改变评分门禁：目标人群持权录音、冻结校准证据仍未取得。

本轮另核验 SingaKids-Mandarin（有音素/声调/熟练度标注但多语新加坡儿童，数据许可不明）、Sinica Phonological Development（台湾儿童、自动音素处理和音节边界核验，许可不明）及 ELRA Chinese Kids Speech Lower Grade（6–10 岁普通话儿童、只有汉字转写、需按用途授权）。这些只增加了外部探索/询证候选，没有一项可直接充当大陆一年级儿童拼音评分金标准；未联系、购买或下载。详见 PoC 状态记录与 SPEC-000 语料使用边界。

评分基准报告现在按内容包的每个 `targetId` 单独提供指标和说话人聚类区间，避免具体拼音目标的问题被目标类别平均掩盖；报告仍只含聚合统计，不暴露样本/说话人标识。新增回归验证覆盖该维度；这改善了研究工具，未改变没有授权儿童样本、校准分数及教师签核的阻塞状态。

PoC 数据 schema 与评测器 v0.4.0 已补过短录音和近邻易混挑战类别；报告分别呈现挑战类型及过短录音拒判率。SPEC 未经教学/研究签核的阈值保持原样。测试仅验证元数据/统计边界，不代表语音判别有效；合法样本与评分引擎仍未取得。

PoC 报告还会明确列出 held-out 目标年龄儿童测试集的条件覆盖；清楚正确、音素/声调错误、静音、过短、噪声、回放或近邻易混任一缺失都不能通过覆盖门禁。该检查防止用空子组指标误读成“达标”，不能替代最小样本量和教师裁决。

PoC 执行现在要求显式提供本机授权登记：每个匿名 `consentRef` 必须对应同数据集、同人群、批准的留存研究用途、未过期且含证据文件 SHA-256 的记录；输出仅含登记摘要和计数，不含引用。此验证只能防止明显缺项，人工仍须复核受控保存的实际同意与授权文件。
