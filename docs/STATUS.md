# 当前产品状态

更新：2026-10-05。当前目标是可供一年级儿童实际使用的家庭产品，不能依靠孩子识汉字读题。首版不录音、不做发音评测；旧评分研究仅作历史资料。本文件记录当前状态，历史实现过程可查 Git 和各 SPEC。

## 本次已实现

- 真实 B/S：Mac Studio 的 FastAPI/SQLite 提供课程、家庭配对、会话、服务端判题、进度、复习、设备撤销、导出/恢复。生产页面没有模拟 API 或内置假成绩。
- 语音读题：全部173道客观题有中文题干及逐题提示脚本，23个中文选项可单独听读，13个界面引导包含提示、反馈、小结、休息。当前可出的112道视觉练习已接入实际语音；剩余61道听辨题还需准确单音，不能把脚本数量写成可玩题数。
- 本机审音台已导入13份源音与427段候选，可试听原音、按PCM帧裁切、保存草稿；两人明确核对后才启用家庭标准音。撤下、摘要/目标变化会停止提供；当前真实标准音仍为0个启用，不由ASR代签。入口`npm run audio:review`。
- 本机已准备382个中文语音ID、14课录音映射。清单引用126份去重WAV和用户提供的13份MP3，共约126.73MB。资源只保存在忽略的 `private/learning-audio/`，保留来源和摘要；未提交原音、模型或数据库。
- 中文指令由已安装的 Mac Tingting 音色生成，不合成拉丁拼音充当示范。用户13份旧课程录音映射新版14课，第2/9课共用合课录音；页面说明旧课序和页码，长录音可暂停、续播和定位。
- 每题有听题按钮，首次开始后自动读下一题；中文字选项独立听读，不等于选择答案。拼音视觉目标置于题干上方，与“看看上面”的朗读一致。未听完题目、缺音或播放失败时不接受作答；可重试、提示、跳过、退出。离页/隐藏停止声音。
- 普通练习已移除固定前6题：未做过的题优先，已作答/跳过次数少的优先；未操作题不会因为进入过会话而被当作已练。跳过仍不计分。
- 错答后可以再选一次找到正确卡片，只改善反馈，不再次提交或改写首次结果；不会因修正增加掌握事件。
- 家长导出会实际下载JSON，恢复后界面设置和服务器记录同步；不再仅提供文本框。
- `npm run prepare:voice -- --source '音频目录'` 显式准备语音，之后 `npm start` 构建、复用声音并启动同源服务。资源不完整会如实显示，不会联网补声音。

当前对应 SPEC-002 BANK-01、SPEC-004 SELECTION-01、SPEC-003 VOICE-01–06、REVIEW-01–05、SPEC-004 HINT-VOICE-01、CORRECTION-01、SPEC-005 R-012-GUI-01。方案重审与完成标准见[产品重审](product/reimplementation-review.md)，决策见[ADR-0005](adr/0005-voice-first-product.md)。

## 仍须完成，不能称最终产品已验收

1. **准确单音与听辨**：现有174项公开录制要求（89项标准发音、85项指令）尚未完成。整课可播放不代表孤立标准音已剪切、映射和审校，61道听辨题保持未开放；标准音服务已按实际资源状态决定准入，不再永久过滤听辨。
2. **课程与题量**：现有14课、83知识项、201题（173客观、28朗读）。可用视觉题每课数量为10、9、8、8、9、9、6、6、9、9、9、7、6、7，每课至少6题已补齐。仍有21个知识点少于2道客观主目标题、79个少于5道；不能靠重复同题或降低掌握标准填补。
3. **教学核对**：教材课序、最新课标原文差异、拼音字形和发音还需有记录的教师/审音核对；本轮没有代签。
4. **家庭设备**：Mac本机桌面流程有证据，iPad、iPhone、Android真机触摸/声音、可信HTTPS与局域网断公网仍待现场验收。WebKit与视口模拟不等于真机。
5. **公开发行**：代码采用MIT；系统声音生成文件与用户课程录音不随代码发布。家庭可用资源和可公开发行资源分别管理。

本次没有新增第三方依赖，没有上传录音、推送仓库、发布站点或安装根证书。后续按[实施计划](implementation-plan.md)持续关闭上述缺口，不把工程测试全绿当作最终产品交付。
