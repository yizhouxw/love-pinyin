# 当前产品状态

更新：2026-10-05。当前目标是供一年级儿童和家长实际使用的家庭B/S产品。首版不录音、不做发音评测，所有客观题有中文语音。标准音直接信任cmguo/PinYinSound，机制见[ADR-0008](adr/0008-trusted-standard-audio.md)。历史切片结果见Git及各SPEC。

## 已实现

- Mac Studio的FastAPI/SQLite提供课程、配对、会话、判题、进度、复习、设备管理及实际JSON下载/恢复。没有模拟成绩或生产mock API。
- 14课、83知识项、476题，其中448客观题可用（220道不依赖标准音的视觉题、228道需要标准音的练习），28道未来朗读题不进入首版。全部客观题有中文题干、提示与答后讲解；67个中文或图片选项说明、15个界面引导、157个书写引导及14个图片卡/故障引导合计1149个中文语音ID。
- 标准音唯一来源cmguo/PinYinSound：固定提交、205个目标映射，183个去重MP3共2278818字节。安装后通过本机家庭/访客API播放，摘要、路径和映射校验保留。用户无需审音或审核确认。
- 删除审音台、两人签名/启用流程、待审状态、多来源审核回退、儿童草稿横幅及家长审校说明。产品用户只有学生和家长；审核不再是软件发布门槛。
- 课程schemaVersion 2.0.0、内容版本2026.10.05.6移除审核字段；2026.10.05.7新增四声听辨题，2026.10.05.8新增42道声母听辨题，2026.10.05.9新增48道韵母听辨题，2026.10.05.10新增32道整体认读听辨题，2026.10.05.11新增40道规则练习。旧冻结题单和家庭备份继续读取，旧审核字段不影响恢复、题目或计分，原文件不删除。
- 本机中文指令由已安装Tingting生成，377份去重WAV；用户13份课程MP3映射14课，第2/9课共用合课录音。中文TTS不合成拼音，长课程录音不替代单音。
- 题目、中文选项、提示、讲解均可停止/重听；声音失败可重试，不计错。拼读先试选、预览、撤销/确认；只有确认才提交。错答后修正不会改写首次成绩。
- 未做题优先轮转，两轮后休息；全部83知识项至少两道不同视觉复习题。配对、学习记录、版本及复习身份可恢复。
- WRITE-01书写课堂已实现26个基础字母、49个原创笔画、14课63个明确目标。可逐笔查看、重听中文步骤/占格，提供纸笔引导，不记录书写分数。三道图形占格题使83知识点均达到五道客观题。WRITE-02新增四声轨迹和72个明确带调目标，支持分组选择、中文标调方法及逐笔说明；去掉标调i的点，保留ü两点，正确显示iu/ui标调位置。
- WORD-01提供12幅原创生活图，课程卡可听标准音和中文图义说明；24道听音找图/看图拼读进入正常轮转，整体认读保持整音。图片未全部加载不允许作答，提供重试与中文语音提示，失败不计错。
- `npm run prepare:pinyin`显式准备标准音，`prepare:voice`准备中文指令与课录音；之后`npm start`只构建、复用已安装文件并启动，不联网补声音。

- 21个声母、24个韵母和16个整体认读音节各有至少5道客观主目标题。声母听辨在同韵母/同声调中区分声母；韵母听辨在同声母/同声调中区分韵母，每个目标使用两种已学的语音条件。
- 已合并访客模式：学生可不配对体验，进度仅保存在当前标签页；同源Mac请求用临时内存数据库计算，家庭数据库隔离。

## 本轮验证

WORD-01：内容版本2026.10.05.14新增12幅原创MIT矢量图和24道语境题，第3至14课各一项生活目标；旧452题、知识规则、中文脚本和205个标准音映射逐字段确认不变。2026.10.05.13题库在改版前保存登记。新增98个中文语音ID，由29份去重WAV提供；图片语音只读中文描述，拼音使用现有整音。

53项前端、276服务端、30模拟视口及10真实家庭/访客GUI通过。全部24题经正常API轮转、作答、备份恢复验证，损坏音源时不派发。真实Chromium/WebKit已验证12张图片卡、米/鱼/星的两类练习、图片说明独立播放、试选确认、图片与声音失败重试、保留首次错答及刷新保存。图片逐一目视核对，并将瓜籽下端调整为圆弧。两种浏览器均完成1149个中文语音入口与14课录音解码；图片卡故障用例单独复跑通过，另两项旧书写声音回归通过。

首次新增API测试误用备份字段名instances，实际字段为exerciseInstances；首次新增GUI测试漏点标准音按钮，不能触发故障；均已修正测试，再加入真实图片故障处理与回归。WebKit会复用已解码图片，故障注入改到首次加载前后复跑通过。保留初次失败日志，不将失败算成通过。资源检查missing=[]，本轮无新依赖。

WORD-01当时的`validate:release`仅剩最新课标原文核对，现已由下文CURR-02关闭；无教学审校或审音审批门槛；新增原创图片文件及引用也纳入发布检查。本机服务已更新至2026.10.05.14，健康检查确认SQLite；实际访客API返回12图、24道新题及1149个可用中文语音入口。12份SVG经HTTP读取与源码逐份核对，图片故障说明、米图片说明及题目图片选项的实际WAV摘要匹配；验证只读，不写家庭练习数据。
