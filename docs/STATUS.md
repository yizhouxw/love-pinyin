# 本阶段交付与真实状态

日期：2026-09-25。交付范围是方案、研究、内容基础和开发环境，**不是已实现的儿童学习应用**。

## 已确定并落地

- 用户确认：大陆统编人教版；首版自动发音评分；B/S；自家Mac Studio服务器；客户端仅向该Mac传录音，评分后丢弃，禁止第三方云处理。
- 课程研究核验14课新版路径、21声母/24韵母/16整体认读/独立y-w，并记录2025日常修订课标存在；不能称2022原版是2026唯一最新版本。
- 结构化学习资料：83知识项、145种子题（117客观+28朗读）、79评分目标，167待录音脚本（89标准音+78题干/选项指令）。全套基础范围已建模，实际题量尚不足正式掌握/复习。
- PRD、UX、架构/API契约、2份ADR、内容加工规范、依赖与隐私研究、SPEC-000评分PoC+001–006实现切片、模型交接模板。
- React/Vite/TypeScript前端基线，FastAPI服务基线，Node/Python锁文件、Git/MIT、lint/format/测试/CI配置及内容发布门禁。
- 本地API如实报告评分和音频未就绪；无云端依赖、无虚构分数。

## 下一阶段优先顺序

先启动 [SPEC-000](specs/SPEC-000-offline-assessment-poc.md) 的本地评分研究，同时做 [SPEC-001](specs/SPEC-001-foundation.md) 的确定性软件开发。然后按[实施计划](implementation-plan.md)推进。

| 待关闭项           | 下一步                                                                  | 谁/什么证据能够关闭                                               |
| ------------------ | ----------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 完整课标差异       | 获取2022版2025修订原文并核对第一学段拼音条款、学校印次                  | 官方原文+教师核对记录                                             |
| 题库足量           | 每知识点至少5道不同客观主目标题，补四声听辨与合法整音、全部朗读目标活动 | 内容扩充+教师审校；数量门槛不是教学效度保证                       |
| 示范音与指令音     | 按167项脚本录制、取得声音/再分发授权、双人审音                          | 真实文件、许可、hash、审核记录                                    |
| 本地自动评分可用性 | 先DSP对照实验，必要时研究专用音素模型或授权Mac离线SDK                   | 持权真实数据、冻结模型/校准、分群指标及失败案例；当前无已接受引擎 |
| 实际跨端           | 实机HTTPS、麦克风、局域网断WAN、取消/恢复、键鼠触摸                     | iPad/iPhone/Android/电脑现场测试记录                              |
| 正式服务           | 配对、SQLite、备份、会话、部署、自启动                                  | 相应SPEC软件实现及验证                                            |

最重要的可行性风险是儿童拼音本地评分，不能承诺靠一个现成开源包即可解决。较低成本模型可以直接按SPEC完成确定的软件切片；教师审校、声音授权、真实样本与评分研究需要相应外部交付。本阶段已把这些依赖放到最前面，而没有掩盖成“后期接个API”。

## 本阶段没有做的外部动作

没有创建远程仓库、推送开源、部署公网、购买SDK、上传儿童声音、安装根证书或修改系统自启动。MIT代码仓库可以后续公开；正式儿童产品必须通过发布门禁。
