# 当前产品状态

更新：2026-10-05。当前目标是供一年级儿童和家长实际使用的家庭B/S产品。首版不录音、不做发音评测，所有客观题有中文语音。标准音直接信任cmguo/PinYinSound，机制见[ADR-0008](adr/0008-trusted-standard-audio.md)。历史切片结果见Git及各SPEC。

## 已实现

- Mac Studio的FastAPI/SQLite提供课程、配对、会话、判题、进度、复习、设备管理及实际JSON下载/恢复。没有模拟成绩或生产mock API。
- 14课、83知识项、377题，其中349客观题可用（186视觉、163听辨），28道未来朗读题不进入首版。全部客观题有中文题干、提示与答后讲解；29个中文选项、15个界面引导合计742个中文语音ID。
- 标准音唯一来源cmguo/PinYinSound：固定提交、177个目标映射，158个去重MP3共2049055字节。安装后通过本机家庭/访客API播放，摘要、路径和映射校验保留。用户无需审音或审核确认。
- 删除审音台、两人签名/启用流程、待审状态、多来源审核回退、儿童草稿横幅及家长审校说明。产品用户只有学生和家长；审核不再是软件发布门槛。
- 课程schemaVersion 2.0.0、内容版本2026.10.05.6移除审核字段；2026.10.05.7新增四声听辨题，2026.10.05.8新增42道声母听辨题，2026.10.05.9新增48道韵母听辨题。旧冻结题单和家庭备份继续读取，旧审核字段不影响恢复、题目或计分，原文件不删除。
- 本机中文指令由已安装Tingting生成，224份去重WAV；用户13份课程MP3映射14课，第2/9课共用合课录音。中文TTS不合成拼音，长课程录音不替代单音。
- 题目、中文选项、提示、讲解均可停止/重听；声音失败可重试，不计错。拼读先试选、预览、撤销/确认；只有确认才提交。错答后修正不会改写首次成绩。
- 未做题优先轮转，两轮后休息；全部83知识项至少两道不同视觉复习题。配对、学习记录、版本及复习身份可恢复。
- `npm run prepare:pinyin`显式准备标准音，`prepare:voice`准备中文指令与课录音；之后`npm start`只构建、复用已安装文件并启动，不联网补声音。

- 21个声母和24个韵母各有至少5道客观主目标题。声母听辨在同韵母/同声调中区分声母；韵母听辨在同声母/同声调中区分韵母，每个目标使用两种已学的语音条件。
- 已合并访客模式：学生可不配对体验，进度仅保存在当前标签页；同源Mac请求用临时内存数据库计算，家庭数据库隔离。

## 本轮验证

BANK-05新增48道韵母听辨，内容检查验证同声母/同声调、真实目标一致性、已学范围和两种语音条件。API测试逐课轮转到达全部新题并保存；注册夹具仅用于准入和业务边界，真实声音另行安装与解码。旧329题、知识规则、旧音频映射不变。

声调重复题GUI按实际课内题量找到再次出现的同题，保留“当前实例须重新听音”断言，避免扩充题库后依赖固定轮数。完整工程检查通过：42项前端、232项服务端、30项模拟浏览器边界测试和6项真实家庭/访客数据GUI。实际声音专项10项通过（桌面Chromium/WebKit）：每个引擎完成12道代表性韵母题、两种中文讲解、键盘作答、休息与刷新保存；全部177标准音目标、742中文语音入口及14课录音解码通过，访客声音和四声重复题回归通过。本机资源检查missing=[]。

`validate:release`目前仍有两个内容缺口：最新课标条款原文核对、每知识点至少五题。实际标准音/中文指令/课程录音的资源检查已通过；无教师审核、审批或审音门槛。
