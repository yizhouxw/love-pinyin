# 当前产品状态

更新：2026-10-05。当前目标是供一年级儿童和家长实际使用的家庭B/S产品。首版不录音、不做发音评测，所有客观题有中文语音。标准音直接信任cmguo/PinYinSound，机制见[ADR-0008](adr/0008-trusted-standard-audio.md)。历史切片结果见Git及各SPEC。

## 已实现

- Mac Studio的FastAPI/SQLite提供课程、配对、会话、判题、进度、复习、设备管理及实际JSON下载/恢复。没有模拟成绩或生产mock API。
- 14课、83知识项、452题，其中424客观题可用（220视觉、204听辨），28道未来朗读题不进入首版。全部客观题有中文题干、提示与答后讲解；31个中文选项、15个界面引导及79个书写引导合计973个中文语音ID。
- 标准音唯一来源cmguo/PinYinSound：固定提交、205个目标映射，183个去重MP3共2278818字节。安装后通过本机家庭/访客API播放，摘要、路径和映射校验保留。用户无需审音或审核确认。
- 删除审音台、两人签名/启用流程、待审状态、多来源审核回退、儿童草稿横幅及家长审校说明。产品用户只有学生和家长；审核不再是软件发布门槛。
- 课程schemaVersion 2.0.0、内容版本2026.10.05.6移除审核字段；2026.10.05.7新增四声听辨题，2026.10.05.8新增42道声母听辨题，2026.10.05.9新增48道韵母听辨题，2026.10.05.10新增32道整体认读听辨题，2026.10.05.11新增40道规则练习。旧冻结题单和家庭备份继续读取，旧审核字段不影响恢复、题目或计分，原文件不删除。
- 本机中文指令由已安装Tingting生成，330份去重WAV；用户13份课程MP3映射14课，第2/9课共用合课录音。中文TTS不合成拼音，长课程录音不替代单音。
- 题目、中文选项、提示、讲解均可停止/重听；声音失败可重试，不计错。拼读先试选、预览、撤销/确认；只有确认才提交。错答后修正不会改写首次成绩。
- 未做题优先轮转，两轮后休息；全部83知识项至少两道不同视觉复习题。配对、学习记录、版本及复习身份可恢复。
- WRITE-01书写课堂已实现26个基础字母、49个原创笔画、14课63个明确目标。可逐笔查看、重听中文步骤/占格，提供纸笔引导，不记录书写分数。三道图形占格题使83知识点均达到五道客观题。
- `npm run prepare:pinyin`显式准备标准音，`prepare:voice`准备中文指令与课录音；之后`npm start`只构建、复用已安装文件并启动，不联网补声音。

- 21个声母、24个韵母和16个整体认读音节各有至少5道客观主目标题。声母听辨在同韵母/同声调中区分声母；韵母听辨在同声母/同声调中区分韵母，每个目标使用两种已学的语音条件。
- 已合并访客模式：学生可不配对体验，进度仅保存在当前标签页；同源Mac请求用临时内存数据库计算，家庭数据库隔离。

## 本轮验证

WRITE-01：已对照官方平台教材的21、23、25、26、32、34、36、38、40页核对字形/笔顺/占格，自行编写轨迹和中文步骤，没有复制教材扫描图。内容版本2026.10.05.12新增a、b、j三道实际图形占格题，原449题不变，继续保留已登记历史题库兼容。

完整工程检查通过：47前端、263服务端、30模拟视口及10真实家庭/访客GUI。声音专项8项通过：真实Chromium/WebKit解码973个中文语音入口及14课录音，完成逐笔/回看/听占格/纸笔引导、故障重试、课程录音互斥；14课63目标均经界面展开，26字母实际截图逐一目视核对。三道图形题通过正常课程轮转到达、作答并刷新保存，书写观察不产生虚假成绩。另用实际GUI检查第一课逐笔操作，320px/200%文字与48px按钮边界有自动证据；不等于移动真机。

初次测试暴露旧访客缓存构造的竞态：答题反馈先显示，进度读取随后完成；测试现等待继续按钮启用再构造历史状态，应用保存中也禁用继续按钮，避免点击被忽略。另修正测试的播放中按钮名称和备份确认参数。完整回归重新通过。最后补图形选项的辅助技术文字后，再跑全工程与6项书写GUI确认。

`validate:release`仅剩最新课标原文核对，题量与实际音频已满足该脚本检查。脚本不代表带调书写、生活词义、教学效果或真机验收已完成。无教学审校或审音审批门槛。本机服务已更新至2026.10.05.12，健康检查确认SQLite；实际API返回452题、26字形、63书写目标、973可用中文语音。g第二笔的实际WAV经HTTP读取并核对摘要，无家庭测试写入。
