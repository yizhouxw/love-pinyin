# 当前产品状态

更新：2026-10-05。当前目标是供一年级儿童和家长实际使用的家庭B/S产品。首版不录音、不做发音评测，所有客观题有中文语音。标准音直接信任cmguo/PinYinSound，机制见[ADR-0008](adr/0008-trusted-standard-audio.md)。历史切片结果见Git及各SPEC。

## 已实现

- Mac Studio的FastAPI/SQLite提供课程、配对、会话、判题、进度、复习、设备管理及实际JSON下载/恢复。没有模拟成绩或生产mock API。
- 14课、83知识项、287题，其中259客观题可用（186视觉、73听辨），28道未来朗读题不进入首版。全部客观题有中文题干、提示与答后讲解；29个中文选项、15个界面引导合计562个中文语音ID。
- 标准音唯一来源cmguo/PinYinSound：固定提交、99个目标映射，85个去重MP3共804093字节。安装后只通过本机配对API播放，摘要、路径和映射校验保留。用户无需审音或审核确认。
- 删除审音台、两人签名/启用流程、待审状态、多来源审核回退、儿童草稿横幅及家长审校说明。产品用户只有学生和家长；审核不再是软件发布门槛。
- 课程schemaVersion 2.0.0、内容版本2026.10.05.6移除审核字段；2026.10.05.7新增四声听辨题。旧冻结题单和家庭备份继续读取，旧审核字段不影响恢复、题目或计分，原文件不删除。
- 本机中文指令由已安装Tingting生成，218份去重WAV；用户13份课程MP3映射14课，第2/9课共用合课录音。中文TTS不合成拼音，长课程录音不替代单音。
- 题目、中文选项、提示、讲解均可停止/重听；声音失败可重试，不计错。拼读先试选、预览、撤销/确认；只有确认才提交。错答后修正不会改写首次成绩。
- 未做题优先轮转，两轮后休息；全部83知识项至少两道不同视觉复习题。配对、学习记录、版本及复习身份可恢复。
- `npm run prepare:pinyin`显式准备标准音，`prepare:voice`准备中文指令与课录音；之后`npm start`只构建、复用已安装文件并启动，不联网补声音。

## 本轮验证

TONE-01在独立验收工作区完成工程检查：35项前端、214项后端、30项模拟边界/视口和2项真实家庭数据GUI通过。原275道题、知识规则、朗读目标、原声音映射和中文脚本逐字段不变。新增12题与24个语音ID，准备5份去重中文WAV；99项目标的实际资源检查missing=[]。

本次隔离验收避免混入共享工作区正在进行的访客模式改动。首次工程GUI有一次平板WebKit休息页焦点断言失败；顺序重跑全部工程检查通过。桌面和视口测试仍不能代替真机验收。完整声音产品GUI在Chromium/WebKit共22项通过，包含99个标准音解码、12道四声题正常轮转、纠错与保存、再次遇到同题必须重新听音。

`validate:release`目前仍有两个内容缺口：最新课标条款原文核对、每知识点至少五题。实际标准音/中文指令/课程录音的资源检查已通过；无教师审核、审批或审音门槛。
