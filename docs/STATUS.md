## 当前内容与功能

内容版本 `2026.10.05.15`，schema `2.0.0`，以 `content/` 和校验器为准：

| 项目         | 当前值与用途                                                     |
| ------------ | ---------------------------------------------------------------- |
| 课程/知识点  | 14课、83项，按统编人教版课序；家长自由选当前课                   |
| 题库         | 476题：448道客观题、28道保留朗读题；朗读题不进入首版会话         |
| 客观题分类   | 听辨204、字形126、声调53、拼读65                                 |
| 朗读研究目标 | 79个，仅保留数据，不表示有录音/评分功能                          |
| 标准音       | 205个目标映射、183个去重文件，固定PinYinSound来源                |
| 中文声音     | 1149个生成入口，覆盖题目、选项、提示/反馈、导航、书写和图片说明  |
| 书写/图片    | 26基础字形、63无调及72带调书写目标；12生活图片目标、24道相关练习 |

普通练习最多六题；到期推荐最多三个知识点，点选其中一个进入两题复习。提示、首次作答、修正与跳过区分计分；新题实例冻结选项顺序。书写观察和课程图片卡不生成纸笔/口语成绩。

家庭进度经配对保存在Mac SQLite；家长可选课、查看明细、管理设备、导出/预览恢复/删除。访客使用标签页临时状态；历史内容、幂等提交、待校时记录、真实停服恢复、SQLite备份及未知迁移版本拒绝均有实现和回归。
