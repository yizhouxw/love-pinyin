# SPEC-000：家庭 Mac 本地发音评分 PoC（已暂缓）

状态：暂缓，不属于首版实施路径，也不阻塞产品开发或发布。用户决定首版不做发音评测，详见 [ADR 0004](../adr/0004-defer-pronunciation-assessment.md)。本文件余下内容保留为未来重启时的历史研究验收草案；不得据此在本期实现录音、上传、评分或依赖。

## 目标与边界

在用户自家 Mac Studio 上找到可离线于互联网运行、授权清楚、真实拼音发音样本验证合格的评分方案。浏览器录音只允许经局域网 HTTPS 到自家 Mac；不允许第三方云评分或外发特征。用户需要的是发音评分，通用 ASR 转写、音高曲线或 DTW 相似度可以作为候选技术的一部分，单独存在不能证明教学准确性。

原生 SDK、Python/ONNX、音素识别/对齐与声调特征均可研究；不提前锁死候选模型，不要求在浏览器 WASM 推理。候选必须覆盖最终内容清单中的单字母/声韵母/整体认读/带调音节等实际目标；只验证汉字句子不能推断覆盖拼音教学。无法可靠覆盖的目标必须明确列出缺口，不能偷偷缩减首版范围。

依赖：课程和音频研究、`content/` 目标清单、[架构](../architecture.md)、[API 契约](../api-contract.md)、Mac 实机。软硬件、许可和模型下载结果必须记录检查日期及版本。

## 文件边界与输出

允许：`research/assessment/`（基准工具、可再现配置及脱敏汇总）、`server/assessment/`（隔离的候选适配器）、`docs/research/`（实验结果与决策）、相应测试和锁文件。不得把真实儿童录音/派生可识别特征/未授权模型权重提交 Git。不得在此切片完成业务页面或伪造一个永远给高分的服务。

必须交付：

1. 候选表：项目/模型精确版本、官方来源、代码/权重/训练或模板数据分别的许可、离线安装步骤、下载是否实测、硬件需求、允许/不允许的使用与再分发、淘汰原因。
2. 范围矩阵：每类发音目标可用程度、输出维度、静音/噪声/错音/错调/扬声器复播处理方法及风险。
3. 可复现离线基准脚本、数据清单与本地授权登记 schema、版本/随机种子/配置摘要、机器与软件环境和无第三方网络请求证据。
4. 教师标注流程、合法样本来源、开发/校准/测试集按说话人隔离的规则、客观指标及置信区间、失败案例分析。
5. 接受/继续研究/不通过决策；通过时冻结 engine/calibration 版本和可输出字段。若没有合格方案，交付真实阻塞说明，保留现有 API unavailable，不改目标。

## 测试数据与评分定义

测试清单最少字段：`sampleId`、匿名 `speakerGroupId`、`targetId`、目标类别、设备/环境类别、两份带不同匿名 `reviewerRef` 的独立判断、最终裁决标签、数据授权记录引用、样本 SHA-256。两人意见一致时最终标签必须等于共识且 `adjudicatorRef` 为空；意见不一致时必须由与前两人不同的第三位匿名裁决者提供 `adjudicatorRef`，最终标签记录裁决结论。审核人资质、独立标注与第三裁决的实际工作记录保留在本地受控记录，不写入公开清单。原始样本路径仅在本地受控配置中。短期保留的 PoC 样本需单独授权、最小访问和到期清理；与产品「处理后丢弃」策略明确区分。

挑战标记区分静音、过短、噪声、扬声器回放与近邻易混。前四类须裁决为 `uncertain` 并使用 challenge target；近邻易混须保留实际课程 target 且裁决为 `incorrect`，单独分组报告。测试清单至少应包含这些挑战条件以及声母/韵母/声调错例；统计报告本身不能取代人工确认样本确实符合标签。

正式验证目标：最终盲测集中至少 30 位不同目标年龄段儿童，数据集总计至少 600 条已裁决样本，包含清楚正确、音素错误、声调错误、静音/过短/噪声及近邻易混目标。训练/校准集与最终测试集按说话人隔离，不把同一个儿童的录音混入两侧。数据量不足时仅能记为探索性实验。发布阈值以 held-out 儿童样本指标判定；成人探索样本单独报告，不能与儿童样本合并掩盖儿童子组表现。两位有资质或充分拼音教学经验的审校人独立标注，分歧由第三次裁决处理；不得用模型输出当真值。

评测器应检查 held-out 目标年龄儿童测试样本是否实际覆盖上述每种条件，并在缺项时报告名称、计数为零且保持数据覆盖门禁失败。至少一个合成逻辑测试应证明完整覆盖可通过、缺一项仍失败。覆盖检查不把一个样本解释为统计充分，600 条/30 位与分层区间要求仍独立适用。

外部儿童语料仅可在其数据集单独书面许可覆盖研究用途/商用产品后取得。会议论文开放获取、数据集标注为 public/open 或可联系作者都不等于录音可下载、训练、商用或再分发。即便许可有效，非大陆普通话目标儿童、较大年龄儿童、无逐目标发音真值、单人 fluency 分级、自动音素对齐均只能用于探索或稳健性分析；不能替代上述产品目标人群 held-out 测试。当前核验候选及边界见[语料候选复核](../research/assessment-poc-status.md#普通话儿童评分数据集候选2026-09-26)。

以下数值是产品提出的初始接受目标，需要实验前由产品和教学审核确认并锁定，不是已证实效果：

| 指标                     | 初始门槛                       | 计算口径                                                                       |
| ------------------------ | ------------------------------ | ------------------------------------------------------------------------------ |
| 明确样本分类准确率       | ≥ 90%                          | 教师明确正确/错误的样本，模型输出正确/需练习；不确定单独记且不得从分母悄悄删除 |
| 错误发音被放行比例       | ≤ 5%                           | 教师错误而模型判通过 / 所有教师错误样本                                        |
| 正确发音被误判为错误比例 | ≤ 10%                          | 教师正确而模型判需练习 / 所有教师正确样本                                      |
| 不确定比例               | ≤ 20%                          | 目标支持范围内的普通安静环境测试样本；噪声挑战集另报                           |
| 静音/纯噪声拒判率        | ≥ 95%                          | 不能把无语音样本评分为好发音                                                   |
| 标注一致性               | 报告原始一致率与 Cohen's kappa | 若一致性不足，先澄清评分目标再测模型，不强行校准分数                           |

每项报告整体、目标类别、设备、说话人分布及 95% 置信区间；对同一说话人的重复样本按说话人整组重采样，样本级 Wilson 区间只能作为描述值，不能假设同一儿童的录音相互独立。少于两位有效说话人的分组，其说话人聚类区间标记为不可估；样本过少的子类标为未证实，不以整体平均掩盖单韵母/声母/声调的明显失败。数字分数不是直接把识别置信度 × 100；需用教师分级样本校准 0–100 含义，报告分段误差及重测稳定性。无可靠数字校准时，不能声称首版自动评分已经完成。

基准报告还需按课程 `targetId` 单独输出计数、比率和区间，以便定位具体声母/韵母/整体认读/声调目标的失效；这些 ID 来自当前内容清单，报告不得包含样本 ID、说话人 ID 或录音路径。

## 性能和网络预算

基准必须在用户实际 Mac Studio 记录型号、芯片、内存、macOS 与加速后端，不臆测配置。初始产品预算：10 秒以内录音，标准化 16 kHz 单声道 PCM WAV，上传上限 512 KiB；热模型单请求 p95 从服务端收到音频到结果 ≤ 3 秒，局域网端到端 p95 ≤ 5 秒（从录音结束起，含上传与排队）；冷启动准备 ≤ 30 秒并有能力状态；最多同时接纳 3 个请求（1 个执行、最多 2 个排队），其余请求返回明确繁忙；单工作进程峰值额外内存 ≤ 4 GiB，模型/模板总下载 ≤ 2 GiB。预算不满足需研究优化或提出有证据的产品变更，不擅自调松。

上述 p95 为正常性能预算。硬上限另为：录音 10 秒、排队 5 秒、推理 5 秒、单次评分操作整体 15 秒；整体从发起评分请求计时，不含用户录音时长。超过任一上限返回明确 unavailable/繁忙状态，不转成低分。端到端性能指标从录音停止后自动准备/上传起计，不包含用户主动停留在预览页的时间。

硬断互联网、保留 LAN 后验证标准音、录音上传、推理和结果均可用；进程网络观测中无公网请求、遥测、许可证在线核验或远端模型拉取。模型应提前安装并校验摘要。并发取消、格式错误、解码异常、worker 崩溃后检查录音释放与临时文件清理。

## 输入与输出契约

输入为 [API 契约](../api-contract.md) 定义的目标 ID、请求 ID、内容/模型兼容版本及 WAV 音频。禁止以客户端任意文本/路径加载文件或模型。

输出采用 `src/domain/contracts.ts` 的 `AssessmentResult`：`scored` 必须有真实 engine/calibration 版本、0–100 分和可信度；只有被证实的维度才填值。`uncertain`、`unsupported`、`unavailable` 没有分数，不产生负向掌握事件。引擎实现需支持取消和截止时间，所有异常必须清理音频对象。请求重复只返回同一次评分摘要，不保留音频来实现重放。

## Given / When / Then 验收

- Given 一份候选模型，When 断网安装/启动并查许可，Then 本地已下载包可完成运行、所有组成资产可追溯，不能只有代码开源但权重不明。
- Given 未参与校准的儿童测试集，When 运行冻结配置，Then 生成每条预测与聚合指标、置信区间，符合锁定门槛并列明未证实子类。
- Given 静音、播放标准音的录音、成人模仿和噪声，When 评分，Then 如实报告检测结果及限制；无法可靠判断时返回 uncertain，不给鼓励分掩盖失败。
- Given 同一个请求被重复发送或被取消，When 服务返回/终止，Then 只有一个摘要且无遗留音频文件、日志音频或第三方请求。
- Given 候选不合格或未取得样本/授权，When 交付本切片，Then 状态是 blocked/继续研究，003 与 006 的评分门禁保持未通过。

## 命令、人工交付与低成本模型提示

现有可运行基线：`npm run verify`、`npm run verify:server`；通过意味着工程质量，不代表 PoC 通过。基准汇总入口为 `uv run --locked python -m research.assessment.benchmark --manifest <本地清单> --predictions <盲测预测> --authorizations <本地授权登记> --audio-dir <本地音频目录> --output <聚合报告>`。它校验课程版本、说话人隔离、WAV 限制、授权引用/用途/人群/有效期和摘要哈希；若测量指标过关但分数校准证据缺失，仍以非零状态退出且决策为 continue-research。当前没有合法数据，尚不能运行该实验。

低成本模型可完成：候选适配器、数据校验、基准脚本、指标/置信区间计算、取消/清理测试、网络调用检测和结果报告。必须由具备授权的人完成：儿童样本合法取得、发音真值审校、实际设备录音、模型商业/再分发许可确认。公开代码可以 MIT；第三方资产不能因仓库 MIT 自动变成可自由再分发。

执行提示：先复现候选最小推理，不接业务 UI。逐项记录失败，禁止编造样本、分数、教师评语或通过状态。只有完整证据满足本门禁后，再给 SPEC-003 提供通过的适配器和冻结版本。
