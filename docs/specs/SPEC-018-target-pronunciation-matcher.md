## MATCH-01：任务及输出

- 输入为白名单目标 ID 和主动录制的 16kHz、单声道 PCM16 语音。目标包含规范拼音、发音形式、允许的音素序列与标准音引用；不接受任意路径、远程 URL 或浏览器提交的“标准答案”。
- 首个实验覆盖完整单音节的声母、韵母和四声；单独声母呼读、单独韵母与“先分拼、再合读”各用显式任务类型，不与完整音节共用隐含标签。词句及变调单列后续实验。
- 模型直接估计声学特征和音素证据，不经汉字转写或语言模型补全。对目标题目、近邻发音和额外音节共同计算证据，不能只强制对齐预期答案后宣布匹配。
- 返回 `matched`、`retry`、`uncertain`、`unavailable`。只在声音可用、目标覆盖、置信充分时给出明确结论；未听清、噪声、过短、过长、音高估计失败、模型缺失、超时及断网不判孩子错误。声调能力独立声明，未验证时 `toneAssessed=false`，不能显示“读得完全准确”。
- 不向儿童展示未经校准的百分制或“相似度等于准确率”。实验匹配及家长放行均与既有客观题首次成绩和掌握度隔离。

## MATCH-02：两个生成模型与数据

- 选择固定修订的 `Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign` 和 `FunAudioLLM/Fun-CosyVoice3-0.5B-2512`，官方权重均标注 Apache-2.0。记录修订、文件摘要、生成器版本、文本、种子、音色家族、音频父子关系及增强参数。
- 年龄/性别是合成音色的风格标签，不是实际说话人属性；合成童声不得写成真实儿童样本。CosyVoice 使用 Qwen 生成的参考音时，两者归属同一音色家族，不能伪装成独立说话人。
- 教学标准音仍直接信任固定 PinYinSound；TTS 素材只用于模型训练和实验，不替换课程标准音，也不增加标准音审音/教师审核角色。
- 训练同时包含正确发音、近邻声母/韵母/声调、音节增删与非语音挑战。加噪、混响和音量变化用于环境鲁棒性，不能自动标成“发音错误”。音高/变速处理不得悄悄改变声调标签。
- 跨语言与方言反例记录相对于具体目标的音素/声调/音节结构差异、生成意图标签局限、词根与父源谱系。语言名称不直接决定正误；共有发音不标错。按语言及差异类别分别报告，训练/校准/冻结留出使用不同词结构及声音家族；声音转换、加噪和多目标配对不虚增独立源数量。粤语等仅风格提示的探索输出不能虚报为已经验证的方言覆盖。非语音明确 `retry` 必须为零；缺少可靠发声证据返回拒判。
- 按原始音频谱系和音色家族先划分集合，再做增强。训练、阈值校准、测试不得共享原始录音、变体或克隆参考来源。数据量区分独立根样本、增强样本和配对次数。
- 先完成 32 目标、约三千段根样本的小实验，再决定全量扩展；无需先收集真实儿童训练集才能开始这一步。

## MATCH-03：CPU 模型与实验验收

实施补充（2026-10-25）：共享声调头在换调挑战中暴露音节内容捷径；仅用合成 ma 四声训练独立轮廓头的校准结果也不足。最终保留 TTS 声学网络，声调另用 6,372 参数的相对有声 F0 轮廓头；采用已授权、直接信任的 PinYinSound 标准音作声调锚，按音节分组，排除全部 32 个试验目标的音节组。记录 325 段训练、92 段校准，保留来源许可状态。最初 88 段挑战仅作探索，另以新音色家族的 190 段声音复测；不把同源标准音记录说成独立说话人验证。

- 选用小型深度可分离卷积/时序卷积声学网络、音素 CTC 分支、相对音高声调分支与保守阈值校准。MFCC/DTW 仅作对照基线，单一余弦相似度不作最终裁决。
- 训练及 TTS 批量生成属于离线工具，可用本地 GPU/Metal；产品只加载独立导出的 ONNX 匹配模型，显式使用 CPU provider。运行不加载 TTS、Whisper 或通用大模型，不自动下载。
- 初始工程预算为 2～5M 参数，INT8 权重目标不超过 10MiB、进程增量内存不超过 200MiB；四秒以内音频，在目标 Mac 的两个 CPU 线程上，暖机后端到端 p95 不超过 500ms、实时率不超过 0.1。均为待实测门槛，不是现有实测结果。
- 声母、韵母、声调、近邻错放行、正确音误拒与拒判分别报告。比较干净/噪声、未见音色、跨生成器、真实成人及真实儿童录音；合成测试通过不能写成儿童准确率通过。
- 家庭实验可在明确标示实验能力的模式下逐步试用，不重新把旧 PoC 的全部人数/样本前置条件设为研发阻塞。广泛自动裁决能力必须以独立真实样本和冻结阈值验证，不以一次家庭试用替代。

## MATCH-08S：预训练包的校准压力协议
