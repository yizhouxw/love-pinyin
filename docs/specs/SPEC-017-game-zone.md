# SPEC-017：有声拼音游戏乐园与家庭时长

2026-10-25，依据用户要求。复用已授权题库、标准音和中文引导，不新增依赖。遵循ADR-0031。

- GAME-01：学生首页有独立游戏乐园，提供听音寻宝、声调探险、字形侦探、拼读列车。仅选当前课及之前已学内容；每关最多6题，不重复题目，按历史轮转。未学到或资源不足的玩法明确说明。提供玩法声音、逐题声音、提示、修正、跳过、提前退出、稳定键盘/触摸按钮；每题一处参与进度，不使用速度奖励、生命值或排行榜。拼读采用可撤销候选和确认，不自由生成教材外音节。
- GAME-02：游戏单次默认15分钟，每天默认60分钟。家长仅在Mac本机管理页修改，整数范围单次1～60、每日1～180分钟。学习课程与天天练不受此游戏额度影响。家庭配对设备共享额度，短暂退出、切玩法、刷新和多设备不能重置；连续停止游戏10分钟才开启新一次，每日按Asia/Shanghai零点重置日额度，单次额度不随跨日重置。到达任一上限自动停音并锁定游戏，保留已答结果；到每日上限次日再玩，单次上限休息10分钟后再玩。孩子无需看秒表，不按速度评分。
- GAME-02A：服务器用UTC时钟结算实际授权游戏时间，跨设备重叠只计一次；授权最长12秒，浏览器每4秒续期。后台继续计至租期结束，长时间后台不持续占用；恢复先续期再开放游戏。续期请求超过6秒取消，掉线或租期到期立即在页面暂停，不判孩子错；刷新和服务器重启保留额度。回拨暂停并要求校时。访客额度随标签页临时状态保存，明确清除访客可重置，不能宣称为防绕过家庭限额。
- GAME-03：游戏结果进入原有真实首次客观作答和掌握度；小结区分独立首次正确、提示后正确、首次待巩固、跳过。家长/游戏乐园看到最近7天游戏题量、首次独立答对数、使用提示数、跳过数和待巩固知识点，注明小样本及非考试/发音评测；不把参与次数当掌握。时间状态、设置、玩法来源随家庭备份往返；旧备份缺字段使用默认值。删除学习记录保留时长限制与当天额度，重置家庭档案才重置游戏设置与额度。
