# SPEC-017：有声拼音游戏乐园与家庭时长

## 2026-10-27 四游戏游玩完善（最终需求）

下列 PLAY 验收修订 LEVEL 固定十二任务与 ADAPT 启动后不可调节的要求；拼音小卖部不在本次范围。

- PLAY-01：四款各六关，每关题量可配置为整数 3～20，默认 6；入口与游戏内均可设置。已开始的题单保持冻结，游戏内题量设置明确用于下次开局。优先分散已学拼音目标，再轮转不同题目，不能整关只重复一个拼音。保留三章节，按题量均衡分配任务，正确/跳过累计达到所选题量才通关；旧十二题会话与备份可继续恢复。
- PLAY-02：游戏内可打开设置并暂停世界，调整启蒙/熟练/挑战、速度、慢动作与连续旅程；难度/速度应用到当前关并由服务端保存，刷新、访客与备份恢复一致，不更改题单、标准答案或首次成绩。设置失败保留草稿、可重试或取消，关闭后恢复此前暂停状态。每款保存自己的下次开局偏好。
- PLAY-03：进入即显示候选拼音，自动优先播放本题标准音，完整说明/故事可随时按按钮听，不串播长说明阻挡开局；听完必要标准音后开放动作。缩短航段与续题停顿，六关通过各自布景及逐关增加的速度区分，仍可随时暂停或辅助慢动作，操作失误不计拼音错误。
- PLAY-04：完整检查四款触摸/键盘、暂停、重听、提示、修正、跳过、退出及网络异常；触摸支持按住移动/划桨，取消/失焦清除，保留点击和键盘操作。提供页内“放大画面/还原画面”，扩大可用网页宽度并将任务栏移至下方，不调用全屏 API、不遮挡浏览器。四场景使用本地 SVG 丰富景深、布景、角色和目标可读性；320px 及桌面无横向溢出，设置可用键盘与 Escape 关闭。跨题保持画面与辅助偏好。

架构见 ADR-0036，无新增依赖。软件验证与真实移动设备、家庭 LAN、儿童试用分别记录，不以模拟视口代替真机。

2026-10-25，依据用户要求。复用已授权题库、标准音和中文引导，不新增依赖。遵循ADR-0031。

- GAME-01（历史初版，已由下方 SCENE 修订替代）：学生首页有独立游戏乐园，提供听音寻宝、声调探险、字形侦探、拼读列车。仅选当前课及之前已学内容；每关最多6题，不重复题目，按历史轮转。未学到或资源不足的玩法明确说明。提供玩法声音、逐题声音、提示、修正、跳过、提前退出、稳定键盘/触摸按钮；每题一处参与进度，不使用速度奖励、生命值或排行榜。拼读采用可撤销候选和确认，不自由生成教材外音节。
- GAME-02：游戏单次默认15分钟，每天默认60分钟。家长仅在Mac本机管理页修改，整数范围单次1～60、每日1～180分钟。学习课程与天天练不受此游戏额度影响。家庭配对设备共享额度，短暂退出、切玩法、刷新和多设备不能重置；连续停止游戏10分钟才开启新一次，每日按Asia/Shanghai零点重置日额度，单次额度不随跨日重置。到达任一上限自动停音并锁定游戏，保留已答结果；到每日上限次日再玩，单次上限休息10分钟后再玩。孩子无需看秒表，不按速度评分。

- GAME-03：游戏结果进入原有真实首次客观作答和掌握度；小结区分独立首次正确、提示后正确、首次待巩固、跳过。家长/游戏乐园看到最近7天游戏题量、首次独立答对数、使用提示数、跳过数和待巩固知识点，注明小样本及非考试/发音评测；不把参与次数当掌握。时间状态、设置、玩法来源随家庭备份往返；旧备份缺字段使用默认值。删除学习记录保留时长限制与当天额度，重置家庭档案才重置游戏设置与额度。

## 2026-10-25 场景游戏修订（本次最终需求）

上一版 GAME-01 是题卡互动，未达到可玩游戏标准。以下 SCENE 验收替代旧 GAME-01；GAME-02/02A/03 保持有效。

- SCENE-01 森林跑酷：持续卷动的森林、可换道和跳跃的角色、树根障碍及拼音拱门。实际穿门触发选择；撞树根/错过跳跃只重走该段，不写拼音错误。
- SCENE-02 河湾划船：左右划桨产生惯性、方向和前进距离，水流随难度变化，驶入实际浮标触发选择。搁浅回到河道，不判拼音错误。
- SCENE-03 节奏鼓岛：音符沿轨道按速度移动到击打区，击鼓命中才触发选择；空拍不判拼音错误。启蒙在击打区停留，可放过当前音符；所有难度均可随时使用慢动作辅助，不强制反应倒计时。
- SCENE-04 星际投递：左右瞄准、发射后真实弹道飞行，与移动星球碰撞才触发选择；空投重试，不判拼音错误。
- SCENE-05 四场景均有触摸按钮和方向键/空格等价操作、真实中文玩法声音和逐题标准音；听完标准音才开放动作。暂停、听声音、隐藏页面、网络故障时停止世界更新。允许随时暂停/退出、辅助慢动作；有限六个检查点，无生命值、排行榜和无限奖励。声音/首次结果/掌握度沿用原流程，不把运动技巧计入拼音掌握度。
- ADAPT-01 每个游戏分别设置启蒙/熟练/挑战和慢速/标准/快速，默认自动匹配。服务器只用家长选定课及之前的真实课程和已校时首次作答推荐；冷启动启蒙慢速，累计有效样本和正确率达到配置阈值才提高推荐。优先安排当前课和待巩固知识点，保留历史轮转；手动提高难度不能解锁未学内容。所有场景首课可玩，优先各自目标题型，不足时用已学听辨题补足。教学选项不裁剪、不另造答案。
- ADAPT-02 各游戏启动选择在本设备保存；本轮实际难度、速度、匹配依据冻结在会话，刷新、访客恢复和家庭备份往返保留。运动速度影响世界更新、难度影响辅助停留/水流/目标大小和移动幅度。模式允许游戏中辅助，不改变本轮学习内容或首次成绩。

跨模块决定见 ADR-0032。本轮验收需新增纯物理碰撞/空操作测试、进度匹配与会话备份边界、四场景真实浏览器操作和声音、窄屏及键盘验证。真实移动设备、儿童可理解性与家庭 LAN 仍需家庭实测。

## 完整关卡与键盘修订（2026-10-25，用户实测反馈）

此前 SCENE 的单题场景和仅画布焦点按键不满足实际游戏要求，以下 LEVEL 验收替代“六题等于六关”的编排。GAME-02/03额度和真实首次成绩保持。

- KEY-01：进入游戏即获得操作焦点；方向键或A/D移动，空格/W行动，S放过音符，P暂停。点击动作/声音后可直接按键，不要求再次点画布。方向键可接管按钮焦点；Tab、Enter/Space仍可操作普通界面按钮，输入框/下拉框/弹窗不被抢键；按住方向/划桨支持连续操作，失焦/后台/暂停清除按下状态，退出卸载监听。
- LEVEL-01：独立content/game-levels.json维护四游戏各6关，共24个有名称、故事目标与不同路线的关卡。每关3个章节、12个连续拼音检查点，共288个任务槽；每关覆盖多个拼音目标，按已学课及之前真实题库绑定12个不重复题实例。单检查点不能宣称一整关；通关小结仅在12段结束后显示。正确后短暂反馈并自动进入下一段，儿童可暂停或手动继续，无强制作答倒计时。
- LEVEL-02：跑酷有逐段根木/灌木和收集路线；划船有礁石、不同水流和补给；鼓岛有真实节拍谱的热身鼓点与拼音音符；投递有可击碎陨石、补给和星球投递波次。每段有多次可玩的动作，不能只走到一排字母即结束。收集物与节奏反馈只说明运动游戏过程，不进入拼音掌握度。
- LEVEL-03：引擎只依赖纯类型化关卡参数、玩家输入和时间；不导入教学内容或内置固定根木/节拍/任务数。关卡数据、教学题库、运动状态与React呈现分层。数据修改即可改变路线，无需改组件。严格校验关卡数量、12段/3章节、唯一ID、引用、场景一致、障碍/节拍边界和所有分支目标可达；发布门禁包含关卡数据。
- LEVEL-04：服务端选择关卡并冻结路线、模式参数及题实例绑定；刷新、旧备份/新备份、访客和服务重启保留关卡和已完成检查点，不重复写首次成绩。旧会话有明确兼容提示；新关卡启动仍遵守同一游戏时长授权。关卡可任意选择与重玩，难度/速度和教学进度匹配独立；不以关卡号解锁未学拼音。
