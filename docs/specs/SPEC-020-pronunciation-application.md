## MATCH-15 补充：录音与其他课程声音互斥

2026-10-26 完整流程复查：课程录音期间开始整课/其他示范，必须先取消采音、释放麦克风并清除该片段，不提交识别；切换听/写/练活动同样取消。开始采音前停止旧声音，权限请求期间也持有可取消的输入生命周期，不能将示范录入儿童跟读。音频适配器统一管理当前输入或输出，释放旧输入不得停止后来启动的声音。补充对应单元及真实浏览器回归，不改变匹配或掌握度规则。

### 完整复验与修复结果（2026-10-26）

测试使用独立工作树、临时家庭数据库和随机测试端口。初始基线为8fd02ea；期间main合入fde208c新版小卖部，补跑其声音/场景用例，随后将验证快照同步到fde208c与本次MATCH-15修复。未包含主工作区尚未提交的模型研发改动，没有操作真实家庭数据库。

发现并修复：课程采音原先与整课声音可以同时运行；现在其他声音取得播放器、切听/写/练、取消或后台时释放采音并丢弃该片段，不提交识别。补充原生音轨ended状态、权限迟到及旧输入释放不影响新播放的回归。WebKit测试曾因重写stop()方法的调用计数未反映原生轨道状态而失败，改为直接检查readyState，两个引擎连续三轮共18项通过；最终完整真实服务页面54项全部通过。旧长测的折叠题目/反馈选择器也已同步，改为实际展开说明并等待标准音、正确反馈的ended事件，没有放宽资源或保存断言。
