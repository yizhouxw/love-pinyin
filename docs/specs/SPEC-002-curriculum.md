# SPEC-002：课程地图、当前课与学习资料

状态：课程与声音练习已实现并通过内容/桌面软件验证，真机与家庭试用未完成。需求：R-001–003、R-014–016。课程/路线、知识卡、到期标记、书写观察及生活图片均使用实际内容；数量统一见STATUS。

## 文件与范围

允许 `src/app/App.tsx`及课程相关组件、共享可访问 UI、对应课程查询 API、内容呈现测试。按当前完整产品需求扩充原创练习与对应朗读；不得改写既定拼音规则或复制教材图片。

输入：版本化课程、知识点、先修关系及 `ProgressSnapshot`。输出：当前课选择、可浏览课程地图、知识卡和启动会话意图。具体 ID、课名与次序只读 `content/`；家长进度不按固定开学日期或学习周数推算。

## 行为与接口

- 首版固定教材映射，配对后家长选择学校当前课；默认突出首课但必须可改。选择提交使用版本条件更新，不覆盖同时到达的练习事件。
- 课程地图显示课名、学习目标及未开始/练习中/已掌握状态；到期复习是独立标记。算法由 005 提供，当前切片可通过显式 fixture 测 UI，不能临时在页面另算一套掌握度。
- 家长选择当前课会更改自动推荐范围，不删历史、不封锁之前的内容。高于当前课仍可浏览，加入自动学习须家长选择对应课。
- 知识卡显示规范拼音文本、标准音播放入口、原创说明和练习入口。标准音播放经 `AudioPlayer`（003）统一控制；资源未安装或损坏时显示不可用，不提供替代 TTS。
- 课程中无合法可用练习时显示「这部分资料还未准备好」，不创建空会话。正式发布时核心课程出现这种状态即发布阻塞。
- API 的课程清单和详情可在浏览器作只读缓存，但版本更新必须按内容 manifest 原子切换。正在进行的会话持有内容版本，不中途换题。

## 边界与可访问性

文字小屏不截掉调号、ü 或上下伸出的字形；拼音使用合适字形和 Unicode 规范化。页面放大 200%、320 CSS px 宽以及横屏仍能操作。地图不必仿游戏地形；每课必须可通过顺序语义列表和键盘访问。没有任何课程时显示配置问题，不把其解释为儿童已学完。

未知当前课（例如导入旧版本）显示「请选择当前课」并保留历史；内容服务不可达显示连接状态与重试，不默默重置到第一课。
已保存的当前课 ID 不在已加载内容包时，首页不伪装成第一课或显示 undefined；学习路线仍可浏览，练习/复习 API 返回 `CURRENT_LESSON_REQUIRES_SELECTION`，家长重新选课后继续使用原历史记录。

## Given / When / Then

- Given manifest 课程顺序变化，When 载入地图，Then 顺序来自 manifest，无需改组件代码。
- Given 某课知识点存在掌握度和到期复习，When 打开课程地图，Then 显示服务端状态并单独标出到期项，不在前端重算规则。
- Given 家长浏览当前进度之后的一课，When 打开课程卡片，Then 可读知识卡，但开始练习不可用，直到家长调整当前课。
- Given 知识卡缺少已安装且完整的标准音，When 浏览知识项，Then 播放入口明确禁用并显示待准备，不调用系统 TTS。
- Given 家长把当前课从后课改为前课，When 保存，Then 历史事件仍在，只变更推荐范围。
- Given 一张带调号与 ü 的知识卡，When 在手机放大 200%，Then 字形不被裁切且播放/练习入口可访问。
- Given 完全不使用鼠标，When Tab/Enter 浏览课程，Then 可进入和退出任意允许课，焦点顺序合理。
- Given 所需音频缺失或练习集合为空，When 启动该课，Then 明确未准备好且不生成错误会话。
- Given 家庭保存的当前课来自较旧内容版本且新包中不存在，When 打开首页或开始练习/复习，Then 显示重新选课提示、保留学习记录并拒绝创建新会话；家长选一门当前课后，课程路线与既有进度可继续浏览。

## WORD-01：生活图义与拼音关联

第3至14课各提供一个本课可拼读的生活目标，共12个：米、土、瓜、鸡、籽、猪、鱼、水、猫、月、山、星。首两课只教单韵母，不提前引入完整拼读。每项包含原创SVG、中文图义说明、规范带调拼音、既有PinYinSound整音与当前课定位；不拼接声音、不以中文TTS冒充拼音。

每项新增两种不同活动：听标准音在三幅图中找对应物；看图听标准音，试选/预览/确认完整拼音；整体认读音节保持整音呈现并直接选择，不拆分声母韵母。图片选项不显示拼音答案，各有独立中文说明按钮；听说明不提交答案。作为既有听辨/拼读模式的语境练习，记录当前主知识点的一次客观作答，不另推断识字、口语或词汇掌握。课程卡可先看图、听标准音和图片说明，不记录预习分数。所有拼音候选仅使用本课及此前已学字母，干扰图片只作为已知生活事物，不展示其未学拼音。

验收：WORD-01A 原创12图、目标/图片/整音一致、24题及先修/中文说明/资源覆盖校验；WORD-01B 课程图片卡和两种练习进入真实API正常轮转，可保存、刷新和恢复，旧题与冻结版本不变；WORD-01C Chromium/WebKit真实图片和语音，鼠标/键盘/触摸等价控件，说明独立播放、标准音或图片失败重试不计错，图片未全部加载前不能作答；拼读须确认、备份记录准确；窄屏与缩放不替代真机。原课程与标准音信任政策不变，无新依赖。
