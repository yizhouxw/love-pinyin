## 行为与接口

- 首次配对后家长选择教材版本和学校当前课；默认突出首课但必须可改。选择提交使用版本条件更新，不覆盖同时到达的练习事件。
- 课程地图显示课名、学习目标及未开始/练习中/已掌握状态；到期复习是独立标记。算法由 005 提供，当前切片可通过显式 fixture 测 UI，不能临时在页面另算一套掌握度。
- 家长选择当前课会更改自动推荐范围，不删历史、不封锁之前的内容。高于当前课仍可浏览，加入自动学习须家长选择对应课。
- 知识卡显示规范拼音文本、标准音播放入口、原创说明和练习入口。标准音播放经 `AudioPlayer`（003）统一控制；未审核/缺资源时标记不可发布，不提供替代 TTS。
- 课程中无合法已审核练习时显示「这部分资料还未准备好」，不创建空会话。正式发布时核心课程出现这种状态即发布阻塞。
- API 的课程清单和详情可在浏览器作只读缓存，但版本更新必须按内容 manifest 原子切换。正在进行的会话持有内容版本，不中途换题。

## Given / When / Then

- Given manifest 课程顺序变化，When 载入地图，Then 顺序来自 manifest，无需改组件代码。
- Given 某课知识点存在掌握度和到期复习，When 打开课程地图，Then 显示服务端状态并单独标出到期项，不在前端重算规则。
- Given 家长浏览当前进度之后的一课，When 打开课程卡片，Then 可读知识卡，但开始练习不可用，直到家长调整当前课。
- Given 知识卡没有已审校标准音，When 浏览知识项，Then 播放入口明确禁用并显示待准备，不调用系统 TTS。
- Given 家长把当前课从后课改为前课，When 保存，Then 历史事件仍在，只变更推荐范围。
- Given 一张带调号与 ü 的知识卡，When 在手机放大 200%，Then 字形不被裁切且播放/练习入口可访问。
- Given 完全不使用鼠标，When Tab/Enter 浏览课程，Then 可进入和退出任意允许课，焦点顺序合理。
- Given 未审核音频或空练习集合，When 启动该课，Then 明确未准备好且不生成错误会话。
- Given 家庭保存的当前课来自较旧内容版本且新包中不存在，When 打开首页或开始练习/复习，Then 显示重新选课提示、保留学习记录并拒绝创建新会话；家长选一门当前课后，课程路线与既有进度可继续浏览。
