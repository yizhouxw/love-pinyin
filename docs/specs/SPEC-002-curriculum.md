# SPEC-002：课程地图、当前课与学习资料

状态：开发预览中（验收未完成）。需求：R-001–003、R-014–016。结构化课程和路线已进入界面；路线卡呈现服务端知识点状态并独立提示到期复习，课程详情展示内容包知识卡和家长提示；当前课以后的课程可浏览但不能加入练习。仅可练视觉选择题，音频尚未通过时不能向儿童发布听读课。

## 文件与范围

允许 `src/features/curriculum/`、`src/features/onboarding/`、共享可访问 UI、对应课程查询 API、内容呈现测试。按当前完整产品需求扩充原创练习与对应朗读；不得改写既定拼音规则、伪造教师审校或复制教材图片。

输入：版本化课程、知识点、先修关系、审核状态及 `ProgressSnapshot`。输出：当前课选择、可浏览课程地图、知识卡和启动会话意图。具体 ID、课名与次序只读 `content/`；家长进度不按固定开学日期或学习周数推算。

## 行为与接口

- 首次配对后家长选择教材版本和学校当前课；默认突出首课但必须可改。选择提交使用版本条件更新，不覆盖同时到达的练习事件。
- 课程地图显示课名、学习目标及未开始/练习中/已掌握状态；到期复习是独立标记。算法由 005 提供，当前切片可通过显式 fixture 测 UI，不能临时在页面另算一套掌握度。
- 家长选择当前课会更改自动推荐范围，不删历史、不封锁之前的内容。高于当前课仍可浏览，加入自动学习须家长选择对应课。
- 知识卡显示规范拼音文本、标准音播放入口、原创说明和练习入口。标准音播放经 `AudioPlayer`（003）统一控制；未审核/缺资源时标记不可发布，不提供替代 TTS。
- 课程中无合法已审核练习时显示「这部分资料还未准备好」，不创建空会话。正式发布时核心课程出现这种状态即发布阻塞。
- API 的课程清单和详情可在浏览器作只读缓存，但版本更新必须按内容 manifest 原子切换。正在进行的会话持有内容版本，不中途换题。

## 边界与可访问性

文字小屏不截掉调号、ü 或上下伸出的字形；拼音使用合适字形和 Unicode 规范化。页面放大 200%、320 CSS px 宽以及横屏仍能操作。地图不必仿游戏地形；每课必须可通过顺序语义列表和键盘访问。没有任何课程时显示配置问题，不把其解释为儿童已学完。

未知当前课（例如导入旧版本）显示「请选择当前课」并保留历史；内容服务不可达显示连接状态与重试，不默默重置到第一课。
已保存的当前课 ID 不在已加载内容包时，首页不伪装成第一课或显示 undefined；学习路线仍可浏览，练习/复习 API 返回 `CURRENT_LESSON_REQUIRES_SELECTION`，家长重新选课后继续使用原历史记录。

## Given / When / Then

- Given manifest 课程顺序变化，When 载入地图，Then 顺序来自 manifest，无需改组件代码。
- Given 某课知识点存在掌握度和到期复习，When 打开课程地图，Then 显示服务端状态并单独标出到期项，不在前端重算规则。
- Given 家长浏览当前进度之后的一课，When 打开课程卡片，Then 可读知识卡，但开始练习不可用，直到家长调整当前课。
- Given 知识卡没有已审校标准音，When 浏览知识项，Then 播放入口明确禁用并显示待准备，不调用系统 TTS。
- Given 家长把当前课从后课改为前课，When 保存，Then 历史事件仍在，只变更推荐范围。
- Given 一张带调号与 ü 的知识卡，When 在手机放大 200%，Then 字形不被裁切且播放/练习入口可访问。
- Given 完全不使用鼠标，When Tab/Enter 浏览课程，Then 可进入和退出任意允许课，焦点顺序合理。
- Given 未审核音频或空练习集合，When 启动该课，Then 明确未准备好且不生成错误会话。
- Given 家庭保存的当前课来自较旧内容版本且新包中不存在，When 打开首页或开始练习/复习，Then 显示重新选课提示、保留学习记录并拒绝创建新会话；家长选一门当前课后，课程路线与既有进度可继续浏览。

## 验证、交付与禁止范围

2026-09-26 验证增量：儿童练习 E2E 在 320 CSS px 下断言无横向溢出、所有拼读选项高度至少 48 px；将页面文本逐项放大至 200% 后再次检查内容宽度和目标可见性。Chromium/WebKit 五个桌面/平板/手机视口项目通过。该模拟不替代真实设备上的浏览器缩放、字体渲染与手指验收。

`npm run verify`、`npm run verify:server`、`npm run test:e2e` 退出 0；新增用户流程测试覆盖选课、调整当前课、空状态和键盘访问。实际浏览器目视核对拼音、调号、布局，测试文字不能自动证明字形正确。

交付页面、课程查询/设置更新 API、需求证据和独立 commit。禁止新增录音算法、游戏积分商城、排行榜、与内容包并行的硬编码数组。

低成本模型提示：先完成家长选课到知识卡这一条端到端流程，随后补边界。只消费 `KnowledgeId`/`LessonId` 和内容 schema，不把研究文本当成可直接渲染的 HTML。

## BANK-01：每课完整一轮与新增题可达（2026-10-05）

- 每课至少6道不同的可用视觉练习，均有实际中文朗读。以字形、声调、已学声母韵母组合和既定拼写规则扩充；不生成笛卡尔积，不用只改选项顺序的副本凑数。
- 题目、答案、主知识点和语音脚本均写入content；旧ID/内容不变，新包增加版本号。语音准备后全量脚本必须能从真实服务读取。
- 此验收仅补齐逐课练习长度，不声称已满足每知识点5题、听辨标准音或教师审校。保持原掌握阈值和音频准入。
- 在真实API上逐课选课并完成一轮6题，确认没有重复题、超前主知识点和只存在于题库却无法进入会话的新题。

实装：内容包2026.10.05-draft.3新增56道逐题编写的视觉练习，14课均至少6题，全部新增题同步中文指令脚本；旧ID和答案保持不变。coverage摘要重算并加校验防止数字过期。逐课API回归确认全部112道视觉题在至多两轮内可达；教师审校、61道听辨和知识点足量门禁保持未完成。

## BANK-02：补齐原来不足两题的知识点

针对draft.3中客观主目标题不足两道的21个知识点，逐题编写新增练习，使每项至少有两道不同、当前不依赖标准音的视觉练习。题干不能仅改选项排列或复用同题ID，须包含不同观察或应用任务；轻声放在明确词语语境中。不将视觉练习当作辨听，不改变既有requiredModes、掌握阈值或音频准入。

所有新题同步纯中文题干、提示及中文选项脚本；原有题ID、答案、语义保持不变，提升内容版本并重算覆盖摘要。通过真实API为受影响知识点创建两道不同题的到期复习并可作答/结束，工程测试的到期状态只在隔离数据库构造，不改真实家庭进度。至少一个此前缺题知识点完成真实桌面GUI两题复习，使用真实准备的语音。保留教师审校、每知识点五题和标准音门禁。

实装：draft.4新增32题，将原先不足两题的21项各补足两道当前可用视觉题。内容库233题（205客观、28未来朗读），新增题干/提示/汉字选项全部接入私有语音；旧201题、知识点requiredModes保持不变。所有知识点客观题数量至少2，但42项仍有视觉题不足2，79项不足发布五题门槛，不以未就绪听辨充当可用题。

BANK-02验收证据：21项真实API参数化用例逐知识点创建两题、正确提交、结束并检查持久记录；Chromium/WebKit各一次以临时到期计划启动原先只有一题的拼写字母知识点复习，实际播放中文题干、完成两题、小结及结束，导出记录正确。临时到期计划不是掌握度教学效果证据。轮转验证扩大到按实际题量决定轮数，超过两轮仍调用休息完成；144道视觉题全部可达。
