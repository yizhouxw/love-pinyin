## 运行与离线定义

Mac Studio 提供同源 HTTPS 静态网页与 `/api/v1/` 服务；浏览器必须能信任证书，录音安全上下文为真。首次安装可联网下载已核准依赖/资源，正常学习不依赖公网字体、CDN、遥测或在线许可服务。HTTPS 信任建立步骤必须在 iPad/iPhone 实测，不能只在 localhost 浏览器验证。

「离线可用」指互联网断开而 Mac 和浏览器的局域网仍连通。标准音、课程、模型与 SQLite 全在 Mac，四类客观题和本地评分均继续工作。Mac 停机、重启、休眠或 LAN 断开时显示服务不可用，保留当前已展示内容和未确认请求 ID；不得在浏览器生成假分、假保存或静默转云。恢复连接后查原请求结果再继续。

不要求安装 PWA，也不承诺浏览器断 LAN 后独立评分。若使用 service worker，只缓存版本化公开静态文件和标准音，不缓存配对响应、进度 API、录音上传或评分请求；禁止缓存私有数据导致删除后重新出现。可以不用 service worker，通过 Mac 本地完整资源实现断互联网运行。

## 更新、回滚与资产门禁

- 构建产物绑定应用、内容、模型、校准与规则版本。启动前完整性校验；缺失或摘要错误时能力接口准确报不可用，不边运行边联网下载。
- 当前会话延迟更新。内容保留稳定 ID/显式迁移表；不能在新版本删除当前题导致进行中会话崩溃。
- 更新前在本机做数据库事务兼容备份，备份不含录音；回滚必须检查 schema 兼容，不能拿旧程序强开新版库。
- 代码 MIT 不覆盖第三方字体、音频、图像、模型、模板和样本。每一项都有来源、许可、版本/摘要、再分发结论；缺项不得进入公开发布包。
- 标准音均审核通过、资源可获得且发音类型标注正确；课程映射和题库完整性校验通过。PoC 的真样本效果/许可报告应可审阅，原始私人样本不公开。

## 跨端、性能与安全验收

完整执行 [UX 验收矩阵](../product/UX.md)。登记真实设备/浏览器版本并冻结首版支持下限；所有声明支持设备均能配对、听音、完成四类客观题、录音、Mac 本地评分、保存及跨设备读进度。桌面 Firefox/WebKit/Chromium 自动化与手机视口通过不等于 iOS/Android 实机通过。

测量标准音第一次播放、切题、10 秒录音上传与评分端到端延迟；评分预算沿用 000，真实 Mac 不满足则不能以 mock 性能替代。连续 20 分钟练习无持续增长的媒体轨道、未释放 AudioContext/Blob URL 或服务器音频临时文件。

核对局域网请求同源、Cookie/CSRF/来源校验、配对过期及撤销、拒绝未配对评分、上传边界、并发限流、SQL 参数化、敏感日志过滤。使用攻击性输入测试实际保护，不要求与任务无关的企业审计体系。断互联网时记录所有出站请求，没有第三方语音/特征传输；录音处理异常后同样验证释放。

## Given / When / Then

- Given 已安装全部资源且断互联网，When 三类终端经 LAN 完成跟读和练习，Then 有真实评分与跨设备保存，无公网请求。
- Given Mac 不可达，When 用户提交或评分，Then 显示连接问题且无假成功；重连后同一请求只形成一条记录。
- Given 新版本缺音频/模型或摘要不符，When 启动发布候选，Then 阻止相关儿童功能并报准确缺口，不偷偷下载未知资源。
- Given iPad/iPhone 首次访问，When 按部署指引信任证书并配对，Then 录音权限可申请并完成实际评分，不要求关闭浏览器安全机制。
- Given 用户完成删除，When 刷新、离线缓存加载再连网，Then 不重现已删除的家庭学习记录。
- Given 任一教师、许可、评分或真实设备门禁未完成，When 准备发布，Then 发布状态保持未通过且列出责任人/需要的证据。
