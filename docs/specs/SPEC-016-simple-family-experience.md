# SPEC-016：面向小学生和家长的简洁交互

2026-10-24，依据本次全产品交互评审与用户要求。目标是完成全部整改并做完整功能验收。沿用教材、内容、成绩算法、API权限和本地运行边界；不增加依赖。实施按下列验收切片提交。

- UX-01：首页以当前学习和开始为首要内容；课堂学习/天天练入口清晰，完整课程路线按需展开，移除重复课程介绍和过量装饰。配对首次使用先提供直接可理解的连接/体验操作，设备型号放到可选详情。
- UX-02：课程顶部直接选择听一听/写一写/练一练，一次展示一种活动；本课练习首屏可达。生活图片逐张浏览，保留全部图片、示范与中文解释；不把六张图片堆在书写前。知识与家长教学说明按需展开。
- UX-03：书写点选目标自动按笔顺播放对应步骤声音；顶部显示清楚的语音与连读开关，主操作统一为上一项/播放或停止/下一项。语音偏好遵循ADR-0016，切换开关停止旧队列；下方移除重复手动听步骤/占格/纸笔按钮，必要占格/标调讲解随示范播放。逐笔观察保留默认折叠。切组/切目标/离开/后台/失败取消旧声音；不记书写分数。
- UX-04：天天练分为选择材料与正在练习；进入后标题/14份选择收拢到换练习入口，当前份全部小节保留紧凑目录和上一节/下一节（按SPEC-008 DAILY-09补充），当前拼音和主操作位于首屏。提示区始终占位，准备/播放/跟读/暂停/结束只换文字与状态，只有跟读倒数有进度动效，结束倒数不挤动下方按钮。点目录/拼音始终示范，语音开关只控制附加说明。
- UX-05：天天练主流程为听示范/跟读/下一条；可选录音比较单独展开，进入后才展示录音、识别和隐私细节，保留失败不判错与内存清理。目录、组词和家长判断仍可访问；退出不把临时跟读标记算课程成绩。
- UX-06：游戏将必要题目说明与标准示范顺序自动播放；保留明确重听入口和语音开关，标准音要求听完的规则不变，错误不能锁死。提示/反馈/继续在稳定区域；详细讲解按需展开，拼读确认紧邻预览，换题恢复到任务位置。保留首答/修正/跳过/幂等与恢复边界。
- UX-07：家长首屏提供当前课程、近期学习概览与待复习建议；声音/播放设置、详细记录、设备、备份恢复和危险操作分别收拢。导出后显示文件成功提示，JSON仅在技术详情中查看；间隔默认三个节奏，精细加减/数字/滑杆按需展开。权限、导入预览和危险操作确认不削弱。家长设置分组与操作顺序按 SPEC-024 DIST-07。
- UX-08：统一主次按钮、开关、字级、间距、图标与反馈；儿童指令短且可听，技术状态在家长详情。错误用中文原因和对应操作，放在相关操作附近，技术代码仅作详情。保持至少48px触摸区域、键盘、320/390px和200%文字、减少动态效果。正常/加载/错误/反馈状态不让主要控件跳动。
- VERSION-01：增加产品版本号和可读变更历史，所有设备可从轻量入口查看，家长区可见；当前版本由package.json单一提供，历史集中保存，不依赖外网。区分产品版本与教学内容版本；每次版本更新维护说明，不杜撰此前发布记录，不自动公开发布。

## UX-09：跟读与书写的操作位置

天天练拼音的声音设置默认折叠，选材页放在选材之后，练习页放在示范和前后条操作之后。书写课堂的语音与连读收进示范之后默认折叠的播放设置；笔顺播放仍紧邻四线格。保留原有偏好、示范方式、录音入口和语音取消规则。

## UX-10：练习状态切换保持控件位置

复核首页与家长区、课程听写练、两套天天练及游戏。未选、已选、准备、播放、录音、提示及错误等同一任务的状态，在预留区域内切换，主要操作位置不随状态移动。拼读试选的预览和确认占位，跟读失败与录音回放各用固定区域，书写演示保留完整占格提示，场景游戏将保存、提示与作答反馈放在同一位置。主动展开设置、进入另一页面和内容较多的说明仍可按需展开。

## UX-11：就近快捷设置（2026-11-13）

播放和游戏卡片设置采用就近的紧凑入口，展开内容覆盖页面而不挤动主体；宽屏靠近入口，窄屏使用底部面板。一次只展开一个快捷面板，点击外部关闭，Escape 关闭并返回入口。即时偏好保持原保存方式，显式保存的草稿仍须保存。家长设置保留 DIST-07 分组和危险操作确认。依据 Apple HIG Popovers；不新增依赖。自动化验证不能替代真机验收。
