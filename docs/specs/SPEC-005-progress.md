## DATA-01：内容升级后仍能恢复并按原题判分

课程追加或修正后，家庭备份和访客标签页状态可包含不同历史内容版本。接受仓库明确登记且具有完整题目快照的已知版本；未知、未来或缺失快照的版本仍拒绝。header/profile提升为当前内容版本，会话与实例保留原版本；每实例版本必须匹配所属会话，历史题目必须真实存在于对应版本并属于原课。

备份仍使用schema v5及既有预览、摘要、revision、过期与确认替换机制。恢复按历史题库重建题单，历史答案、提示内容、未完成题判分及恢复后的结果均使用实例/会话的原版本；不能用当前题库悄悄改写。访客共享同一校验和恢复代码，状态升级只在当前标签页，不写家庭库、不清空进度。

验收：用真实历史版本数据复现升级前备份及升级后混合版本导出，预览/恢复/再次导出可往返；原题字形和答案保存，实际修改新版答案后旧题仍按旧版判分。未知版本、版本跨接、历史不存在题及坏答案仍拒绝且不改家庭数据。真实Chromium/WebKit通过家长上传旧备份恢复并继续作答，以及访客旧标签页状态升级。现有冻结题测试须同时替换所有实际内容入口，避免只替换未被判题使用的加载函数。

## 文件和契约

## 固定算法 v1

完整依据为 [PRD 第 6 节](../product/PRD.md)。实现时逐条覆盖：

1. 每题实例只有一个首次提交事件；同知识点/题目/北京时间自然日只有第一个事件计入掌握窗口。提示后正确视为未独立正确；重复听标准音不算提示；跳过不计分。
2. 取最新 8 条有效客观题事件。至少 5 条；正确数乘 5 ≥ 事件数乘 4；最近 2 条独立正确；每个 objectiveRequiredMode 至少一条正确，全部满足才已掌握。零事件未开始，其余练习中。客观模式集合为空是内容错误。
3. 首次掌握后次日到期。到期复习 2 道当天未计分的不同题，均独立正确且仍满足掌握规则才通过。阶段 0→1→2→3，对应下次 3/7/14 天，最后维持 14 天；失败重置阶段 0、次日到期。跳过/中断不推进计划。
4. 提前练习不推迟已有到期日。一个知识点每天最多推进一次复习阶段。逾期优先，再按课序/知识点 ID；最多推荐3个知识点，点击一个创建2题会话。
5. 只在家长当前课及以前范围推荐；调整当前课不删历史。会话开始冻结题单，跨午夜不换题；各题按实际服务端接受日去重，下次日期按完成日。
6. Mac 时间回退超过 5 分钟暂停推进，记录待校时练习但不计算掌握；时钟恢复后由家长选择删除待校时记录或保留为不计分练习，不自动重写历史时间戳。

规则版本必须随数据保留，导入历史不能因算法升级无说明地改变状态。当前备份携带masteryRuleVersion=1、进度返回mastery-v1；没有逐事件多版本规则执行机制。后续算法升级前必须补迁移/复习事件版本策略，不能把内容快照当作规则升级已实现。重新计算应在相同输入和 `now` 下完全一致；派生状态可缓存但事件仍为可重建来源。

## 家长页、导入导出与删除

进度展示课/知识点、最近窗口样本量及首次独立正确数、模式覆盖和复习日期。无需输入儿童姓名、学校和生日。不把规则状态表述成专业诊断或考试等级。首版没有跟读摘要或评分记录。

导出 JSON 含 schema/content/rule 版本、UTC 导出时间、匿名 profile、事件/会话/复习/评分摘要及 settings；不含音频、语音特征、配对会话、API 凭据、模型权重。服务器输出固定字段白名单。导出文件最大输入验收为 16 MiB、最多 50,000 条练习事件；超过时清楚拒绝并保持旧数据，不静默截断。随实际容量需求变更需更新 schema 与测试。

导入经过「上传校验 → 预览 → 家长确认替换」；校验 schema、引用、类型/范围、重复 ID、时间、摘要、大小和版本。预览绑定文件 SHA-256、当前数据库 revision 和 5 分钟有效期；确认时任何一项变更则拒绝并重新预览。一次 SQLite 事务替换整个档案，不做隐式合并；故障回滚到旧数据。未知新版 schema 不猜测解析；旧版只能经显式迁移函数。

删除学习记录移除客观题、会话、复习和评分摘要，保留设置/配对/公共资源；重置家庭档案再清除设置并撤销全部设备。两者都需家长管理授权、列清影响和二次确认；取消无变化。已下载的备份无法被服务器远程抹掉，确认页说明。操作完成后其他设备下一次请求应刷新 revision/退出，不继续显示已删除缓存。

## Given / When / Then

- Given 同一事件集以不同数据库读取顺序返回，When 重算进度，Then 结果一致且符合上表。
- Given 家长导入预览后另一台设备新写一条记录，When 确认替换，Then 返回版本冲突，旧数据和新记录均仍存在。
- Given 损坏/超大/未知版本备份，When 导入，Then 全部拒绝、旧数据完全不变。
- Given 有效备份且中途数据库写入失败，When 替换回滚，Then 仍能读取原完整数据。
- Given 删除确认取消，When 返回进度页，Then 记录未改变；确认成功后其他设备也不再取得旧记录。
- Given Mac 系统时间比最近记录回退超过 5 分钟，When 继续作答，Then 记录标为待校时且不进入掌握度；时钟恢复后由家长选择删除或作为不计分练习保留。
- Given 家长撤销一台次设备，When 该设备发起下一请求，Then 认证失败并要求重新配对，家长自身设备仍可访问。
- Given 下载备份，When 搜索内容，Then 不包含录音、特征、配对令牌或私有路径。
