# SPEC-025：Web 屏幕交互调试

- WEB-DEBUG-01：家长高级设置提供 Web 屏幕调试入口。打开同源真实页面，可选择桌面、手机及横竖屏，显示 CSS 像素尺寸。支持关闭；不伪造原生桥接、识别能力或学习结果。预览继续使用当前家庭档案，明确提示会保存真实操作。
- WEB-DEBUG-02：桌面及手机尺寸覆盖首页、课堂听写练、天天练、词语练习、四款游戏、小卖部、家长设置与数据流程，修复溢出、遮挡和不可达控制。自动浏览器验证与人工视觉检查分开记录，不称真机验收。
- WEB-DEBUG-03：工程及发布检查后合并、普通推送，更新本机 Web 与 Mac App 并验证启动，保留家庭数据。

不新增依赖；仅预览窗口改变视口，不改变 API 权限或平台能力。

WEB-DEBUG-02 补充：窄屏课堂向下浏览后，听/写/练切换栏保持可达；点击切换后定位到活动起点，避免留在长内容尾部。大字号仍允许正常滚动，不裁剪内容。
