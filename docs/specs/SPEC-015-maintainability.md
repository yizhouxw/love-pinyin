# SPEC-015：按职责拆分大型模块

2026-10-17，按用户要求优化当前仓库的可维护性。保持产品行为、HTTP契约、教学内容、备份格式、数据库及依赖版本不变。

- MAINT-01：前端入口集中学习状态、导航与当前题交互；课程详情、配对、家长/访客设置、通用确认控件独立成模块。请求适配和待确认答题恢复移出React组件，跨组件数据类型集中声明，避免页面间循环引用。
- MAINT-02：服务端路由按配对设备、课程资源、家庭资料、学习会话拆分；共享认证依赖与备份校验/迁移独立。访客计算直接复用业务模块，保持请求级内存库、鉴权、事务、幂等和历史内容恢复边界。
- MAINT-03：样式按职责归档，保留原始级联顺序；架构文档提供定位导览。执行 `npm run verify:all`、`npm run validate:release` 和真实声音产品浏览器回归，报告实际结果与未完成的外部门禁。

模块方向见[ADR-0026](../adr/0026-feature-modules.md)。不引入框架、依赖、通用仓储层或另一套教学规则。已有业务边界测试继续使用；新增回归聚焦请求及恢复边界，不以行数阈值替代职责判断。

`npm run verify:all`通过：89项前端/工具测试（含14项新增请求/恢复边界回归）、341项服务端测试、30项本机视口测试、34项真实API/SQLite浏览器测试。首次WebKit停服恢复测试因声音和网络警告同时出现而触发定位歧义；改为明确定位连接失败后，Chrome/WebKit定向回归及完整工程门禁均通过。沿用仓库本机Firefox例外，不将视口模拟作为真机。
