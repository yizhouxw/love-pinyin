## 文件、输入与输出

允许 `src/features/exercises/` 的拼读/字形 renderer、`src/features/session/`、共享可访问 UI、会话规划 API 和测试。输入为服务端冻结的 `Session`/`ExerciseInstance`，包括题 ID、内容版本、主知识点、模式、合法选项/格位、标准音 ID。输出为选择/组合答案、提示使用、揭晓/跳过/结束行为；计分事件仍由 001 API 判定。

`blend-choice` 支持按格位点选声母/韵母/调号或合法完整候选，规则由内容题型声明；不能对任意字母做字符串拼接造出非法拼音。当前种子库可先执行视觉拼读，缺完整音节 audioRef 时不假装已完成听音验证；正式发布须补经审校的整音资源，不能机械拼接片段。`symbol-choice` 比较字形或易混项，可选择卡片完成；可选描红不影响通过要求。

## 会话行为

默认 6 题，可提前结束，不按时间评分。开始时服务器冻结内容版本、题实例、顺序和业务日；使用固定 seed 可复现选项排列。题库不足时减少至实际可用题数并说明，空题库不能启动；正式内容完整性门禁另行保证覆盖。

每题一个主知识点，不把同一题正确重复写入全部辅助知识点。首次提交后的改答仅更新反馈状态。短会话保存已提交题与当前位置；返回/刷新不能发出第二次计分事件。未提交的拼读选项可保留为 UI 草稿，但不能表示已保存进度。

页面显示单题、再听、提示、跳过、退出。选错给有针对性的原创提示，动画短且可跳过；不使用负面声效、红叉惩罚、生命值或倒计时。完成小结区分独立首次正确、提示后完成、跳过。装饰奖励只与参与完成相关，不诱导无限刷题。连续两轮后显示休息页，默认焦点在结束。

## 交互与边界

全部拼读可以依次点选与撤销；可选拖拽不是唯一完成方式。键盘 Tab 访问卡片和格位，Enter/Space 选择，清空/撤销是明确按钮。不能让按键输入法、精细路径或外接键盘成为一年级儿童完成任务的前提。

素材均原创或明确授权；不复制教材配图、游戏角色、未审核表情素材。字形不使用装饰字体替换规范目标。屏幕窄时选项换行，不缩到不可点击。

资源失败暂停当前题，显示重试/跳过且不计错。会话中 Mac 断连时保留当前页面，提交标明未保存；恢复后用同一请求 ID 处理，不能离线凭空推进服务器会话。内容更新延迟到本会话结束应用。

## Given / When / Then

- Given 不使用拖拽，When 仅点选或键盘完成拼读，Then 与拖拽得到相同合法答案和反馈。
- Given 首次答错后改对，When 查看小结和数据库，Then 首次结果仍未独立答对，只有一个计分事件。
- Given 做完 2 题后刷新，When 恢复会话，Then 回到未完成任务且原 2 题不重算。
- Given 第 3 题跳过后结束，When 查看小结，Then 跳过单列，不变成错误答案。
- Given 跳过请求重复提交或刷新，When 恢复当前会话，Then 题目仍只标记为跳过，不新增作答或掌握度事件。
- Given 拼读组合题含已审核的完整音节候选，When 键盘 Enter 或触摸选择一个候选，Then 选择其稳定 option ID 交由服务端判分，不在界面拼造候选。
- Given 家长导出家庭数据，When 本次会话包含跳过题，Then 导出同时包含匿名会话信息和跳过实例，不包含设备凭据。
- Given 动画减弱设置开启，When 完成游戏，Then 无必要动画等待，操作焦点正确。
- Given 减少到 320 CSS px 且放大文字，When 选组合卡片，Then 文字/调号可见、48 px 点击区仍满足。

## SELECTION-01：题库轮转（2026-10-05）

普通练习不能固定截取前6题。服务端从当前允许课程及真实资源可用的候选中，按已作答或已跳过次数从少到多选择最多6题；次数相同按最近完成时间从早到晚，完全未做过时沿用内容顺序。顺序由纯函数计算，数据库查询及冻结题单在同一写事务内进行。不把仅创建但未操作的题计为做过；跳过仅影响轮转，不成为学习成绩或掌握证据。题库不足6题仍可返回实际数量，不能凭空补题。

同一题单内部不重复；客户端刷新读取冻结题单而非重选；两轮休息、当前课范围、音频准入、幂等与掌握规则不变。新增题应优先于已完成题出现；删除学习记录后恢复内容初始顺序。到期复习保留SPEC-005独立选择规则。

实装：server/domain.py的plan_practice按完成次数、标准化时间排序；server/api.py在会话写事务内读取真实作答/跳过历史并冻结题单。未作答未跳过的预建题不消耗轮转位置。测试覆盖未做优先、时区归一、顺序稳定、刷新不重排、删除复位，以及14课真实API逐题可达；不新增成绩或数据库表。
