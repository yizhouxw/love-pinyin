# SPEC-004：拼读、字形与短会话游戏

状态：四类客观游戏及真实服务集成已验证，真机和完整输入矩阵未完成。需求：R-005–009、R-014–016。已接入单题卡片、拼读/字形/声调选择、提示、反馈、可恢复跳过和会话小结；课程/题目 API 隐藏答案与提示内容，只在作答或请求提示后返回必要结果。两个完整会话后显示可选休息页，不强制计时且默认焦点是结束按钮；家庭减少动态效果偏好持久化并应用到 UI。真实移动设备、完整键盘与家庭网络验收仍未完成。

## 文件、输入与输出

允许 `src/app/App.tsx`的题目/会话视图、`src/app/learning-voice.tsx`及相关组件、共享可访问 UI、会话规划 API 和测试。输入为服务端冻结的 `Session`/`ExerciseInstance`，包括题 ID、内容版本、主知识点、模式、合法完整选项、标准音 ID。输出为选择/组合答案、提示使用、跳过/结束行为；计分事件仍由 001 API 判定。

`blend-choice`采用完整合法候选的试选、预览、撤销与确认；不自由拼造音节。视觉拼写题无audioRef时不声称完成听辨，声音任务必须播放对应完整标准音，不能机械拼接片段。`symbol-choice`比较字形或易混项，课程书写观察不生成纸笔评分。

## 会话行为

默认 6 题，可提前结束，不按时间评分。开始时服务器冻结内容版本、题实例、顺序和业务日；使用固定 seed 可复现选项排列。题库不足时减少至实际可用题数并说明，空题库不能启动；正式内容完整性门禁另行保证覆盖。

每题一个主知识点，不把同一题正确重复写入全部辅助知识点。首次提交后的改答仅更新反馈状态。短会话保存已提交题与当前位置；返回/刷新不能发出第二次计分事件。未提交的拼读选项可保留为 UI 草稿，但不能表示已保存进度。

页面显示单题、再听、提示、跳过、退出。选错给有针对性的原创提示，动画短且可跳过；不使用负面声效、红叉惩罚、生命值或倒计时。完成小结区分独立首次正确、提示后完成、跳过。装饰奖励只与参与完成相关，不诱导无限刷题。连续两轮后显示休息页，默认焦点在结束。

## 交互与边界

全部拼读可以依次点选与撤销；可选拖拽不是唯一完成方式。键盘 Tab 访问完整候选卡片，Enter/Space 选择，清空/撤销是明确按钮。不能让按键输入法、精细路径或外接键盘成为一年级儿童完成任务的前提。

素材均原创或明确授权；不复制教材配图、游戏角色、来源不明的表情素材。字形不使用装饰字体替换规范目标。屏幕窄时选项换行，不缩到不可点击。

资源失败暂停当前题，显示重试/跳过且不计错。会话中 Mac 断连时保留当前页面，提交标明未保存；恢复后用同一请求 ID 处理，不能离线凭空推进服务器会话。内容更新延迟到本会话结束应用。

## Given / When / Then

- Given 不使用拖拽，When 仅点选或键盘完成拼读，Then 可选择相同合法答案并获得反馈；当前不提供拖拽。
- Given 首次答错后改对，When 查看小结和数据库，Then 首次结果仍未独立答对，只有一个计分事件。
- Given 做完 2 题后刷新，When 恢复会话，Then 回到未完成任务且原 2 题不重算。
- Given 第 3 题跳过后结束，When 查看小结，Then 跳过单列，不变成错误答案。
- Given 跳过请求重复提交或刷新，When 恢复当前会话，Then 题目仍只标记为跳过，不新增作答或掌握度事件。
- Given 拼读组合题含内容包定义的合法完整音节候选，When 键盘 Enter 或触摸试选并确认候选，Then 以其稳定 option ID 交由服务端判分，不在界面拼造候选。
- Given 家长导出家庭数据，When 本次会话包含跳过题，Then 导出同时包含匿名会话信息和跳过实例，不包含设备凭据。
- Given 动画减弱设置开启，When 完成游戏，Then 无必要动画等待，操作焦点正确。
- Given 减少到 320 CSS px 且放大文字，When 选组合卡片，Then 文字/调号可见、48 px 点击区仍满足。

## BLEND-01：可撤销的拼读试选与确认

全部blend-choice采用“选择完整候选—查看拼合结果—确认”的独立交互。候选及答案仍由内容/API提供，不将任意声韵母拼接为新答案。首次选择仅保存当前题实例的浏览器草稿，展示完整音节；可换选或撤销，只有明确点击勾选确认才调用原作答接口。

试选后按家庭自动朗读偏好播放中文操作引导，另有可重复听的玩法说明；不得用中文合成读出候选拼音。确认遵守原题干/标准音播放门槛，声音失败不记错。换选、撤销、仅听玩法均不使用提示、不创建成绩；刷新、跳过、退出或换题清除未确认草稿。确认失败保留当前草稿及原幂等请求，重试不能把失败当已保存。首次答错后仍可试选确认修正，但沿用原来的仅首次计分规则。

键盘、鼠标、触摸使用相同按钮；选择后焦点移至确认，撤销后回到原候选。预览、撤销、确认在320px及200%文字下可见，点击区至少48px，不依赖拖拽或动画。真实桌面GUI验证零提交的试选/撤销/刷新、故障重试与首次错误后修正，检查实际导出记录和网络请求；模拟视口只作补充。

## FEEDBACK-01：作答后的逐题语音讲解

## WRITE-01：四线三格、逐笔观察与纸笔练习

课程知识卡提供有语音的书写入口，按本课明确登记的目标选择字母/组合。content/writing.json集中保存26个基础字母的原创SVG笔画、笔顺、起点、中文逐笔说明、占格、对应教材定位及14课目标；显示使用这些轨迹，不用平台字体代替a/g教学字形，不引入v字形。复合拼音按内容明示的字符顺序组合笔画，不生成未登记目标。四线三格固定显示，基础字母单层a/g，i/j的点在上格，ü两点在上格，j跨三格；高竖和下伸不机械碰第一/四线。

孩子可听玩法、听占格、选第一/上一/下一笔、重看当前笔、看完整字形，随后听纸笔练习提示。各笔以突出颜色、编号起点和有方向的轨迹显示；点选下一笔直接显示完整笔画，不以强制动画等待代替学习，减少动态效果同样可用。目标选择及笔画操作为至少48px按钮，鼠标/触摸/键盘等价。切换目标、退出、后台停止声音；复用全局播放器，不能与课程录音/标准音叠播。声音失败可重试，不计错，也不伪造书写评分。是否自动朗读遵守家庭声音偏好；手动听仍可用。

本轮覆盖26个无调基础字母及显式登记的已学组合，声调书写轨迹由下文WRITE-02补充，不将本轮宣称为完整带调音节书写。纸笔练习仅给中文引导，不记录为答对、掌握或完成轮次。新增三道原创图形占格题，分别针对a中格、b上中格、j三格，附中文题干/提示/讲解；图形由版本化字形引用和明确上下偏移构成，答案仍走原API。已知题版本及新字形数据保留兼容，不改旧题。
