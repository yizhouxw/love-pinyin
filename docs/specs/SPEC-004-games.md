## 会话行为

默认 6 题，可提前结束，不按时间评分。开始时服务器冻结内容版本、题实例、顺序和业务日；使用固定 seed 可复现选项排列。题库不足时减少至实际可用题数并说明，空题库不能启动；正式内容完整性门禁另行保证覆盖。

每题一个主知识点，不把同一题正确重复写入全部辅助知识点。首次提交后的改答仅更新反馈状态。短会话保存已提交题与当前位置；返回/刷新不能发出第二次计分事件。未提交的拼读选项可保留为 UI 草稿，但不能表示已保存进度。

页面显示单题、再听、提示、跳过、退出。选错给有针对性的原创提示，动画短且可跳过；不使用负面声效、红叉惩罚、生命值或倒计时。完成小结区分独立首次正确、提示后完成、跳过。装饰奖励只与参与完成相关，不诱导无限刷题。连续两轮后显示休息页，默认焦点在结束。

## 交互与边界

全部拼读可以依次点选与撤销；可选拖拽不是唯一完成方式。键盘 Tab 访问卡片和格位，Enter/Space 选择，清空/撤销是明确按钮。不能让按键输入法、精细路径或外接键盘成为一年级儿童完成任务的前提。

素材均原创或明确授权；不复制教材配图、游戏角色、来源不明的表情素材。字形不使用装饰字体替换规范目标。屏幕窄时选项换行，不缩到不可点击。

资源失败暂停当前题，显示重试/跳过且不计错。会话中 Mac 断连时保留当前页面，提交标明未保存；恢复后用同一请求 ID 处理，不能离线凭空推进服务器会话。内容更新延迟到本会话结束应用。

## Given / When / Then

- Given 不使用拖拽，When 仅点选或键盘完成拼读，Then 与拖拽得到相同合法答案和反馈。
- Given 首次答错后改对，When 查看小结和数据库，Then 首次结果仍未独立答对，只有一个计分事件。
- Given 做完 2 题后刷新，When 恢复会话，Then 回到未完成任务且原 2 题不重算。
- Given 第 3 题跳过后结束，When 查看小结，Then 跳过单列，不变成错误答案。
- Given 跳过请求重复提交或刷新，When 恢复当前会话，Then 题目仍只标记为跳过，不新增作答或掌握度事件。
- Given 拼读组合题含内容包定义的合法完整音节候选，When 键盘 Enter 或触摸选择一个候选，Then 选择其稳定 option ID 交由服务端判分，不在界面拼造候选。
- Given 家长导出家庭数据，When 本次会话包含跳过题，Then 导出同时包含匿名会话信息和跳过实例，不包含设备凭据。
- Given 动画减弱设置开启，When 完成游戏，Then 无必要动画等待，操作焦点正确。
- Given 减少到 320 CSS px 且放大文字，When 选组合卡片，Then 文字/调号可见、48 px 点击区仍满足。

## WRITE-01：四线三格、逐笔观察与纸笔练习

孩子可听玩法、听占格、选第一/上一/下一笔、重看当前笔、看完整字形，随后听纸笔练习提示。各笔以突出颜色、编号起点和有方向的轨迹显示；点选下一笔直接显示完整笔画，不以强制动画等待代替学习，减少动态效果同样可用。目标选择及笔画操作为至少48px按钮，鼠标/触摸/键盘等价。切换目标、退出、后台停止声音；复用全局播放器，不能与课程录音/标准音叠播。声音失败可重试，不计错，也不伪造书写评分。是否自动朗读遵守家庭声音偏好；手动听仍可用。

本轮覆盖26个无调基础字母及显式登记的已学组合，声调书写轨迹作为后续内容切片，不将本轮宣称为完整带调音节书写。纸笔练习仅给中文引导，不记录为答对、掌握或完成轮次。新增三道原创图形占格题，分别针对a中格、b上中格、j三格，附中文题干/提示/讲解；图形由版本化字形引用和明确上下偏移构成，答案仍走原API。已知题版本及新字形数据保留兼容，不改旧题。

## WRITE-02：带调书写
