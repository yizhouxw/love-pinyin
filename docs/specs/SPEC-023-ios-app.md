# SPEC-023：iPhone 与 iPad 离线应用

2026-11-07，状态：实施中。技术决定见 [ADR-0039](../adr/0039-ios-offline-app.md)。各切片的实现与验收证据见下方记录。

## 产品目标与范围

一年级孩子安装后可以在 iPhone 或 iPad 独立学习。首次启动无需联网、连接 Mac、配对或注册，直接进入学习首页。家长可选课、查看本机学习记录、调整声音、跟读节奏与游戏时长，并通过系统「文件」备份和恢复。孩子从听题到选答、求助、重听或跳过均有声音或可听操作提示；客观题按既有规则计入学习记录。

| 形态             | 家庭使用方式                                                   | 进度与游戏额度                       |
| ---------------- | -------------------------------------------------------------- | ------------------------------------ |
| B/S              | 浏览器访问 Mac Studio 上的服务，沿用访客、配对和本机家长入口   | 已配对设备共享该服务的家庭档案       |
| macOS App        | 桌面应用自带服务与声音，独立离线运行                           | Mac App 自己的家庭档案               |
| iOS / iPadOS App | 同一个通用应用，课程、图片和声音随包，手机和平板可各自离线运行 | 每台设备独立记录；家长可手动备份迁移 |

首版按独立档案设计：iPhone 与 iPad 之间、iOS 与 Mac/B/S 之间均无自动同步。备份恢复是显式替换，导入前展示来源、内容版本和摘要，并由家长确认。家长页写明「仅此设备」及删除 App 后应使用备份恢复的边界。需要共享记录的家庭可以继续通过浏览器访问现有家庭服务。现有 Windows App 仍走其桌面交付路线。

- 学习范围：14 课听写练（标准音、课程录音、笔顺演示、客观题与复习），14 份天天练拼音（听读、跟读节奏、连播、逐字高亮），38 课词语天天练（拼读、纸笔听写、课文背诵与插图），四款有声闯关游戏。
- iOS 首版天天练采用听读模式；录音回放、Whisper、专用拼读识别不纳入。小卖部保留现有明确标识的购物模拟，入口和结算说明其模式，成绩与课程客观题隔离。
- 学习首页沿用同一课程和入口结构。iPhone 以紧凑单栏与大触控区组织操作，横屏及窄高度下保证题干、音频和操作可达；iPad 宽窗使用课程列表与内容分栏或网格，窄窗回落单栏。窗口变化保持当前课程、题目和焦点，不触发作答、重复计分或丢失操作。
- 家长管理沿用现有确认流程。备份文件保留家庭学习档案范围；设备快捷偏好与词语练习的临时标记仍属于各自设备。家长可清空记录或重置档案，两个操作均有明确确认与影响范围。
- 首轮交付通过 Xcode 安装到用户的 iPhone 13，iPad 单独进行真机验收。商店提交与 TestFlight 为后续交付项。

2026-11-07，交付顺序调整。先完成 IOS-04 的四款离线游戏及本机游戏额度，到期复习和跨端备份分别移到 [#36](https://github.com/yizhouxw/love-pinyin/issues/36) 与 [#37](https://github.com/yizhouxw/love-pinyin/issues/37)。

2026-11-07，首页与品牌调整。iOS 使用「爱拼音」与现有四线格品牌图标。共享首页优先展示当前课、练习、课堂学习、天天练拼音、词语天天练和游戏乐园；课程目录次之，使用说明与进度放在入口之后。窄窗使用紧凑入口，宽窗横向排列，大字号允许内容换行。沿用现有配色。真机检查 iPhone 与 iPad 竖屏首屏的入口、点击区域和返回路径，浏览器复核窄窗与宽窗。

## 验收切片

| 编号                      | 通过条件                                                                                                                                                                                                                                  |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| IOS-01 通用应用与离线启动 | Xcode 构建同一 iPhone/iPad target；iPhone 13 安装后断开 USB、关闭 Wi-Fi 与蜂窝，首次启动进入学习首页，显示本机能力与真实课程；Mac 服务停机时同样可用。用竖横屏和 iPad 窄窗验证安全区、布局回落、触摸、VoiceOver、放大文字和键盘。         |
| IOS-02 全量声音与学习界面 | 构建核对所有登记资源与许可证，覆盖 14 课、14 份跟读、38 课词语、四款游戏。用真实人声检查听题、听选项、重听、失败重试、标准音拼接、逐字高亮、长录音暂停/拖动及耳机断开；锁屏或切后台停止学习播放，回前台由孩子决定重播。音频故障不记错题。 |
| IOS-03 本地成绩与家长闭环 | 正确、错误、提示、跳过、复习与掌握结果匹配现有业务规则。崩溃、重启、重复提交或升级后可继续有效会话，首次作答只保存一次。家长可选课、看历史、改设置和清除数据；文件导出、双向迁移和导入取消可用，损坏、未知版本或写入失败不覆盖原档案。    |
| IOS-04 游戏与设备生命周期 | 四款游戏真实启动、过关、恢复及计分；暂停、来电、后台、重启和时钟回拨按既有规则结算本机额度。暂停状态下不继续扣时或收新作答。确认小卖部模拟不写课程成绩，所有儿童流程均无麦克风请求。                                                      |
| IOS-05 三端共存           | 使用同一提交生成课程与界面。现有 B/S 验证访客、配对、Mac 停服提示、家长权限与保存；现有 macOS App 验证独立启动、同机与 Web 服务并存、音频、备份及可选识别入口。Windows 保持既有构建入口并做共享前端回归。                                 |
| IOS-06 安装包与交付记录   | 提供 Xcode 工程、可复现资源准备命令、签名安装与七天续签说明、实测资源和构建大小。压缩下载体积以 180 MB 为设计目标，记录实测差距。iPhone 和 iPad 分别记录设备、系统、构建版本和验证结果；模拟器结果标明模拟。                              |

- **IOS-07 屏幕与系统交互**。按 WebView 安全区内的可用宽高适配。iPhone 窄屏使用单列主入口、紧凑的听题和答题区以及从底部打开的选课面板。宽 iPad 窗口提供保留选中态的课程侧栏和详情。横屏短窗、iPad 窄窗和较大的系统辅助字号可以滚动并回到单列，切换布局不重置题目或课程。主要触控目标至少 44 × 44 pt，支持系统字体大小、可见焦点和 VoiceOver 可读的标签。
- **IOS-08 真机自动化**。使用 XCUITest 的独立测试档案覆盖窄屏首页、听题、作答、旋转和冷启动恢复，并记录 iPhone 与 iPad 的结果及截图。大字号回归另测 320–1024 CSS px；扬声器实际出声、分屏拖动和 VoiceOver 使用仍需人工验收。

设计基线：拟支持 iOS/iPadOS 17 及以上，基于当前前端 Safari 17 编译目标，最低版本需再做运行验证。2026-11-07 本机 Xcode 27.2 已通过 USB 同时识别 iPhone 13（iOS 26.5）和 iPad Air（第 4 代，iPadOS 26.7）。设备识别与开发签名安装已确认，运行验收和最低版本覆盖待验证。

## 实现记录

2026-11-07，IOS-01 工程验证切片：`deploy/ios/` 提供 iPhone/iPad 通用 Xcode 工程、离线资源准备、Swift/WebKit 桥接与音频探针。设备与模拟器目标均可无签名编译，包内已校验 3,602 个声音 ID、字体与课程。验证页读取实际包内课程，通过 WebKit 加载短音频，通过 AVPlayer 请求长录音播放与定位。构建通过，页面行为和实际出声仍需在设备验证。

原始格式资源共 345.6 MB（ZIP 275.6 MB）。独立 AAC 试验资源共 161.5 MB（ZIP 140.0 MB），1,916 个不同 WAV 均通过编码后重新解码的采样率与帧数核对。听感、逐字时间轴及 App 下载和安装大小待实测。默认工程构建使用原始格式资源。

两台设备启用开发者模式后，Personal Team 签名构建均已成功安装（0.8.0 / 1）。首次启动被系统安全策略拒绝，用户随后在设备端配置信任并报告工程验证测试通过。该反馈记录为工程验证，完整学习流程的真机及飞行模式验收仍按表执行。此切片没有接通共享 React 学习页面或本地 SQLite，IOS-01 的学习首页及 IOS-02～06 继续按验收表推进。构建和真机步骤见 [iOS 工程说明](../../deploy/ios/README.md)。

2026-11-07，IOS-02 听读切片（0.8.0 / 2）：用现有 React 课程详情、笔顺、天天练拼音、词语天天练替换工程验证页。Swift 只向包内主页提供课程数据和登记资源。短音复用有界缓冲播放器；长录音用 AVPlayer 提供暂停、进度和定位，并参与同一播放互斥。听读入口无需 Mac 服务或配对，录音入口按 iOS 能力隐藏。Xcode 签名构建已安装到 iPhone 13 和 iPad Air，两台设备锁屏，待解锁验证新界面的实际播放。桌面 WebKit 使用真实包内资源验证了 14 课入口、笔顺、天天练和词语听写导航，并确认真实词语音频播放完成。桥接由测试注入。

本切片的 `npm run verify:all` 和 `npm run validate:release` 均通过。浏览器回归结果单独记录，不作为 iOS 真机验收。

2026-11-07，IOS-03 课堂作答切片（0.8.0 / 3）：iOS 改用共享课堂界面。Swift 从同一内容构建选题，按既有规则冻结题单与选项顺序，提供有声作答、提示、跳过、休息和小结。SQLite 原子保存课堂状态、首次作答回执和学习记录；重新打开继续未结束轮次。家长可选择当前课并查看此设备的答题和完成轮数。标准音播放或写入失败不会伪装为已提交。当前尚未接入到期复习、完整家长记录与备份、游戏和游戏时长。

真机：用户确认两台设备显示上一构建的离线听读页。第 3 构建在 iPhone 13 和 iPad Air 均已签名安装并发出课堂就绪信号，真机完整作答、恢复和断网验收待记录。桌面 WebKit 使用真实包内音频及 Swift/SQLite 服务验证首题听音、作答、重启服务后恢复到第二题，SQLite 恢复、幂等冲突、时钟回拨、跳过、轮数以及 Python 选题与掌握度对照通过。

本切片的 `npm run verify:all`、`npm run validate:release` 和 `deploy/ios/test-classroom.sh` 均通过。单窗口约束下的最终签名包已重新安装到两台真机。

2026-11-07，IOS-07/08（0.8.0 / 4）：按安全区内可用尺寸重排首页、课堂、天天练与选课面板。宽窗课堂侧栏跟随当前查看课，窄窗保留同一详情；短横屏可滚动。接入系统正文和辅助字号，主要操作的触控区至少 44 pt。题号有完整辅助功能标签，听题控件以播放和停止动作读出。

验收已在 iPhone 13（iOS 26.5）和 iPad Air 第 4 代（iPadOS 26.7）各跑通一条 XCUITest。覆盖主要按钮尺寸、听题后作答、横屏保持题号、重开恢复第二题和单条作答记录。报告与截图位于本机 `build/ios/adaptive-phone-r3.xcresult` 和 `build/ios/adaptive-pad-r3.xcresult`。桌面 WebKit 检查八种视口、四种大字号宽度、侧栏收合、选课面板和短窗答题。工程与内容发布检查通过。实际扬声器出声、VoiceOver 操作、系统大字号及 iPad 真机分屏拖动仍待单独验收。

2026-11-07，IOS-04 游戏切片（0.8.0 / 5）：iOS 首页接入森林跑酷、河湾划船、节奏鼓岛和星际投递。复用现有关卡、有声任务和操作规则，按已学范围冻结题单及路线。成绩与课堂记录一起保存在本机。暂停、切后台或重开后可以继续当前题，主动退出结束关卡并保留成绩。家长可设置每次和每日时长，默认分别为 15 和 60 分钟。小卖部在 iOS 使用模拟模式。暂停放在顶部操作区，主要游戏按钮保留至少 44 pt 触控区。

iPhone 13（iOS 26.5）与 iPad Air 第 4 代（iPadOS 26.7）已签名安装。两台真机的 XCUITest 覆盖四款游戏打开、听题后启用动作、触控尺寸、暂停和恢复，另在森林跑酷验证切后台和冷启动恢复。报告及截图位于本机 `build/ios/game-phone-r2.xcresult` 和 `build/ios/game-pad-r2.xcresult`。Swift/SQLite 测试验证四款完整题单、计分、重开、上海跨日、单次及每日额度、暂停和时钟回拨。桌面 WebKit 通过测试桥接调用真实 Swift/SQLite，驱动四款场景各完成作答，跑完森林跑酷一关，并验证家长时长设置及小卖部模拟结算没有写入作答。真机飞行模式、扬声器听感、来电和 iPad 分屏仍待人工验收。

本切片通过 `npm run verify:all`、`npm run validate:release`、`deploy/ios/test-classroom.sh`、`deploy/ios/test-games.sh` 和 B/S WebKit 的 10 项游戏专项回归。

2026-11-07，IOS-07/08 首页与品牌（0.8.0 / 6）：iOS/iPadOS 从资源目录生成系统图标，采用现有四线格「bā」与品牌配色，系统名称为「爱拼音」，页内状态为「离线学习」。首页主卡并列放置「开始今天的练习」与「课堂学习」，后续三项采用整块按钮。浏览器宽窗与 iPad 宽窗横排，窄窗纵排，课程目录紧随其后。打开三个学习分区从顶部开始，返回时焦点回到原入口。天天练的语音开关样式仅作用于天天练页面。设计依据为 [Apple 布局指南](https://developer.apple.com/design/human-interface-guidelines/layout)与[触控尺寸建议](https://developer.apple.com/design/tips/)。

两台真机的首页测试均确认主要入口无需滚动、触控区至少 44 pt，并打开天天练拼音、词语天天练和游戏乐园后返回。报告与截图位于本机 `build/ios/home-phone-r3.xcresult` 和 `build/ios/home-pad-r3.xcresult`。课堂作答、横屏和重开恢复也在两台设备上通过。Chromium 和 WebKit 使用实际家庭服务，在 320、375、820、1280 CSS px 检查首页入口可见并继续进入词语选课。桌面 WebKit 另使用 iOS 测试桥接检查 320–1440 CSS px 的课堂、两类天天练和游戏页，确认无横向溢出并恢复入口焦点；四种宽度的大字号检查通过。真机 VoiceOver 与系统大字号仍待人工检查。

工程检查通过。首次真服务浏览器回归的报告目录被并行专项测试重置，改用独立目录重跑后 68 项全部通过。内容发布检查通过。
