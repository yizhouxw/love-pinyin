# SPEC-024：Android 独立离线应用

2026-11-13。状态：实施中，尚未完成产品真机验收。

## 产品范围

Android 安装后脱离 Mac、服务器与网络独立使用。复用现有 React 页面、content 教学内容和全部已授权声音；覆盖14课课堂、词语天天练、每日练习、四款游戏、本机学习进度与家长文件备份。不得把联网 WebView 包装、环境测试包或模拟识别称为产品交付。不发布商店或公开 APK。

Android 本地识别在可靠移植并独立验证前显示不可用，提供听示范和人工确认，不生成识别结果或分数，不自动下载模型。不复制教学答案、课程顺序或标调规则。全部儿童题目和操作继续有声音引导。

## 验收切片

- ANDROID-01：固定 Kotlin/Gradle 工具链构建安装；随包 React、字体、图片与课程/题目声音；飞行模式冷启动；限制导航和资源访问；缺失资产明确失败。
- ANDROID-02：本机 SQLite 学习档案；课堂冻结题单、首答、幂等回执、revision 与历史内容；进程终止后恢复；存储失败不清库、不返回成功。以共享契约验证与现有服务一致性。
- ANDROID-03：词语与每日练习、四款游戏；沿用家庭额度、上海业务日与时钟回拨规则；后台暂停声音和授权，进程重启恢复待完成关卡；触摸与点击等价操作。
- ANDROID-04：家长通过系统文件选择导出和恢复版本化备份；导入先校验并预览，家长确认后事务替换；无效文件、版本不兼容与中断保持原档案。明确跨端兼容范围。
- ANDROID-05：工程与内容发布验证，真实 OnePlus 设备离线、声音、中断、重启、额度、备份回归；分别记录自动测试、实际设备观察与家庭试用范围。

## 实施约束

工程放在 deploy/android，复用 Android harness 固定工具链及项目隔离 Gradle 缓存。新增依赖记录版本、官方来源、许可与实际构建结果。跨模块平台桥接和业务服务设计在 ADR 确认后实现。资源准备按登记清单与摘要验证，不打包私有目录、家庭数据库、密钥或识别模型。

保护共享工作区其他聊天未提交的改动。每个提交仅包含本切片文件及相关验证；独立 worktree 与 codex/ 分支开发，验收后合并 main 普通推送。桌面/Web 本机交付必须从明确提交构建，不能把其他聊天未提交源码混入并声称来自提交。真机系统授权由用户完成，不绕过。

## 当前证据

ANDROID-ENV-01 仅证明工具链和独立测试 Activity 可构建安装，不计入上述产品验收。ANDROID-01～05 全部待完成。

## 本轮实现

ANDROID-01～04 使用 Kotlin 原生服务与 SQLite 持久化，React 通过统一原生端口访问；课程长音频使用原生 MediaPlayer，短音频复用 Web Audio。备份先提供同 Android 内容版本的独立格式，不宣称与 iOS/Web 互导。系统文件导入后原生预览并确认，按 revision 检查后事务替换。ANDROID-05 记录实际通过范围。

ANDROID-01 图标要求：沿用 public/logo.svg 的四线格 bā 标识，安装后桌面和系统应用列表显示正式图标；提供自适应前景/背景及 Android 13 单色主题图标，不使用默认机器人图标。

ANDROID-02/04 补充：Android 词语练习标记和每日听读的“练过/家长标记”同样写入本机 SQLite，随 Android 学习备份导出恢复；这些是练习记录，不当作自动识别成绩。保存失败保持原标记并提示重试。现有 Web/iOS 标记存储语义不因 Android 适配改变。

ANDROID-03 回归边界：场景游戏仅使用拼音目标时，不应等待课堂专用插图加载；带 pictureId 的拼读题必须能在星际投递命中、保存并进入下一题。Android 音频焦点中断必须同步暂停游戏授权。
