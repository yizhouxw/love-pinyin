# SPEC-003：标准音与语音引导

当前决策：ADR-0008。产品只有学生和家长，直接信任cmguo/PinYinSound为标准音。不设教师审音、审核者、签名确认、待审状态或审核启用流程。旧REVIEW-01–05及SOURCE-01中的审音/草稿机制已取消，历史实现见Git。

## TRUST-01：标准音机制简化

- TRUST-01A：固定来源版本与89个目标映射保存在content/pinyin-source.json。唯一标准音来源为cmguo/PinYinSound；API不再优先读取其他已审资源或本机裁切录音，不返回审核状态。
- TRUST-01B：显式prepare:pinyin下载固定归档或导入本地归档，校验摘要、解码与时长后安装。标准音只按安装、启用、映射和文件完整性决定可用；保留停用/损坏/缺失处理、配对认证、Range和目录边界。运行时不联网补资源。
- TRUST-01C：移除审音台命令、页面、API及审核角色流程。课程卡称“播放标准音”；家长显示来源和可播放数量。儿童/家长界面不出现教师审校、待审音、课程草稿横幅、审核按钮。
- TRUST-01D：课程schemaVersion升级2.0.0，内容版本2026.10.05.6。当前内容格式和发布检查不要求reviewStatus、reviewEvidence、审核者或音频审批状态；不伪造approved。旧备份和冻结题单继续读取，忽略旧审核字段，保持版本/答案/进度不变。
- TRUST-01E：真实Chromium/WebKit在真实FastAPI/SQLite上解码89个标准音，完成课程卡播放、停止、重播、听辨声音失败重试、六题练习和导出校验。断音不计错；损坏、停用、未知ID和越界拒绝，已有成绩不受机制简化影响。

## 语音优先学习（VOICE-01–06）

content/narration.json集中维护全部客观题的中文题干、汉字选项、提示与反馈脚本，拼音目标另作视觉展示。禁止用中文TTS朗读拼音充当标准音。Mac预生成指令，原13课长录音按14课映射，资源保存在private，运行时经同源配对接口提供。

学生首次开始后自动听中文题目；各题、中文选项、提示和讲解均能停止/重听。选择前须听完题干和题目所需标准音，声音失败可重试/跳过，不产生错误作答。全应用单播放器，切题、退出、后台停止声音。键盘、鼠标和触摸等价。

/api/v1/learning-audio返回指令与课程录音可用性；/voice/{id}只允许登记资源；/audio/{id}只允许内容目标映射的PinYinSound标准音。不得接受任意路径/URL，不使用外部CDN、浏览器语音合成或云服务。首版不录音、上传儿童声音或做发音评分。
