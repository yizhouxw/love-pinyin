# SPEC-003：标准音、听辨/声调与 Mac 本地评分

状态：计划中。需求：R-004–007、R-013–019、R-021。依赖 001、002，正式评分接入必须等待 000 通过。没有通过的模型只能保留诚实 unavailable 接口，不能验收本切片。

## 文件与接口

允许 `src/features/audio/`、`src/features/assessment/`、`src/features/exercises/` 的听辨/声调部分、`src/services/` 的音频/API adapter、`server/assessment/` 与对应路由/测试。禁止把第三方云 SDK、评分密钥或未授权标准音放进浏览器包。

使用 `src/domain/contracts.ts` 的 `AudioPlayer`、`AssessmentClient` 和 `AssessmentResult`；接口细节由 [API 契约](../api-contract.md) 规定。内容目标 ID 和音频 ID 必须经过服务器 allowlist 查询，不接收任意 URL、系统路径或自由文本作为模型目标。

音频输入由浏览器麦克风获得，转成 16 kHz 单声道 PCM WAV、最长 10 秒、最大 512 KiB；如果浏览器采集本身使用其他编码，转换须有实测解码/重采样路径且不能误改播放速度。严格验证实际文件头、采样率、通道数、长度和解码后样本数，不能只信扩展名/MIME。

评分 POST 使用同源局域网 HTTPS、家庭会话、目标 ID、唯一请求 ID 和取消信号。服务端用 000 接受的 adapter 执行，返回模型/校准版本。`scored` 才有分数；`uncertain`、`unsupported`、`unavailable` 没有分数。网络层失败单独呈现，不能构造一个 0 分结果。

## 标准音与客观题

全应用同一时刻只允许一个标准音/录音播放器。播放必须由用户手势触发；路由变化、切题、开始录音停止其他声音，避免答案串音。相同按钮连点只重播一次，不叠加实例。

听辨为 `listen-choice`，声调为 `tone-choice`，每题目标与正确选项来自审核内容。tone-choice 有 audioRef 时执行听音选调；无 audioRef 时执行视觉标调题，不要求播放且不能算作听辨证据。当前种子库主要是视觉标调，正式发布必须补足经审校的声调听辨题及其标准整音，不能把种子库存在等同于听辨教学覆盖完成。提示/首次选择/揭晓规则遵循 PRD，播放标准音不算提示。服务端根据题实例/答案判定正确性；客户端即时反馈不作为计分真源，保存结果以服务端为准。

## 录音、生命周期与错误

家长先启用「录音仅发送自家 Mac」功能，浏览器才在明确点击后请求麦克风。拒绝、无设备、证书不信任/非安全上下文、被其他应用占用均有可理解的说明和其他模式入口。不能通过反复弹窗强迫授权。

录音不自动开始；10 秒自动停止；用户可回放、重录、明确发送评分。页面隐藏/卸载、退出、取消与权限撤回须停止全部 media tracks。浏览器保留的音频仅在当前页面内存，路由离开时释放 Blob URL 和缓冲。

Mac 在内存处理并在成功/失败/超时/取消路径清理；不写数据库、访问日志或未经批准临时文件。只保存可导出的评分摘要。按 `requestId` 去重返回已完成摘要；正在处理的重复请求返回同一任务状态，不重复推理。取消不意味着一定没有开始计算，但不得继续持有无用音频；明确最终状态。

最多接纳 3 个请求（1 个执行、最多 2 个排队）；硬排队上限 5 秒、推理上限 5 秒、从发起评分请求起整体截止时间 15 秒，不含最长 10 秒的用户录音。超时结束等待并可查询原请求 ID。正常预算是服务端热推理 p95 ≤ 3 秒、局域网端到端 p95 ≤ 5 秒（录音结束后的准备/上传起计、含排队，不含用户预览停留）。429/503 显示繁忙/尚未准备好，不扣分；退避重试必须由用户选择或最多一次受控自动重试，同一 ID，不能无限占用 Mac。低信噪比、过短、目标不支持等使用稳定 reason code，不能传模型堆栈给儿童。

跟读为 `read-aloud`，分数摘要单独呈现，不写成 `firstTryCorrect=false` 影响客观题掌握度。录音不支持或服务失败不等于儿童答错。维度（声母/韵母/声调）只展示 000 已验证的字段；缺字段不是 0 分。

## Given / When / Then

- Given iPad 首次打开，When 用户点播放，Then 标准音可播放；没有手势时不依赖自动播放。
- Given 标准音播放中，When 开始录音，Then 标准音先停止，没有双重声音；离开页面麦克风立即停止。
- Given 有效 WAV、可用本地模型且 Mac 无互联网，When 发送评分，Then 经 LAN 得到真实结果，网络无第三方请求。
- Given 静音、过短或模型低可信度，When 评分，Then 返回 uncertain 且无数值，不生成错误掌握记录。
- Given 权限拒绝或 HTTP 非安全上下文，When 点录音，Then 说明问题、保留其他练习入口、不循环弹权限窗。
- Given 结果响应丢失，When 用相同 requestId 重试，Then 只有一条评分摘要，不保存/重放原音频。
- Given 恶意超长/多声道/错误头录音，When 上传，Then 服务端拒绝且清理资源，不执行无界解码。
- Given 评分 PoC 未通过，When 正常页面请求，Then 返回 unavailable，不启用开发 mock 或显示假分。

## 验证与交付

运行 `npm run verify`、`npm run verify:server`、`npm run test:e2e`。自动化测试可用清楚标记的 fixture 模拟声卡/API，但正式验收另需真实 Mac + iPad/iPhone/Android 录音、声卡切换、锁屏中断、断互联网及清理证据。模仿真实声音的 fixture 不能作为教育准确性证据。

交付：标准音播放器、两类客观题、跟读 UI/本地评分 adapter、版本化评分摘要、失败与资源释放测试、真实设备记录。禁止范围：第三方云降级、将 ASR 文字匹配直接当发音分、猜测维度分、后台录音、音频长期保存。

低成本模型提示：先读取 000 接受报告和 API 类型，缺报告就只做独立音频/录音与未接入状态，明确剩余阻塞。不要为了跑通页面自创评分公式。把设备问题、信号问题和发音问题分别呈现。
