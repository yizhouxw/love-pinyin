# SPEC-003：标准音资源与客观听辨

状态：首版范围已缩减；不含浏览器录音、发音评测或儿童语音上传。产品范围变更见 [ADR 0004](../adr/0004-defer-pronunciation-assessment.md)。覆盖 R-004、R-005 的音频/听辨部分、R-013；依赖 SPEC-001、002。发音评测从首版移除，不是本 SPEC 的未完成项。

## 目标与范围

管理已授权、经教师审音的标准示范音；在浏览器中由用户主动播放；为听辨/声调客观题提供可审校的音频刺激。音频、许可、目标类型和内容版本必须可追溯。音频缺失或未审时明确显示未就绪，不能用 TTS、ASR 或网上未授权素材补齐。

本期不申请麦克风权限，不录音、不回放儿童录音、不上传语音、不生成发音分/维度诊断，也不保存跟读结果。拼音短音节的 ASR 研究工具只面向维护者整理素材，与产品运行时隔离。

## 资产与播放

示范音必须按目标区分字母呼读、本音、完整音节、词语及必要语境。每项登记来源与授权范围、说话者许可、审音记录、目标/课程 ID、格式、时长和 SHA-256。MIT 代码许可不覆盖声音资产。用户提供素材按 ADR-0005 经私有配对接口播放，不拷贝进仓库，也不自动标为已审标准音。

前端只能通过登记的音频 ID 请求同源配对 API；不接收任意 URL、路径或外部服务地址。播放须有用户手势；全应用单实例；切题、切页、暂停、失败或卸载时停止并释放媒体资源。键盘、鼠标和触摸均可播放/暂停/重播。听辨答案在揭晓前不能从按钮名称或辅助文本泄露。

`listen-choice` 必须播放已审标准音。`tone-choice` 有合格音频时为听音辨调；无音频的视觉标调题只能验证规则练习，不能计作听觉能力证据。客观题由服务端按题目数据校验，发音识别结果不参与。

## 验收

- Given 一个已登记、授权和审校均通过且摘要匹配的标准音，When 儿童通过鼠标、键盘或触摸主动播放，Then 浏览器从同源 API 播放正确资源。
- Given 播放中切换题目、离开页面或重播，When 协调器处理动作，Then 旧播放停止且不叠加实例。
- Given 资源无效、无授权、未审、缺失或服务失败，When 请求播放，Then 显示“标准音待准备/暂不可用”，不外链、不调用 TTS、不伪造音频。
- Given 声调题没有合格音频，When 儿童完成视觉标调，Then 只记录客观规则练习，不显示听力或发音评测结果。
- Given 任意正常首版学习流程，When 浏览器与 Mac 运行，Then 不请求麦克风、不发送儿童语音、不提供跟读评分入口。
- Given 首版配对页、儿童首页或家长管理页，When 用户查看功能说明，Then 不显示“评分验证中”“评分暂未开启”或可启用评分的暗示；可清楚说明本期不使用麦克风。
- Given 音频依赖练习没有已审核标准音，When 创建首版练习会话，Then 不向儿童展示该题；字形、视觉声调和视觉拼读题不显示标准音缺失提示。

## 发布门禁

运行 `npm run verify`、`npm run verify:server` 和适用的 E2E。正式发布还需逐项完成音频来源/授权核对、教师审音、内容映射，以及 Mac/iPad/iPhone/Android 浏览器实际播放验收。评分准确率、录音权限和语音上传不属于本期验收。

## R-022 语音优先实现契约

- VOICE-01：content/narration.json version=1，ui 字典每项 text；exercises 按题目 ID 索引，包含 text（纯汉字中文引导）、hint（纯中文逐题提示，HINT-VOICE-01）、可选 visualCue（可含拼音的视觉目标）、options（需朗读的汉字选项 ID→中文脚本）。所有客观题必须覆盖；禁止直接用 TTS 朗读拼音。
- VOICE-02：Mac 显式准备脚本生成私有 WAV 与摘要清单，用户原有课程 MP3 显式导入私有目录。清单不进入标准音 approved 状态。每个资源含 ID、来源、用途、sha256 和相对文件名。默认 private/learning-audio，可用 LOVE_PINYIN_LEARNING_AUDIO_DIR 指定独立目录。
- VOICE-03：GET /api/v1/learning-audio（配对后）返回 {narration: {id: boolean}, lessons: {lessonId: {audioId,title,available,sourceType}}}；GET /api/v1/voice/{id} 返回已登记且摘要一致的私有音频，使用 Range 与配对认证，不接受路径/任意文本。资源 ID 规则：ui-{key}、prompt-{exerciseId}、hint-{exerciseId}、option-{exerciseId}-{optionId}、lesson-{lessonId}。
- VOICE-04：孩子首次点击开始后，新题自动读中文指令；每题有大号听题/停止按钮和视觉目标，漢字选项用独立按钮听读，不触发作答；提示、正确/错误反馈、小结、休息有语音。浏览器禁播时可直接点按钮恢复。切题、跳页、隐藏后不重叠播放。
- VOICE-05：真实 Chromium/WebKit 在真实 FastAPI/SQLite 上取得实际语音文件并成功解码；验证朗读/重播不创建作答、失败可重试且不计错。缺少语音的安装不得称儿童可用；设置页给出具体准备状态。
- VOICE-06：课程详情可播放用户已提供的整课录音，标为家庭课程录音；不冒充孤立标准音。最新14课与原13课映射写入内容配置，y/w 使用合课录音时明确提示。

首版完成要求覆盖所有可出的题目，不能只为样例题添加播放按钮。网络必须仅访问自有 Mac，不在运行时下载模型或调用第三方。

## 实装记录（2026-10-05）

已实现153个中文语音入口（117题干、23中文选项、13界面引导）与14课私有录音映射；Mac实际生成76份去重WAV，13份源MP3独立复制并校验，清单89个文件约109.78MB。内容脚本改变会令旧声音不可用，再准备时只重建变更项；资源留在Git外。课程录音支持原生暂停、续播及定位。听辨会话与推荐已按真实标准音就绪计算，不再永远关闭，但现有准确单音仍未审核就绪，整课录音不会使它们自动通过。

桌面真实服务验收检查了所有153个语音入口和14课映射录音能解码且非静音，开始/重播/选项朗读不会提交答案，声音失败仍能重试，听完题目前不接受作答。网页与SQLite是真实服务；文件没有用合成正弦或mock Audio替换。此证据证明播放链路，不声称听辨单音和教师审校已经完成。
