# SPEC-003：标准音与语音引导

当前决策：ADR-0008。产品只有学生和家长，直接信任cmguo/PinYinSound为标准音。不设教师审音、审核者、签名确认、待审状态或审核启用流程。旧REVIEW-01–05及SOURCE-01中的审音/草稿机制已取消，历史实现见Git。

## TRUST-01：标准音机制简化

- TRUST-01A：固定来源版本与当前全部目标映射（数量见STATUS）保存在content/pinyin-source.json。唯一标准音来源为cmguo/PinYinSound；API不再优先读取其他已审资源或本机裁切录音，不返回审核状态。
- TRUST-01B：推荐显式run.sh同步Git固定commit并导入；prepare:pinyin保留固定归档下载/本地导入的维护入口，校验摘要、解码与时长后安装。标准音只按安装、启用、映射和文件完整性决定可用；保留停用/损坏/缺失处理、配对认证、Range和目录边界。运行时不联网补资源。
- TRUST-01C：移除审音台命令、页面、API及审核角色流程。课程卡称“播放标准音”；家长显示来源和可播放数量。儿童/家长界面不出现教师审校、待审音、课程草稿横幅、审核按钮。
- TRUST-01D：课程schemaVersion升级2.0.0，后续内容版本独立递增。当前内容格式和发布检查不要求reviewStatus、reviewEvidence、审核者或音频审批状态；不伪造approved。旧备份和冻结题单继续读取，忽略旧审核字段，保持版本/答案/进度不变。
- TRUST-01E：真实Chromium/WebKit在真实FastAPI/SQLite上解码当前全部标准音目标，完成课程卡播放、停止、重播、听辨声音失败重试、六题练习和导出校验。断音不计错；损坏、停用、未知ID和越界拒绝，已有成绩不受机制简化影响。

## 语音优先学习（VOICE-01–06）

content/narration.json集中维护全部客观题的中文题干、汉字选项、提示与反馈脚本，拼音目标另作视觉展示。禁止用中文TTS朗读拼音充当标准音。中文指令按SPEC-011以本地Qwen3-TTS预生成，原13课长录音按14课映射，随仓库保存在resources/audio；固定PinYinSound导入资源留private。运行时经同源配对或访客接口提供。

学生首次开始后自动听中文题目；各题、中文选项、提示和讲解均能停止/重听。按ANSWER-READY-02，题干朗读是可选辅助，未听完、中止或失败都不锁答案；仅题目所需标准音必须听完，标准音失败可重试/跳过，不产生错误作答。全应用单播放器，切题、退出、后台停止声音。键盘、鼠标和触摸等价。

ANSWER-READY-01（SPEC-004）：普通题目短声音首次加载最多等待30秒，开始播放后15秒没有实际进度则报告停滞；重复相同currentTime的事件不延长等待。超时清理媒体与计时器，交由声音失败提示重试，不冒充听完。已完成的本题声音重听中止保留完成状态，必需声音播放失败仍暂停答题；非必需选项声音失败保留单独重试，不阻止已满足标准音条件的作答。

/api/v1/learning-audio返回指令与课程录音可用性；/voice/{id}只允许登记资源；/audio/{id}只允许内容目标映射的PinYinSound标准音。不得接受任意路径/URL，不使用外部CDN、浏览器语音合成或云服务。原课程不录音或做发音评分；每日跟读按SPEC-009仅向家庭Mac内存发送录音作音节匹配，不写入课程成绩。

## 验证与资源边界

npm run verify:all验证工程，npm run test:e2e:product验证实际声音和浏览器流程。内容发布检查仍检查题目覆盖、课标依据、标准音映射和实际资源完整性；不要求教师批准。真正移动设备与局域网场景独立验证，桌面模拟不冒称真机。

标准音信任是产品决定，外部素材许可事实保留在开发文档，不占用学生/家长学习流程。按SPEC-010/011授权的课程MP3、每日PDF和Qwen生成中文素材随仓库提供，保留独立许可；PinYinSound缓存、模型权重、儿童录音和家庭数据不提交Git。源码及原创内容继续MIT。
