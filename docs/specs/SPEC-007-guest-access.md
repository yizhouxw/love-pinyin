# SPEC-007：首页配对与访客学习

日期：2026-10-05。用户要求修复配对入口缺失，并允许不持久化的访客学习。

## 验收切片 ACCESS-01

- 首页始终有“没有配对码”说明。本机访问可生成一次性配对码并自动填入；局域网访问说明在服务器 Mac 打开本机地址生成，或在已配对的家长页生成。不可向未认证的远程设备开放家庭配对码生成。
- 过期或撤销的 Cookie 回到正确的首页，不丢失本机生成入口。
- 无配对码可点击“访客体验”进入完整语音、课程和练习流程；首版仍无录音/评分。
- 访客进度只缓存到当前标签页 sessionStorage，刷新保留、退出清除，不与家庭记录合并，不提供家庭备份/恢复/设备管理。关闭标签页通常会清除，浏览器恢复会话可能恢复缓存；显式退出始终清除。
- 访客仍需要连接 Mac 获取课程、声音及计算结果。每次请求只在独立内存数据库中处理浏览器携带的临时进度，结束即销毁；不写家庭 SQLite、磁盘临时文件或服务端访客会话。
- 复用现有服务端出题、判题、进度与休息算法。访客可选课、查看本次记录、清空和退出；界面持续标明临时模式。
- 浏览器缓存不可用或写满时明确报错，不能假称进度已缓存；网络失败保留原缓存与可重试请求。
- 访客接口严格限制操作和输入大小；不能借访客接口生成家庭配对码、读取或删除家庭数据。声音只允许既有白名单 ID。

## 验证

真实服务桌面 Chromium/WebKit：不配对进入、实际中文语音播放后作答、刷新继续、改课、退出清除、重新进入为空；同时证明家庭数据库学习记录与设备均未改变。API 覆盖隔离、恶意路径、无效缓存、来源及大小限制，现有配对流程回归。

架构见 [ADR-0009](../adr/0009-stateless-guest.md)。此切片不宣称真实 iPad/手机验收，也不关闭题库和课程依据等既有发布缺口。

## ACCESS-01 验证结果

2026-10-05：`npm run verify:all` 通过（40项前端单测、219项服务端测试、30项浏览器边界/视口模拟、6项真实服务桌面GUI）。新增访客真实GUI在 Chromium/WebKit 验证中文题目真实播放、断网提交重试、刷新恢复、选课完成后刷新、退出清除与再进入空进度；前后家庭数据库 SQL 快照完全相同。过期Cookie生成并自动填入配对码后可连接；既有家庭备份/删除/恢复GUI通过。新增访客标准音/课程录音真实GUI另2项通过，浏览器实际解码标准MP3并播放整课录音，全程无外部请求或配对Cookie。

访客模式在内存中锁定，缓存异常不会退回家庭接口；待重试答案使用独立命名空间，退出不会删除家庭重试状态；退出中迟到响应不能恢复已清除缓存。对应单测覆盖缓存写满、损坏/丢失、并发串行与退出竞态。没有新增依赖。

首轮全量浏览器运行受共享预览端口退出影响，已用独立端口回归，并再次完整运行 `verify:all` 通过。最终日志在Git忽略的 `private/verify-access01-final.log`、`private/audio-access01-pass.log`。`validate:release` 仍报告既有的最新课标原文核验和每知识点至少5题缺口；本切片不改变这些门禁。Firefox和真实移动设备不在此次验收范围。
