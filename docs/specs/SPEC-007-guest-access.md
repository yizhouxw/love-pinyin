# SPEC-007：首页配对与访客学习

日期：2026-10-05。用户要求修复配对入口缺失，并允许不持久化的访客学习。

## 验收切片 ACCESS-01

- 首页始终有“没有配对码”说明。本机访问可生成一次性配对码并自动填入；局域网访问说明在服务器 Mac 打开本机地址生成，或在已配对的家长页生成。不可向未认证的远程设备开放家庭配对码生成。
- 过期或撤销的 Cookie 回到正确的首页，不丢失本机生成入口。
- 无配对码可点击“访客体验”进入完整语音、课程和练习流程；原课程不录音或评分。天天练可按SPEC-009自愿录音，经独立访客识别端点仅发送家庭Mac内存，不写家庭档案或客观题成绩。
- 访客进度只缓存到当前标签页 sessionStorage，刷新保留、退出清除，不与家庭记录合并，不提供家庭备份/恢复/设备管理。关闭标签页通常会清除，浏览器恢复会话可能恢复缓存；显式退出始终清除。
- 访客仍需要连接 Mac 获取课程、声音及计算结果。每次请求只在独立内存数据库中处理浏览器携带的临时进度，结束即销毁；不写家庭 SQLite、磁盘临时文件或服务端访客会话。
- 复用现有服务端出题、判题、进度与休息算法。访客可选课、查看本次记录、清空和退出；界面持续标明临时模式。
- 浏览器缓存不可用或写满时明确报错，不能假称进度已缓存；网络失败保留原缓存与可重试请求。
- 访客接口严格限制操作和输入大小；不能借访客接口生成家庭配对码、读取或删除家庭数据。声音只允许既有白名单 ID。

## 验收切片 ACCESS-02：模式与配对管理可发现性

- 页面持续显示当前为访客、家庭家长设备或家庭学习设备；访客状态与“清除并退出访客”在滚动、练习和天天练中仍可见，家长管理内也提供退出入口。
- 访客与家庭模式的家长管理均有配对码管理。本机访问可直接生成一次性码，不因访客或学习设备身份禁用；（已由ACCESS-03收紧：远程家长不再提供管理入口或生成权限）。真实bootstrap在已配对时也返回isLocalHost。
- 访客可在管理页输入有效码连接家庭；成功后清除访客缓存并进入真实家庭档案，不合并临时记录。失败保留访客缓存与输入，允许重试。
- 配对管理请求明确走家庭API，不进入访客临时数据库；访客学习仍保持隔离。远程访客或学习设备提供可操作的本机生成指引，不开放匿名远程生成家庭凭据。
- 显示配对码五分钟一次有效及过期状态，可重新生成；不保留无说明的灰色生成按钮。

## DEVICE-01：设备信息与配对码复制

2026-10-16用户要求：已连接设备显示型号、配对码、最后连接服务时间（年月日时分秒），配对码可复制。

- 配对表单提供设备型号输入；浏览器可给出标明“推测”的类型建议，家长可补全真实型号。旧设备下次认证请求可补全类型提示，家长可修改型号；不采集硬件指纹或保留完整UA，不把推测当成准确硬件型号。
- 设备记录保存本次成功配对所用码，仅家长设备列表返回；标明“已使用，不能再次配对”。历史码未保存的旧设备显示“未记录”，不能从哈希还原或编造；新生成的有效邀请与已使用码均可复制。
- 成功的家庭身份认证请求更新该设备lastConnectedAt，使用服务端时钟，不接受客户端时间；访客学习、失效/已撤销认证不更新家庭设备时间。列表可手动刷新，时间按Asia/Shanghai显示到秒。迁移前无记录显示“尚未记录”，不拿配对时间代替最后连接时间。
- 型号编辑走家长、同源与CSRF保护，限制长度及控制字符，只修改同家庭未撤销设备。设备元数据由SQLite迁移7添加，不改变家庭JSON备份格式或旧学习记录；SQLite备份包含元数据，JSON学习档案不包含设备凭据和设备元数据。
- 复制成功以系统剪贴板写入完成为准；不支持或被拒绝时选中文本并提示手动复制，不伪称成功。移动布局需能操作，桌面自动化不等于iPad真机验收。

## ACCESS-03：家长管理仅限127.0.0.1

2026-10-16用户修正预期，覆盖此前允许远程家长管理的行为。

- 家长管理仅在请求来源为服务器loopback且实际Host为127.0.0.1时开放；localhost、IPv6、LAN地址、主机名均不作为该入口，不能只凭客户端地址或转发头判断。
- 远程家庭/访客界面不显示家长管理按钮，不弹成人确认，也不渲染管理面板；远程有效学习、声音、跟读及访客退出继续可用。访客bootstrap同样返回由真实请求确定的isLocalHost。
- 全部家长读写API和本机配对码生成在服务端实施相同限制。旧远程家长Cookie不保留管理能力；伪造Host或X-Forwarded-*不能把LAN来源变为本机入口。访客修改课程/设置也仅在本机入口允许。
- 新设备只有从127.0.0.1入口配对才取得家长角色，远程首台配对也只能成为学习设备；后续本机配对可以建立家长角色，不被历史远程家长记录阻塞。不删除现有设备或学习数据，不迁移数据库。
