# SPEC-020：macOS 本地应用

2026-11-03：用户要求原生 Mac 应用及 GitHub Actions 安装包，Python 运行时、后端与课程声音随包；Whisper 由家长在应用设置中主动下载。

- MAC-01：应用以本机回环地址启动随包服务并显示界面；退出时停止其服务，家庭数据放用户应用支持目录，升级不覆盖。标准音在构建期校验后随包；不包含数据库、证书或儿童录音。
- MAC-02：Whisper small 可选；设置明确下载大小，家长主动下载固定版本，校验大小和 SHA-256，失败可重试，推理不下载。未安装时不判错。模型存用户目录。
- MAC-03：GitHub Actions 在 macOS 构建并验证安装包，标签触发 GitHub Release。2026-11-03 用户明确授权公开发布包含课程声音的安装包。未签名/公证的包需明确说明。
- MAC-04：README 说明安装、升级、数据与模型、限制；验收记录区分自动化与真实设备。

## 实现与验证记录

本机 Apple Silicon 构建 DMG，并从应用包启动 Python 服务，验证健康接口、首页和退出时子进程停止。构建脚本还以临时数据目录验证随包服务和页面。模型下载权限、CSRF、损坏文件及失败重试有自动化测试；未把合成数据或本机启动等同儿童、家庭设备验收。GitHub Actions 构建及标签发布需以远端实际运行结果为准；安装包未签名、公证，Intel 和真实家庭试用未验收。

工程验证：`verify:all` 的格式、lint、类型、内容、180 项前端、548 项服务端和 36 项本机视口测试通过；真实服务 54 项中 53 项通过，WebKit 窄屏首屏被新增设置挤出导致 1 项失败。将设置移至页面后部后，重建前端并单独复跑该项通过；未将复跑结果描述为完整套件重跑通过。`validate:release` 通过。

远端核实：2026-11-03 GitHub 仓库为公开状态；用户随后明确授权公开发布，移除仅私有仓库发布的限制。标签推送不等于 Release 成功，须检查实际构建和发布结果。
