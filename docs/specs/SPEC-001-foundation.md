# SPEC-001：基础领域、局域网会话与存储

状态：软件验证中（验收未完成）。需求：R-001、R-007、R-009、R-011、R-018、R-019。已有本地配对、CSRF/Origin、SQLite 会话与客观答题 API；儿童区进入家长管理前增加可读成人确认，取消回孩子区；该步骤仅防误触，变更操作仍由服务端家长授权保护。双设备并发提交不同题目时两条事件均保留、revision 各递增一次。断网/响应丢失恢复、迁移故障恢复及真实局域网双设备边界仍未验收。

## 范围与文件

允许修改 `src/domain/`、`src/services/`、`server/` 的领域/存储/会话模块、`schemas/`、相关测试和最小应用路由。内容文稿归内容包，不在此切片新增教材或游戏。SQLite 是进度真源，浏览器缓存只用于请求恢复和 UI，不建立第二套离线进度数据库。

## 输入、输出与接口

- 内容：从 manifest 读取内容版本、课序、知识点、题目/音频引用，完整校验后载入只读内容仓库；无效包不能部分进入儿童会话。
- 会话：家长从 Mac 管理入口取得短时一次性配对码；浏览器配对后使用同源 HttpOnly/Secure 会话凭据。只允许显式配对设备访问档案，令牌不写入 localStorage 或导出文件。具体端点/CSRF 与来源校验以 API/安全文档为准。
- 存储：创建单个匿名家庭 profile；保存当前课、设置、练习会话、客观题事件和评分摘要。表有 schema migration 版本、外键与必要唯一索引；服务启动时原子迁移，失败不重建空库覆盖旧库。
- `ProgressRepository.load(profileId)` 返回包含 revision 的快照；`appendAttempt` 发起有请求 ID 的幂等提交，服务器验证配对权限、题实例、合法选项和内容版本，不信任客户端的 `firstTryCorrect`。
- `occurredAt`/业务日由服务端规范化，客户端时间只能作为非权威观察值；排序和复习日期采用服务器时间及 `Asia/Shanghai`。
- 相同请求 ID 重试返回相同结果；同一题实例只接受第一次有效提交。同一知识点/题目/业务日的掌握度计分资格由服务端唯一键确定，原始练习事件可保留为重复练习且不重复贡献掌握度。
- revision 冲突返回可识别的 409，客户端重新读取后用原请求 ID 重试合法事件；不能全量覆盖别人刚产生的进度。参数错误 422、无权限 401/403、不可用 503，UI 不伪称已保存。

## 状态与边界

数据库写入与事件去重、会话状态更新在同一事务完成。响应丢失后客户端可查询请求 ID；刷新或路由重复挂载不能生成新计分事件。设备撤销后所有后续敏感读取/写入失败并回配对页。

家长管理权限与儿童模式的「进入家长页」误触确认不同，不能用前端布尔值授权导入/删除。配对码 5 分钟过期、一次性使用；5 次错误后冷却 1 分钟，服务端实施限流。精确网络授权策略遵循架构，不开放公网默认入口。

旧内容 ID 不认识时保留历史为只读并提示迁移，不丢弃数据。启动失败显示服务问题和管理入口；无浏览器存储权限时仍可在当前页面使用服务器会话，但请求恢复能力受限需说明。

## Given / When / Then

- Given 有效/无效内容包，When 启动加载，Then 前者可查询全部引用，后者有带路径的错误且不进入学习模式。
- Given 同一题被双击提交和网络重试，When 两次请求到达，Then 数据库只有一个首次事件、revision 只按实际新事务变化。
- Given 两台设备读到同一 revision，When 各完成不同题，Then 两条事件最终都保留，不发生后写覆盖前写。
- Given 响应发出前连接中断，When 刷新并恢复，Then 通过同一请求 ID 找到原结果，不重复计分。
- Given 未配对/已撤销浏览器，When 访问家庭进度或提交答案，Then 无权限且不泄露档案数据。
- Given 迁移失败或磁盘写入失败，When 重启，Then 旧数据库可恢复，不默默生成空进度。
