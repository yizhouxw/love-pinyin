# SPEC-008：PDF 每日跟读

2026-10-13 用户要求将根目录《一年级天天练拼音》做成子功能页，电脑示范、学生跟读并判定读音。此需求允许本功能请求麦克风，更新 ADR-0004/0005 的全局禁止录音范围；原有课程和客观练习仍不录音。

## DAILY-01：来源与完整内容

- 导入 PDF 的14份练习，保留练习编号、源PDF页码、分节、重复音、词语和句子；内容集中在 content/daily-reading.json，NFC 保存。原稿ɑ/ɡ按教学展示使用a/g单层字形，数据正规化a/g并记录来源转换。
- 混合汉字句补齐朗读拼音；原稿未标调的孤立音节必须标明示范声调，不能视为其唯一正确答案；词句轻声保持轻声。保留可核对的原文。原稿组词环节保留口头组词提示，不自动评价所组词语。
- 来源属于用户提供的家庭材料，不宣称MIT；后续按SPEC-010用户授权将PDF加入resources并保留独立说明，不据此宣称取得公开发行整本材料的许可。无新增依赖。

## DAILY-02：语音示范与跟读

- 首页提供“天天练拼音”入口，按14份练习选择，分节逐条展示；点击开始后播中文指令及当前目标的固定PinYinSound序列。词句优先逐音节示范；轻声标准音缺少的42条词句使用SPEC-011本地Qwen预生成、随仓库提供的中文朗读，明确标注，不能称作PinYinSound。
- 支持上一条、下一条、重听、全节连播、停止及换练习。单条跟读由学生主动继续；连播等待与提示按SPEC-012 READ-05和下文DAILY-08执行。连播只听示范，不能记作学生跟读。
- 标准音直接使用固定来源完整归档的登记白名单，摘要校验后经同源API提供。找不到完全匹配音时显示未就绪，不用中文TTS代替拼音，词句也不用近似声调代替；未标调孤立音节的示范声调逐条写入内容注记。
- 所有儿童操作有中文语音说明；全局播放器互斥。换条/退出/后台取消队列；失败不计错。

## DAILY-03：录音与识别判定

- 用户后续要求不训练模型，以语音识别能否识别判断；[SPEC-009](SPEC-009-asr-reading-match.md)为现行契约。停止录音后在家庭Mac运行已有Whisper small，配置拼音场景，并将识别文字转换为拼音核对音节。
- 仅主动点击录音请求麦克风；浏览器只保留当前条录音，回放与示范互斥，重录/换条/退出/后台释放麦克风和对象URL，取消旧请求。上传只到家庭Mac内存，不到外部服务，不保存到数据库、备份或日志。
- 不支持、拒绝权限、非安全上下文和录音错误清楚提示，仍可听和直接跟读；不产生错误成绩。
- 显示识别原文、拼音和matched/different/uncertain/unavailable。仅音节识别匹配，不判断真实四声或专业发音准确度，没有分数和知识掌握度写入；字典声调不能代表录音音高。
- 明确标注的“家长判断”与自动识别结果分别展示，本次标记退出清除。实际孩子跟读、真实麦克风、移动设备与家庭网络仍待试用验证。
