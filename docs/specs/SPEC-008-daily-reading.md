# SPEC-008：PDF 每日跟读

2026-10-13 用户要求将根目录《一年级天天练拼音》做成子功能页，电脑示范、学生跟读并判定读音。此需求允许本功能请求麦克风，更新 ADR-0004/0005 的全局禁止录音范围；原有课程和客观练习仍不录音。

## DAILY-01：来源与完整内容

- 导入 PDF 的14份练习，保留练习编号、源PDF页码、分节、重复音、词语和句子；内容集中在 content/daily-reading.json，NFC 保存。原稿ɑ/ɡ按教学展示使用a/g单层字形，数据正规化a/g并记录来源转换。
- 混合汉字句补齐朗读拼音；原稿未标调的孤立音节必须标明示范声调，不能视为其唯一正确答案；词句轻声保持轻声。保留可核对的原文。原稿组词环节保留口头组词提示，不自动评价所组词语。
- 来源属于用户提供的家庭材料，不宣称MIT；后续按SPEC-010用户授权将PDF加入resources并保留独立说明，不据此宣称取得公开发行整本材料的许可。无新增依赖。

## DAILY-02：语音示范与跟读

- 首页提供“天天练拼音”入口，按14份练习选择，分节逐条展示；点击开始后播中文指令及当前目标的固定PinYinSound序列。词句优先逐音节示范；轻声标准音缺少的42条词句使用SPEC-011本地Qwen预生成、随仓库提供的中文朗读，明确标注，不能称作PinYinSound。
- 支持上一条、下一条、重听、全节连播、停止及换练习。跟读等待没有倒计时；下一条由学生主动继续。连播只听示范，不能记作学生跟读。
- 标准音直接使用固定来源完整归档的登记白名单，摘要校验后经同源API提供。找不到完全匹配音时显示未就绪，不用中文TTS代替拼音，词句也不用近似声调代替；未标调孤立音节的示范声调逐条写入内容注记。
- 所有儿童操作有中文语音说明；全局播放器互斥。换条/退出/后台取消队列；失败不计错。

## DAILY-03：录音与识别判定

- 用户后续要求不训练模型，以语音识别能否识别判断；[SPEC-009](SPEC-009-asr-reading-match.md)为现行契约。停止录音后在家庭Mac运行已有Whisper small，配置拼音场景，并将识别文字转换为拼音核对音节。
- 仅主动点击录音请求麦克风；浏览器只保留当前条录音，回放与示范互斥，重录/换条/退出/后台释放麦克风和对象URL，取消旧请求。上传只到家庭Mac内存，不到外部服务，不保存到数据库、备份或日志。
- 不支持、拒绝权限、非安全上下文和录音错误清楚提示，仍可听和直接跟读；不产生错误成绩。
- 显示识别原文、拼音和matched/different/uncertain/unavailable。仅音节识别匹配，不判断真实四声或专业发音准确度，没有分数和知识掌握度写入；字典声调不能代表录音音高。
- 明确标注的“家长判断”与自动识别结果分别展示，本次标记退出清除。实际孩子跟读、真实麦克风、移动设备与家庭网络仍待试用验证。

## DAILY-04：熟练操作与语音引导开关

2026-10-13用户要求减少操作等待。天天练提供“语音引导”开关，初始版本默认开启（已由DAILY-05的家庭设置继承取代），浏览器本地记住选择；存储不可用时仍可切换。关闭后跳过小节说明、跟读提示、录音前说明和识别结果播报，保留拼音标准音与中文词句示范。点击当前内容直接示范；关闭引导时点击本节条目立即示范该条，不能因旧条异步播放而读错目标。连播也仅播示范。切换关闭时停止当前说明/示范，录音或识别不受影响。重新开启恢复原有引导。设置作用范围随后由DAILY-05统一。

验收：实际声音请求验证默认引导、关闭后的直接发音/连播/录音、切条中断、刷新记忆和重新开启。麦克风拒绝仍不判错。

## DAILY-05：统一设置与就近快捷开关

用户反馈家长页关闭自动朗读后天天练仍播说明。天天练必须继承应用的soundEnabled设置，移除独立默认开启的开关。首页、课程练习导航、天天练当前内容区提供同一设备偏好的快捷开关；无需进入家长页。快捷选择在本浏览器记住，家长设置变更优先于基于旧家庭设置的设备选择；不改家庭权限。旧daily-guidance=off偏好迁移保留，旧on不能覆盖家长关闭。切换关闭立即停止引导，不中断录音/识别；拼音及词句示范可直接点播。入口HTML禁用缓存，避免旧页面继续提供失效开关。验收真实家长设置关闭→天天练无说明、快捷开关跨页面/刷新同步、恢复引导、直接发音和播放中关闭。

## DAILY-06：天天练短音频缓冲与资源准备

2026-10-16用户确认iPad天天练拼音/句子仍卡顿、加载失败。覆盖当前逐片网络流式播放的不足，不改变语音引导、教学间隔、高亮时间轴或学习规则。

- 当前一份练习按API白名单构建去重声音清单，低并发2后台准备；点击当前片段提升优先级并保留一个前台槽，总并发最多3。优先本节说明和当前/下一条，再当天其余资源；不等整份完成才允许开始，不预取14份。
- 拼音、句子、小节说明/组词等短声音完整下载后从Blob播放，当前天编码缓存最多16MiB、128项、单项最多4MiB；不批量解码PCM。共享进行中的同资源请求，重播缓存片段不发网络请求。只保留许可学习声音，不缓存录音或家庭进度，不使用service worker。
- 天天练共享一个HTMLAudioElement，在用户操作时启动短静音以保持媒体激活，静音不触发示范完成/高亮。每个真实片段仍以playing/currentTime/ended通知，不把下载就绪当播放完成。长课程/录音回放保留原生控件与互斥。
- 下载10秒超时，仅网络中断/超时/5xx最多重试一次；404/鉴权/取消/解码/手势拒绝分开报告。播放开始后不自动从头重播，加载/停滞有界；换条停止旧音，退出/切份/后台取消预取与释放Blob URL/编码池，后台回来不自动出声。
- 显示真实准备进度、当前下载/正在播放状态与失败重试；这些状态不计进度。测试请求去重/上限、截断重试、断网重播、取消旧响应、用户激活拒绝、后台恢复、互斥与高亮，最终需用户iPad验证，不宣称WebKit即真机。
