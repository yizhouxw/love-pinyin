# 示范音制作与参考库准入规范

版本：1.0；日期：2026-09-25。当前状态：**未取得生产音频、签署授权或儿童校准样本**。本规范定义可执行制作和交付过程，不代表素材已经存在。

## 1. 三种库分开管理

| 库           | 用途                                          | 权利与访问                                                  |
| ------------ | --------------------------------------------- | ----------------------------------------------------------- |
| 教学示范音   | 孩子点击听读、拼读示范、任务引导              | 必须允许网站/App播放、缓存、剪辑与计划中的公开再分发        |
| 评分参考模板 | 多说话人正确发音与混淆对照，用于本地算法      | 必须单独允许特征提取/模型研究；不自动等同可向用户公开播放   |
| 验证语料     | 教师标注的儿童正确/错误发音，评估真实评分效果 | 取得监护人授权，按批准用途本地受限保存；默认不公开、不进Git |

正式产品用户的练习录音不自动进入任何语料库。它只在本次浏览器/Mac内存处理后释放。只有独立招募、独立授权的研究录音才可以作为验证语料保存，不以“改善体验”默默扩大用途。

## 2. 采购/自录任务书

1. 内容负责人从已审核课程清单导出目标 inventory，按 `targetId + pronunciationKind + tone + context + speed` 去重；保留每个目标对应课程位置，不靠录音师自行推断读法。
2. 先做 15–25 个高风险目标试录：`a/o/e/i/u/ü`、`b/p`、`n/l`、`z/zh`、`an/ang`、同音节四声以及一个三拼连读。教师确认音色、音准、呼读/本音、口令速度后再批量生产。
3. 每条至少录三遍，内容负责人挑选；保留原始 master、未处理片段与最终交付文件的对应关系。一个文件只对应一个明确目标，不把一长段字母歌切成标准声母库。
4. 每课先保证“示范音 + 合法练习目标 + 必要纠错对照 + 简短口令”的完整闭环，然后分批扩展。生产规模由 inventory 实际行数决定，不能将未提供的几百个音节标为已覆盖。
5. 录音者优先有小学拼音教学/普通话教学经验的成人；普通话等级可作为筛选条件，最终仍逐条审音。避免直接录用儿童声线作为唯一标准模板。

报价表按“目标数量、每目标 take 数、自然/慢速版本、试录费用、补录轮次、教师审核、授权范围、原始文件交付”拆分，不在未获得报价时编造预算。首个试录包通过后才扩大制作范围。

## 3. 授权材料清单

由采购负责人在委托前准备并保存签署文件，至少覆盖：

- 委托双方、录音者、录制时间、资产清单/批次及身份核验；录音者确认录制与授权为本人自愿。
- 录音作品和声音使用的权利范围：地域、期限、免费/收费使用、网站/Android/iOS、离线缓存、公开仓库和镜像再分发、剪辑降噪格式转换、署名方式。
- 教学音与特征提取/评分研究分别明确授权；不得从录音使用许可推断允许克隆声音或训练任意语音生成模型。默认不做声音克隆。
- 如未来开源媒体，优先获得可使用 CC BY 4.0 或 CC0 发布的明确授权；记录最终选择。MIT 代码仓库可以包含单独许可媒体，但必须醒目标明，不能把第三方素材改贴 MIT。
- 原始文件交付、质量不合格补录、违约/撤回处理、历史开源分发的处理安排和第三方素材来源保证；涉及第三方声音或已有录音时保留完整权利链。

以上是项目采购要件，不替代实际合同。缺授权签名、范围含糊或不允许所需再分发时，资产状态保持 `rights_pending`；可先做不含该资产的开发，但不得发布教材音。

## 4. 录制与处理标准

以下为项目建议工程参数，由试录审听验证，不是国家教学标准：

- 安静房间、同一麦克风/距离/方向，关闭音乐、混响和美声效果；选稳定自然音色，不故意尖细或夸张。
- Master：单声道 WAV，48 kHz / 24 bit，无削波；保留未降噪版。交付播放版默认单声道 MP3，另保留无损 WAV；参考模板按评分流水线确定性转为16 kHz PCM。
- 示范清楚但不过度拉长；慢读需要自然补录，不以改变播放速度生成教学发音。拼读序列单独录制，不能拼接碎片假装自然连读。
- 文件首尾保留少量静音以免爆破音截断；建议起始约80–150 ms、结尾约150–250 ms，逐条听审优先于机械裁切。
- 同批音量一致、无明显底噪和点击。短单音节响度测量不稳定，不把某个 LUFS 数字当唯一门槛；以不削波、峰值留余量、人工一致性为准。
- 本音、教学呼读、四声、轻声、词语变调均分别标记。使用母语汉字辅助录制时，最终记录真实发音目标，不把汉字音节重命名成单独声母。

转码工具在采用前登记版本、二进制来源和许可。使用 FFmpeg 的某个构建时应核对该构建启用了哪些组件，不能仅凭“FFmpeg开源”认定整个发布包是MIT；建议生产工具留在制音工作站，不把工具二进制随应用分发。

## 5. 资产 manifest 合同

学习内容 schema 与音频生产 manifest 分开。以下是生产 manifest 的最低字段，后续实现可添加字段，但发布准入不能减少：

| 字段                                       | 规则                                                                                               |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| `assetId`, `targetId`, `revision`          | 稳定ID，不用URL当身份；内容改动升 revision                                                         |
| `pronunciationKind`                        | `initial-base` / `initial-call` / `final` / `syllable` / `blend-sequence` / `word` / `instruction` |
| `displayPinyin`, `canonicalPinyin`, `tone` | 展示与机器标记分开；tone 为0–4或null，null不能误作轻声；数字形式只作内部规范                       |
| `context`, `speed`                         | 单独发音/词中/变调说明；自然/慢速                                                                  |
| `speakerId`, `sourceKind`                  | 公开匿名录音者ID；自录/委托/第三方，不存身份号码                                                   |
| `files[]`                                  | 每文件包含相对路径、格式/MIME、采样率、位深或编码率、声道、时长、字节数、SHA-256                   |
| `sourceMasterId`                           | 对应原始 master，可指向私有档案的索引，不公开私人路径                                              |
| `license`, `attribution`, `rightsRecordId` | 许可标识/文本、署名和授权记录编号；公开manifest不含签名/联系方式                                   |
| `redistributable`, `analysisAllowed`       | 是否允许打包公开、是否允许评分研究；明确布尔值，未知为false                                        |
| `reviewStatus`, `reviews[]`                | pending/rejected/approved；内容与音质审核者、日期、结论及问题编号                                  |
| `productionStatus`                         | planned/recorded/rights_pending/qa_pending/approved/retired                                        |
| `usage`                                    | teaching/reference/both；模板算法版本另有manifest引用此assetId                                     |

草稿可以没有文件，但不得伪填路径/哈希。发布所用条目必须 `productionStatus=approved`、双审通过、文件存在且哈希相符、权利范围满足用法。未授权、未审、退役素材一律不能被“临时打包”。

示例草稿只展示真实缺失状态，不可直接供播放：

```json
{
  "assetId": "initial-b-call-natural-v1",
  "targetId": "initial-b",
  "revision": 1,
  "pronunciationKind": "initial-call",
  "displayPinyin": "b",
  "tone": null,
  "productionStatus": "planned",
  "reviewStatus": "pending",
  "redistributable": false,
  "analysisAllowed": false,
  "files": []
}
```

## 6. 双人审核和发布门禁

内容审核者：逐条核对目标、声韵、声调、轻声/变调、拼读过程、呼读/本音和课程版本；混淆音成组盲听，不能只看文件名就签字。音质审核者：确认无截断、削波、杂音、过长空白、异常音量和文件解码错误。两类审核由不同人独立给出，分歧退回补录；教学错误没有“低优先级豁免”。

自动发布检查至少包括：

1. 所有可发布课程引用的 audio ID 唯一存在；每条课程所需音频覆盖100%。
2. 文件扩展名、真实编码、manifest一致；不存在空文件、超限时长、哈希漂移或缺失版权记录。
3. 播放资产必须允许播放与分发；评分模板必须允许分析；验证儿童语料不得混入 public/dist。
4. 当前首版发布目标的字体、示范音、评分引擎和课程内容版本相互匹配。
5. 真机审听覆盖桌面、iPad、iPhone、Android；首次点击、快速连点、横竖屏、静音/蓝牙和网络失败均不误导孩子。

## 7. 评分参考和基准制作

教学示范与评分模板的目标不同：示范需要清楚一致；模板需要涵盖合法说话人/设备差异。首轮不使用同一录音者同时充当全部参考与测试。为每个试验目标准备正确样本与明确混淆样本，记录目标、实际读音、环境、设备、重复take、两个教师的独立判断；不公开儿童真实身份、学校、精确生日。

基准划分以说话人为单位，建议 train/calibration/test 三组；同一录音的裁切/变速/降噪版本随原样本进入同组。教师分歧先仲裁或保留 `uncertain`，不能强行当作确定真值。噪声/无声与错读是不同标签。评分、声调、拒判指标按任务类别及设备分别报告；不允许只给一个总平均数掩盖声母错误。

首次研究语料应覆盖6–7岁目标人群；正式规模、招募方式和保存期限要在录制前确定。用户日常录音默认丢弃，不得因为缺数据在实现中自动加入训练集。

本规范没有提供可发布声音资产；完整获取状态和技术证据见 [语音与资产调研](../research/audio-and-assets.md)。

## 本机审音台（2026-10-05，REVIEW-01–05）

源音、机器候选、草稿和已确认家庭标准音分开管理；流程见[ADR-0006](../adr/0006-private-standard-audio-review.md)。本工具替代手工改清单的家庭制作流程，不自动完成教师审音或公开授权。

```sh
npm run audio:review -- \
  --source '/Users/chad/Documents/1汉语拼音音频' \
  --candidates '/Users/chad/Documents/1汉语拼音音频/提取候选_20260927'
```

第一次显式导入13份原始MP3及427段候选时间码。Mac自带`afconvert`转换为16kHz单声道PCM，仅存入`private/audio-review/sources/`；原文件不修改。再次导入核对源摘要和转换缓存摘要。浏览器打开 http://127.0.0.1:8019 。以后已有素材时只需`npm run audio:review`。

1. 选择课程，筛选候选转写；先听原录音。机器转写可能把单音误成汉字，不能据此确认目标。
2. 调整起止秒数，试听裁切；完整片段须在0.1–20秒内。选择实际听到的拼音目标并保存草稿。
3. 由教学审音者、另一位音质核对者分别试听，填写名字并勾选对应确认后启用。工具不会代签、默认确认或自动选择拼音。
4. 已确认文件写到`private/standard-audio/`。学习API动态发现，儿童新会话可以使用依赖该声音的听辨题，无须改公开内容JSON或重启。听辨题若还需其他未备齐声音仍不会出现。
5. “从家庭练习撤下”立即停止新请求和新会话使用该文件；已下载到浏览器的声音无法收回。新草稿不会自动覆盖正在使用的声音。修改目标语义、摘要不符或撤下清单都会使其不可用。

两位核对者记录仅证明本家庭主动确认，不构成身份认证、教师资格认证或公开授权。全部录音和签名记录留在Git外。工具仅监听本机127.0.0.1，不向局域网儿童端开放编辑；拒绝异常Host/Origin、远程连接及无令牌写入。不要经反向代理公开审音台。

测试的合成PCM只证明帧裁切/摘要/准入；实际课程录音GUI测试只保存隔离临时草稿，**不签署真实素材**。公开发行继续使用`validate:release`门禁。
