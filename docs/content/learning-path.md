# 学习路径与内容使用规格

本路径是面向小学一年级的**项目建议**，按已核验的 2024 修订统编人教教材顺序组织；课标版本研究和限制见[课程研究](../research/curriculum.md)。它不是全国统一逐周教学计划。

## 学校进度优先

监护人在首次进入时选择学校当前课号（1–14）或“还没有学拼音”。默认只开放当前课及此前复习，允许监护人修改。不根据日期猜测学校进度，不通过游戏奖励诱导越级。

基础为零的孩子从第 1 课开始；已有基础可由监护人选已学课，短诊断只调整复习推荐，不凭一次分数把孩子永久贴成薄弱。进入新课之前可跳过已经看过的演示，但不能隐藏遇到困难时重新示范的入口。

## 一次学习的节奏

一次默认约 8 分钟，是待试用调整的产品设置，不是医学或课标规定。孩子随时可暂停退出并保留进度；约 5–10 分钟完成一段后给明确收尾和离屏活动邀请。

1. 复习 1–2 个已学点，优先选之前需要帮助的内容。
2. 进入当课一个小目标，显示简短图形提示，播放一段经教师审校的标准音。
3. 用 2–3 种形式练习同一目标：听选、拼合、跟读；游戏反馈直接解释学习点。
4. 错误后示范、缩小选项并重试；不扣生命、不倒计时、不要求连续签到。
5. 做一个迁移题，展示本次练过哪些声音，然后结束。题库不足时诚实重复练习，不声称是新材料。

示例玩法“声音投递”可在桌面点选后按 Enter，触摸可直接点击选项；拖放有点击替代。动效用于表现声音组合和声调，不在题目期间自动播放无关奖励。

## 熟练度与复习

唯一算法依据是 [PRD 第 6 节](../product/PRD.md#6-掌握度规则-v1)，由 [SPEC-005](../specs/SPEC-005-progress.md) 实现与测试。本文不另定义状态、阈值或复习间隔。到期复习是独立标记，不是第四种掌握状态。

`requiredModes` 只允许四种客观题型：`listen-choice`、`symbol-choice`、`tone-choice`、`blend-choice`。`read-aloud` 不进入客观掌握窗口；可用朗读活动从题目与 `readingTargets` 获取，家长单独查看跟读结果。书写观察另列，不用选择题正确代替会写。

当前种子库只有 117 道客观题：59 个知识点不足两道不同客观主目标题，81 个知识点不足五道。它可以支持功能开发与局部演示，不能用来宣称完整体验掌握与复习流程。正式发布每个知识点至少五道不同客观主目标题，并保证可复习点有两道不同客观题；朗读题不能抵数。这是产品的内容数量门槛，不是已验证的教学效果标准。

遇到题量不足时，研发不得自动生成未经审校的题或修改算法来凑数。完整算法验收使用明确的测试 fixture，儿童正式包须先补齐题库。解锁仍服从课堂范围与已完成学习活动，不以模型置信不足锁住后续学习。

## 内容 JSON 契约

| 集合                 | 稳定主键                                                           | 用途                                                     |
| -------------------- | ------------------------------------------------------------------ | -------------------------------------------------------- |
| `knowledgeItems`     | `k-initial-b` / `k-final-v` / `k-whole-yu` / `k-tone-1` / `rule-*` | 音形、规则、来源、教学说明、混淆对象与已覆盖题型         |
| `lessons`            | `lesson-01`…`lesson-14`                                            | 课序、教材定位、先修课、知识项、目标与练习引用           |
| `exercises`          | `q-01-01` 等                                                       | 原创题干、选项、标准答案、主知识项、语音引用、审校状态   |
| `readingTargets`     | `rt-03-ba1` / `rt-03-initial-b` 等                                 | 完整音节、声母教学音或孤立韵母的显式目标，不自动生成发音 |
| `audioRequirements`  | `audio-*`                                                          | 待自录标准音和操作指令脚本；不是现成可用音频             |
| `supplementalTopics` | `ext-*`                                                            | 字母表、语流变调、隔音与词界；与14课主路径区分           |
| `coverage`           | 聚合字段                                                           | 种子库数量与不足，不作为学习效果证据                     |

当前 83 项基础知识均有至少一道客观主目标题；145 题由 117 道客观题和 28 道朗读题组成。`coverage.objectivePrimaryExerciseCounts` 明确逐知识点客观题量；`requiredModes` 是当前客观主目标题的模式要求，不能据此推断听说读写全部覆盖。题目选项 ID 是答案引用；前端可以随机排列，但必须保持 ID，不按数组位置判题。

音节表无调的 zi/chi 等辨听素材采用第一声教学示范，题目只考音节字形；无调拼写不自动解释成轻声。声母素材不能念英语字母名，韵母素材不按独立汉字词生成语音。

`listen-choice` 须播放 `audioRef` 对应的已审音频；找不到资产时应提示资源未就绪，不能静默改成系统 TTS 字母名。`read-aloud` 关联 `readingTargetId`，先处理录音有效性，再请求局域网 Mac Studio 本地评估服务。音频不传第三方，处理后丢弃；此策略由语音与隐私规格共同约束。

朗读库现有 79 个目标，明确区分：

- 21 个 `isolated-initial`，`pronunciationForm=teaching-call`：教师审校的声母教学呼读音，不按英语字母名发音，不直接当作纯辅音本音；复用 `audio-initial-*`。
- 24 个 `isolated-final`，`pronunciationForm=final-sound`：孤立韵母；原第 2 课 i/ü 目标有明确第一声，其余目标先只评音段。
- 34 个 `syllable`：其中 16 个按 `pronunciationForm=whole-syllable` 完整覆盖整体认读，18 个为其他已知合法的带调音节。

每个目标有 `primaryKnowledgeId`、`audioRef` 和 `pronunciationForm`。孤立音目标 `syllables=[]`，使用 `phoneme`；`phoneme.tone=null` 表示该任务不设声调评分维度，**不是轻声**。数字 `0` 仍只表示需要语境的轻声。完整音节保留 `base/tone/marked`，不能把 i 教学音与 yi 拼写互换后假称评估了同一任务。所有目标均 `pending-local-poc`。

新增的 51 个目标登记在各课 `readingTargetIds`，尚未配套朗读游戏题；它们是评分 PoC 和后续内容扩展的明确范围，不表示现有 28 道朗读题已覆盖全部目标。

### 题干、选项提示音和声调听辨

全部 145 道题有 `promptAudioRef`，对应 60 个独立题干脚本；23 个含汉字选项有 `option.audioRef`，复用 18 个独立脚本。这 78 项资源使用 `kind=instruction`。稳定 ID 为 `audio-prompt-<文字哈希>` 或 `audio-option-<文字哈希>`，相同文字复用，改写文字须生成新 ID，避免旧录音串用。

总计 167 项待录资产 = 89 项标准发音 + 78 项指令。它们全部 `not-recorded`，只提供原创脚本，不生成 TTS，也不宣称无需认字的独立操作已经可用。正式发布需录制、审校并校验这些引用。界面通过儿童显式点按播放题干和含汉字选项；所有播放遵循统一协调器，录音前停止播放。

纯拼音选项不增加选项语音引用，也不能在答题前自动念出，避免泄露听辨答案或改变任务。指令中的拼音符号由教师按任务目的审校读法；不能把需要孩子判断的音调作为旁白答案念出。

现有 16 道 `tone-choice` 是视觉标调与认调号，未提供声调听辨题。**补齐带审校音频的声调听辨是正式发布门禁**：四声均须有真实听辨任务，轻声在明确词语语境中覆盖。可使用 `listen-choice` 并以相应 `k-tone-*` 为主知识点；必须有合法目标音节与标准音，题面不得提前显示正确音调。视觉声调题、跟读分数不能抵作这一覆盖。

## 内容加工与发布门槛

当前机器状态使用 `needs-teacher-review → approved`。批准之前分别完成教师文字审校、音频复核与权利核验，并保存审校证据；模型目标也必须由 `pending-local-poc` 转为 `validated`。当前整个库仍待审，研发可使用它开发功能，但面向学生的正式版本必须只加载通过发布校验的内容包。

每次内容变更单需列出：变更知识点、原值/新值、依据、受影响练习/音频/评分目标、教师审校记录。修正错别字可保留 ID，改变题目语义或答案必须提升内容版本；已完成记录不能直接套上含义已变化的题目。

内容版本、音频版本、评分模型版本分开存储并一同记录到尝试结果。库内没有教材原文、插图或出版社音频；后续也不能为了快速补齐内容直接抓取它们。

## 本阶段交付与后续缺口

已交付：版本研究、3 单元14课路径、完整基础分类、规则项、原创种子题、朗读目标和音频待办。仍需：2025课标原文逐条差异确认、2026实际印次核对、教师审校、原创发音录制、书写图形、迁移题与阅读短句，以及本地自动评分 PoC。

这些工作可并行于界面开发；教师审校和评分验证是面向学生发布前必须闭合的事项，不是要求研发等待所有内容完美才开始。
