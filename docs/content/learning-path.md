# 学习资料库与实际学习路径

首版只配置中国大陆统编人教版课序，家长选择学校当前课；没有教材切换、入门诊断或按开学周数自动推进。具体课名、顺序、知识ID和先修关系以 [`content/curriculum.json`](../../content/curriculum.json) 为唯一机器来源，依据见[课程研究](../research/curriculum.md)。

## 课程与活动

| 课程范围  | 内容方向                     | 当前活动                                   |
| --------- | ---------------------------- | ------------------------------------------ |
| 第1–2课   | 单韵母与四声                 | 标准音、声调听辨、字形/标调观察、书写示范  |
| 第3–8课   | 声母与拼读                   | 完整音节听辨、点选拼读、易混字形、生活图片 |
| 第9课     | y/w及相关拼写                | 独立课序、整体认读与拼写规则               |
| 第10–14课 | 复韵母、鼻韵母和相关整体认读 | 声音对比、拼读/标调、图片与书写观察        |

儿童可先听课程录音、看知识卡、听逐目标标准音，再进入练习。书写入口提供四线三格、逐笔和纸笔提示；生活图片卡提供标准音与中文图义。这些课程活动不生成纸笔或口语评分。

## 一轮实际流程

1. 普通练习从当前课可用题中选最多六题，未做题优先，再按已完成/跳过历史轮转；不会自动插入一套“热身—迁移题”模板。
2. 中文题目先朗读，听觉题还须听完标准音；中文选项可单独重听。声音或图片失败时重试/跳过，不判错。
3. 字形、听辨、声调直接选择；拼读先试选完整合法候选、预览、撤销，确认后才提交稳定选项ID。当前无逐格自由组装或拖拽。
4. 提示会影响独立首次正确资格，但重复听标准音不会。答错后可听讲解和修正，不缩小选项、不覆盖首次成绩。
5. 完成或提前退出后看小结；只有所有题已答/跳过才计完整轮次。两轮后进入休息页，无强制倒计时。

目标时长约5–8分钟是待家庭试用的设计假设，不是强制时间或教育效果结论。支持键盘/鼠标/触摸的控件不代表所有真机已验收。

## 掌握与复习

唯一算法依据为[PRD第6节](../product/PRD.md#6-掌握度规则-v1)，实现/边界见[SPEC-005](../specs/SPEC-005-progress.md)。到期是独立标记，首页最多推荐三个知识点；点击一个进入两道不同题的复习，不是自动合并成六题。

每知识点至少五道不同客观主目标题，可复习点至少两道合法题；四类requiredModes由内容配置，不能因题量不足降低算法门槛。当前覆盖已通过检查，数量见[STATUS](../STATUS.md)。这些规则只描述应用练习，不证明会写、会说或考试能力。

## 内容契约与声音

| 集合                          | 用途                                                 |
| ----------------------------- | ---------------------------------------------------- |
| lessons / knowledgeItems      | 课序、知识点、来源、说明、必需题型                   |
| exercises                     | 原创题目、稳定选项ID、答案、主知识点、声音引用       |
| audioRequirements             | 历史及当前声音需求登记；不是“所有条目都为标准音文件” |
| readingTargets                | 保留的未来研究目标，不进入首版会话或掌握窗口         |
| supplementalTopics / coverage | 补充主题及自动计算的覆盖摘要                         |

标准音目标/来源以 `content/pinyin-source.json` 为准，中文脚本由 `content/narration.json` 与书写/图片内容组合生成。中文TTS不朗读拉丁拼音充当示范；纯拼音选项不自动念出泄露听辨答案。目标NFC保存，ü展示正确；内部v仅用于约定ID/输入。

四声听辨的a/o/e各四声必须听音后选择，同题重新出现仍需重听。视觉标调不能当作声调听辨证据；无调音节的带调示范也不能解释为轻声。声母使用教学呼读音，整体认读完整呈现，不机械拼接文件。

## 维护边界

标准音直接信任PinYinSound，无审音审批。修改教学语义或答案前保留历史快照并提升内容版本，旧会话按原题判分；选项顺序由服务器按实例冻结，前端不能自行重排。CURR-02已核对最新课标相关拼音条款，其他研究范围不得扩大声称。私有声音与家庭数据不入Git，内容正确性、实际设备和儿童理解仍需分别核对。
