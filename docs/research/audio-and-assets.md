# 声音与素材方案

首版声音分成三类，不能互相替代。当前机制见[ADR-0005](../adr/0005-voice-first-product.md)、[ADR-0008](../adr/0008-trusted-standard-audio.md)。已取消的评分SDK比较、声学性能预算与审音流程不再作为实施指引；历史可从Git查看。

| 类别       | 实际来源与准备                                  | 运行用途与边界                                                      |
| ---------- | ----------------------------------------------- | ------------------------------------------------------------------- |
| 拼音标准音 | 固定cmguo/PinYinSound，由prepare:pinyin显式安装 | 逐目标示范和听辨；不使用TTS、长课录音或机械拼接替代                 |
| 中文引导   | Mac已安装Tingting，由prepare:voice本地预生成    | 中文题干、选项、提示、反馈、导航、书写/图片说明；不把拼音读成字母名 |
| 课程录音   | 家长提供的13份MP3，按lesson-recordings.json登记 | 映射14课，第2/9课共用旧合课录音；旧页码不代表新版教材页码           |

## 标准音依赖已落地

准备脚本核验归档与文件摘要、解码/时长及非静音；运行时核验映射和文件完整性，只从Mac同源API播放。应用直接信任该来源，无教师/家长审音批准、草稿审批或多来源回退。无调目标使用内容清单明确记录的示范声调，不从文本猜文件名。

该归档未附明确LICENSE，登记为unknown；产品信任声音不等于获得再分发许可。原始文件、归档和安装产物都在忽略目录，不作为MIT资产发布。

## 资源交付与许可

中文脚本和原创题目可随代码MIT分发，Mac系统音色生成的声音不据此宣称可公开再分发。家长课程录音只作本机家庭素材，须保留原来源与课序映射。图片与书写轨迹为仓库原创实现，教材或政策引用不授予其配图/录音许可。

资源缺失时明确报不可用；准备脚本不能自动下载系统音色，运行时不能联网补素材。制作命令见[音频制作](../content/audio-production.md)，系统依赖见[依赖记录](../engineering/dependencies.md)，完整许可边界见[第三方说明](../../THIRD_PARTY_NOTICES.md)。

## 验证结论的范围

真实声音GUI验证实际文件可解码、播放、停止、重听、错误重试及不误计分；不能由解码推断儿童听懂，也不能由localhost推断移动真机播放。题目语音全覆盖与标准音完整性是发布门禁，真实家庭LAN/断WAN及儿童试用仍独立验收。

首版不采集儿童录音、加载ASR模型或返回发音分数。维护者素材转写工具见[ADR-0003](../adr/0003-local-asr-transcription.md)，暂停评分研究见[PoC状态](assessment-poc-status.md)；两者都不是运行应用的前置条件。
