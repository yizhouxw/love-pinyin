# 拼音匹配质量协议 2：更正统计单位

日期：2026-10-26。固定定义见 [protocol JSON](../../content/pronunciation-quality-protocol-v2.json)。本次更正在最终模型/阈值冻结和新盲测声音生成前记录。三个百分比仍为 5% / 10% / 20%；旧报告及当时校准失败结论不覆盖、不删除，也不追认成当时已经通过。

## 审计发现

原 SPEC 的错放行以“每段音频的最难近邻”为单位，同一个 WAV 对多个错误目标，只要有任一个被接受便失败一次。相关性、父源数量与置信区间需要另外报告，不能自动改变该点估计的定义。

最初实现有两处偏离：

1. 将同一标准音的四个不同 VC 声音体先取最坏结果，再把 5% / 10% / 20% 应用于父源。这个附加压力要求比原每段声音门槛严格；把它提升为主门禁是实现偏差。四个声音体有相关性，但相关性并不要求把平均错误事件改成“整个簇任何一次失败”。
2. 总体负例键包含 `case`，同一个 WAV 的换调、近音查询各计一次分母。若 100 段声音中换调错放行 4 段、另外近音错放行 4 段，每类各为 4%，但最难近邻总体是 **8/100=8%**。旧实现可能显示 8/200=4%，错误稀释了分母。

例如 96 个 VC 声音体中有 17 个拒判，逐段为 17.7%；若这些拒判涉及 24 个父源中的 8 个，父源压力指标为 33.3%。两者回答不同的问题。将后者当作原 20% 逐段门槛，改变了估计对象。

## 协议 2

主门禁以不同 WAV 的 SHA 为单位。总体计算跨错误目标、`case`、重复导入来源作并集，每个 WAV 最多一次错放行。正确目标每个 WAV 一次；`retry` 是明确误拒，`uncertain/unavailable` 是拒判，所有预先声明清晰的正例保留在分母中。来源、生成器、反例类型和语言/音素类别在各自子集中用同样定义另行检查，不能用子组平均替代总体并集。

`parentStressView` 保留父源层面的额外压力观察。负例为任一派生声音被错放行；正例分别统计任一派生的明确误拒和任一派生的拒判。这两个事件独立计数：同父源一个声音 `retry`、另一个 `uncertain` 时两项都计，不能用优先级掩盖拒判。父源压力指标不作为新增临时验收门槛。

不同波形数、父源数、词根数及合成家族数分别报告。普通 Wilson 区间只作未调整的二项描述；同教师标准音、VC、TTS 音色和词根重复带来相关性，不能把波形总数宣称为独立儿童或人群证据。原始来源和家庭划分仍用于防泄漏，未放宽训练/校准/测试隔离。

非语音明确 `retry` 必须为零等工程契约继续执行；语言名称不能自动提供负标签。不存在通过删除失败、过滤不可用结果或放宽百分比来让模型达标的步骤。

## 复算及冻结

协议 1 的校准输出原样保留。使用完全相同的已存原始分支证据，写入新的 `-v2-protocol` 目录；记录输入文件 SHA、原模型元数据 SHA 和协议 JSON SHA，模型不重新推理、数据不重新筛选。复算只使用校准集，仍不能给出测试质量通过结论。

```sh
PYTHONPATH=. tools/pinyin-matcher/.venv/bin/python -m pinyin_matcher.calibration_v3 \
  --model private/matcher-v4-selected-candidate \
  --records private/matcher-v4-selected-calibration/records.json \
  --output private/matcher-v4-selected-calibration-v2-protocol
```

新模型继续在同一固定校准清单及三个阈值网格上比较。选定最终模型和阈值后，才准备尚未生成的新家族盲测。校准报告、质量冻结计划及评估报告均带 `protocolVersion=2` 和协议 SHA；评估时同时校验运行时代码与协议 JSON 没有改变。输出目录已存在时拒绝覆盖。
