原生序列实验保留完整人工拼音和CTC空白/多标签事件，先用真实整句，再混合OMPAL人工分量监督适应孤立短音。整句12轮所选epoch2仍处头预热阶段；后续尾层确实训练，不能将所选包描述成尾层已获益。初次MPS尝试因CPU float64转移路径失败，在完成任何epoch前停止；修复并用新v2目录重跑，失败日志/源码保留。训练入口随后加强原标签与缓存完整性校验，实际v2缓存独立审计通过；未重写历史模型的代码SHA。混合轮次固定8轮、两个域等权、头0.0001/尾层0.00001，按校准损失选检查点。训练根、重复曝光、排除、梯度和曲线见JSON。

## 剩余门禁

本轮质量记录针对成人四声整音节及明确列出的输入挑战；没有据此验收单独声母、逐步拼读序列或自由拼音内容识别。整句CTC训练能力不等于这些用户任务已经达标。

模型质量未达标。真实声母/韵母错误校准只有18/16根、各4位说话人，少于冻结的100根/5位说话人；反事实近邻不能补足真实错音。频繁使用的校准集已用于研发，不是盲测。最终10位说话人494份WAV仍未出现在预期原音路径，未读取；缺乏真实儿童验证。当前不发布儿童评测能力，不替换应用mock。

工程验证：`npm run verify:all`通过（178个前端单测、465个Python测试、36个本地和54个真实服务浏览器测试），`npm run validate:release`通过。独立研究环境270项测试通过、8项显式慢测默认跳过；本轮另实际完成两组真实模型导出数值验证。首次全量验证遇到并行应用改动的格式问题，修正后完整重跑通过，日志分别保留。工程通过不替代当前未过的质量门禁。

所有权重、录音、逐根结果留在忽略目录；Git保存代码、固定数据与训练配置、锁文件及聚合证据。复现命令见[工程文档](../engineering/pretrained-pronunciation-matcher.md)，本报告由`run.sh reconstruction-report`读取实际产物并核对身份/分母生成，缺失完整运行会报错。
