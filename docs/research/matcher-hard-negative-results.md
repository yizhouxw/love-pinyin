# MATCH-14：错音训练对及真实语音补充

2026-10-27。此记录是研发校准结果，不是冻结验收；原有 API 和应用 mock 不变。门槛始终为近邻错误放行不超过 5%、正确音明确误拒不超过 10%、清晰正确音拒判不超过 20%。校准和历史诊断已经用于模型选择，不能再作最终测试。

## 数据和训练

- 原 OMPAL 训练集中，专家确认正确的分量配对其余不同目标分量，生成 399,845 条训练比较，来自 7,250 个原始音频根及 28 个来源说话人 ID。这些比较不增加录音或说话人，也不代表每个替代分量构成合法完整音节。
- 为检查句级专家标签和自动切片之间的偏差，另训只将已有弱对齐分量设未知的版本，生成 336,689 条比较，来自 6,614 个原始根；不按模型预测删样本，校准集未删减。
- AISHELL-3 按预先固定的 20 位来源说话人、每人 25 个句子抽取 500 句，用来源听辨拼音和固定声学模型得到候选边界。5,617 个片段全部保留原因；符合边界质量和原 1,208 目标覆盖的 4,455 个片段用于训练。边界未经逐片人审；补充来源人 ID 不证明跨语料没有同一个人。
- [EdUHK](https://lml-elearning.eduhk.hk/about_g.aspx) 来源允许适当署名的研究用途，产品部署和再分发许可未核实。16 位预划定训练说话人的整段任务音频中，仅 5 人自然切分出恰好 40 段；候选目标顺序和切分边界尚未经独立人审。剔除不可映射及音频数值异常后，56 个音频根提供 79 个明确标注错误分量，以原目标和来源标注的实际分量产生 158 条训练比较，未标记分量视为未知。其余 11 位训练说话人不能对齐，保留原因。12 位校准和 10 位新盲测说话人录音没有下载或打开。该数据和衍生模型只作研究。
- 所有训练固定 120 轮、随机种子、网络、原目标覆盖和校准规则；困难负例每分量选择当前得分最高的三个错误类别。新增真实语音还做了同数据、均匀负例的对照。训练与模型包、音频和逐条清单保存在 Git 忽略目录；固定配置、来源和重放入口见 [工程说明](../engineering/pretrained-pronunciation-matcher.md)。

## 同一校准集完整 CPU 结果

每行都使用原 OMPAL v2 的 4,202 个根，其中 2,239 个清晰正确音，188 个专家标注错误根，1,775 个标签不确定。正确音的接受、明确误拒、拒判分别以 2,239 为分母，拒判没有被删除；反事实错误以同一正确录音配不同近邻目标，按 2,239 个根计，真实专家错误按 188 个根计，同一根有任何错误目标放行即计一次。

| 模型                  | 正确接受 | 明确误拒 |        正确拒判 | 反事实错误放行 | 专家错误放行 |
| --------------------- | -------: | -------: | --------------: | -------------: | -----------: |
| 原 factorized 基线    |    1,088 |      164 |   987（44.08%） |   124（5.54%） |  11（5.85%） |
| 困难负例              |      977 |      107 | 1,155（51.59%） |    75（3.35%） |   9（4.79%） |
| 弱对齐屏蔽 + 困难负例 |      950 |      142 | 1,147（51.23%） |   103（4.60%） |  13（6.91%） |
| 真人语音 + 困难负例   |      893 |      149 | 1,197（53.46%） |   109（4.87%） |   6（3.19%） |
| 真人语音 + 均匀负例   |      827 |      122 | 1,290（57.62%） |    94（4.20%） |   5（2.66%） |
| 再加真实错音候选      |      967 |      159 | 1,113（49.71%） |   114（5.09%） |  10（5.32%） |

错误类型分层中，困难负例模型的真实声调错误放行 9/174（5.17%），仍超过 5%；真实声母和韵母仅分别 18 和 16 个根，均不足分层样本量。校准结果不能证明泛化到新的说话人、独立音节或儿童。本轮比较说明压低错误放行与提高正确接受并未同时实现，不应靠排除拒判或事后放宽门槛给出达标结论。

困难负例模型的缓存诊断中，2,239 个正确音的声母、韵母、声调最高分同时正确只有 1,491 个；仅身份分支为 1,471，仅有效性分支为 1,323。最高分类别不等同于最终判定，此检查不能证明某个方案的准确率，但说明单纯换用现有分支或调整拒判阈值并不能直接证明质量问题得到解决。

312 个压力病例的病例 ID、波形摘要、查询目标和预期行为均与原 v2 诊断逐项相同；困难负例、弱对齐屏蔽、真人语音均匀负例和真实错音候选四个包没有通过全部压力检查，真人语音困难负例包通过该压力诊断。压力检查不替代完整质量和样本量门槛。

## 本机 CPU 与可复查记录

Mac Studio M2 Ultra，两线程，四秒固定音频，含解码、特征、编码、头和目标比较；暖机 3 次后测 30 次，冷启动为 5 次独立进程。各包大小均为 243,909,922 字节。基线为前一轮记录，其余本轮串行测量；机器并非独占。

| 模型                  | 暖机 p95（ms） | 实时率 | 峰值 RSS（MiB） | 冷启动 p95（ms） |
| --------------------- | -------------: | -----: | --------------: | ---------------: |
| 原 factorized 基线    |         101.23 | 0.0253 |           723.6 |          2,987.1 |
| 困难负例              |          93.32 | 0.0233 |           778.7 |          2,778.3 |
| 弱对齐屏蔽 + 困难负例 |          94.79 | 0.0237 |           802.8 |          2,795.3 |
| 真人语音 + 困难负例   |          91.48 | 0.0229 |           595.0 |          2,785.5 |
| 真人语音 + 均匀负例   |          93.13 | 0.0233 |           597.4 |          2,773.3 |
| 再加真实错音候选      |          96.22 | 0.0241 |           820.0 |          2,808.1 |

这些测试均符合暖机 p95 不超过 500ms、实时率不超过 0.1 的目标；冷启动包含 Python 启动、模型加载和一次推理，系统文件缓存未清除。详细分层、区间、逐轮训练、压力结果、包资源 SHA 和时延记录见 [机器可读结果](matcher-hard-negative-results.json)。

## 剩余门禁

需要改善分量和边界证据、获取足量独立且可靠标注的真实近邻错误，并先固定模型与阈值，再对未使用的冻结集一次性验收。原 OMPAL 最终留出的 494 份录音仍未打开，且其真实声母/韵母错误库存本身不足分层样本量。没有真实儿童验证，不能声称儿童发音评测通过；EdUHK 研究许可也不等于产品可用许可。
