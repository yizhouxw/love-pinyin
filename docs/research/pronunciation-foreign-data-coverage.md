## 反例与覆盖边界

语言名称不是错误标签。只有相对于明确目标的音素、声调或音节数量差异，才能形成负配对；跨语言同音、近似同音不能仅凭英语、法语或方言身份被判错。清单必须保留 `phoneticDifference`、目标 ID、词根及来源；跨语言评估还需明确 `mismatchBasis` 和 `mismatchDescription`。

报告分别按语言及 `contrastCategory` 展示齿间擦音、浊齿间擦音、唇齿擦音、小舌音、鼻化元音及辅音丛/多音节。较远的多音节词不能稀释较近的音素反例；每个实际分组独立应用门禁。类别名称说明预期差异，并不证明所有其它音素都已组成严格最小对立。

这些标签均为 TTS 预期标签。固定语言参数、生成成功和数值质量检查不能证明输出中每个实际音素都正确；不增加听审、教师或人工批准门禁。粤语探索样本单列且 `unknownLabel=false`，不得移动到正式负例；当前不宣称方言错误拒绝能力已通过。

## 原音、父源和配对的计数

加噪、混响、音色转换、同音频对多个错误目标，都不会产生新的原始发音根。报告同时保存 `rawAudioUnits`、`parentRootIds`、不同波形数、不同词根数和音色家族数。

首批标准音 VC 校准 v1 有 272 个波形，来自 68 个标准音父源、四个合成家族；该批次已参与问题诊断。后续声学来源划分调整时，必须从新版校准中剔除移入训练父源的全部派生波形，不能继续把旧 272 条报告为最终独立校准。每次实际数量以输入清单及 `collection.json` 为准。

最初协议 1 把父源最坏结果升级为质量主门禁，这超出了原“每段声音”的约定；总体负例还存在按 `case` 重复计算分母的问题。两处偏差已在最终冻结与新盲测生成前按[协议 2](pronunciation-quality-protocol-v2.md)显式更正。主门禁逐 WAV 统计全部错误查询的并集，父源层面另列 `parentStressView`，不再作为新增门槛。旧报告与当时失败结论原样保留；校准及新冻结评估共享同一版本定义。

48 条机械非语音输入中，有四对静音文件完全相同，因此实际只有 44 个波形单位。它们只检验非语音拒判契约，不能充当真实家庭噪声或发音准确度数据。非语音 `retry` 必须为零；`uncertain/unavailable` 不会从清晰正例拒判分母删除。

## 当前稳定校准结果

最终 INT8 候选按协议 2、固定校准输入和同一份原始证据重算，报告保存在 `private/matcher-v4-final-calibration-v2-stable/calibration.json`。校准输入为新版标准音 VC 的 228 个波形（57 个标准音父源×4个合成家族）、96 个英法波形及44个不同机械非语音波形，合计368个不同 WAV。公开正确目标的正例为其中96个 VC 波形，来自24个标准音父源；这些波形也被查询错误目标，因此不能把正负单位数直接相加成新的声音数量。

选定阈值下，错误放行为 **5/368（1.36%）**；正确音96段中 **83段 matched、3段 retry、10段 uncertain、0段 unavailable**，明确误拒为3/96（3.13%），清晰音拒判为10/96（10.42%）。外语部分英语为 **0/48**、法语为 **0/48**，合计 **0/96** 错放行；每段声音对全部已声明错误目标任一被接受即算一次错误。这里的48段/语言仍各只有12个词根及4个合成音色家族，不是48种独立发音结构。

这些是校准点估计，用于选择阈值，`calibrationPassed=true` 不等于冻结留出评估通过；校准报告仍保持 `qualityPassed=false`。父源压力视角、相关性及弱标签局限均保留，新盲测结果完成前不据此宣称真实儿童或开放语言输入质量达标。

## 数量是否足够

原质量门槛仍为错放行 ≤5%、正确音明确误拒 ≤10%、清晰音拒判 ≤20%，不因样本较少而调低。工程测试或校准通过不能替代新的冻结评估。

作为数量示例，若独立二项试验零次错误，95% Wilson 上界为 `3.8416 / (n + 3.8416)`；至少 73 次独立试验才会使上界不超过 5%。这是统计说明，不是新增硬门禁。TTS 音色、同词重复、同标准音的 VC 和增强样本存在相关性，96 段声音不能自动换算成 96 次独立试验，更不能据此保证真实儿童或整种语言的人群效果。

接下来应根据独立分组的失败补充有效词根、近邻对立及未见音色；增加噪声份数不能弥补错误标签或发音结构不足。所有波形、模型、逐样本报告只留在 `private/` 或 `models/`。

## 本地校准入口

```sh
PYTHONPATH=. tools/pinyin-matcher/.venv/bin/python -m pinyin_matcher.calibration_v3 \
  --model /absolute/path/to/v3-candidate \
  --manifest private/matcher-v2-controlled/manifest-vc-calibration.json \
  --foreign private/matcher-v2-foreign/qwen-calibration/manifest.json \
  --non-speech private/matcher-v2-nonspeech-calibration/manifest.json \
  --output private/matcher-v3-calibration
```

每个不同 WAV 只运行一次内容网络和原始音高分支；错误声调及最多六个不同音素近邻复用相同证据。仅公开覆盖目标的实际正例进入匹配门禁，其它明确音节只能作为反例来源，不能据此宣称公开覆盖全部研究音节。不可行时保存完整原因，返回 `thresholds=null`，不回退到较宽门槛。
