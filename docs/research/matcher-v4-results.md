# v4 冻结匹配结果：未通过质量门禁

日期：2026-10-26。对应 SPEC-018 / MATCH-04～06。本轮仅底层匹配，不接应用。v4 的 `calibrationPassed=true`，实际冻结留出结果为 **`qualityPassed=false`**；模型和安装包保留失败状态，不把工程测试、校准过线或外语零错放行写成最终达标。

## 固定来源及范围

机器摘要见 [matcher-v4-results.json](matcher-v4-results.json)，绑定原始结果、质量计划、生成锁、外语叶计划、输入清单、模型元数据及协议文件的 SHA256。逐样本结果留在 `private/matcher-v4-quality-results.json`，冻结计划为 `private/matcher-v4-quality.plan.json`。本轮使用协议2：一个 WAV 对全部错误目标只要任一 `matched` 就记一次错误；按来源、生成器、反例类别分别执行原5% / 10% / 20%门槛。没有删除失败或缺失记录。

声学 INT8、独立声调头、SwiftF0及目标目录在生成新声音前已冻结。阈值固定为内容 margin ≥0.5、自由 CTC advantage ≤0.025、声调概率 ≥0.45，测试未参与阈值选择。32个目标都可被查询，但本批正确目标样本只覆盖 **5个目标：chī、hē、nǐ、rì、xī**，共20个波形；不能称为32目标均已正例验证。

本批包括52个 VC 波形（13个标准音父源×4个新合成家族 `voice-32～35`）、由它们固定拼接的52个双音节波形，以及96个英法波形（24个新词根×4个家族）。共200个不同 WAV、3,424次查询，缺失结果为0。双音节拼接没有创造新的独立父源。13个标准音父源已有历史基准使用，本轮验证的范围只是这些已知源在新合成家族上的表现；不是新的独立标准录音、人类说话人或儿童检验。

## v5 的后续要求

已核对本轮标准音和 VC 训练清单：`n+i`、`h+e`、`x+i`、`ch+舌尖后元音`、`r+舌尖后元音`、`l+ü` 六个完整音素组的标准域训练计数均为0。先前按全部试验音节组排除标准音的策略留下了明确覆盖缺口；合成汉字域训练不能据此被假定已经补齐。这个事实支持下一步扩充覆盖，但不能证明它是每条失败的唯一原因。

进一步核查发现，六组可用于迁移的非blind校准候选为0。因此v5不称“校准父源迁移”：在把v4已消耗测试降为诊断后，显式释放原blind中的8个非公开声调标准父源ni2、he2、he4、xi2、xi3、xi4、chi3、lv2到声学训练，仅为00/06/08/10训练家族生成新派生。刚完成的52个测试VC波形、32～35参考及其派生不参与梯度，三个阈值保持不变。旧228段校准本来不含这8个父源，所以原96个公开正确正例不因本项变更减少；如其它新增源触及旧校准，仍须将相关父源整体降诊断并剔除全部派生。daily-ni1/ri1须先核实为直接原始许可资产、不是PSOLA或基于旧blind的派生，不能预称已纳入。原13个blind父源不再整体保留，下一轮仅保留ni3、he1、xi1、chi1、ri4五个公开父源，先预留36～39新家族，待模型与阈值冻结后生成20段VC；仍只检验已知标准父源上的新家族。旧测试的失败结论及来源历史完整保留，不追认成新的独立测试。

现有 `models/pinyin-matcher-v4` 继续为可运行的实验包，`qualityPassed=false`。本记录不宣布达到可靠自动裁决或真实儿童发音评测质量。
