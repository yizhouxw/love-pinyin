## 新增研究候选复核（2026-09-26）

复核 [Chen、Shahin、Ahmed 的 2026 年 6 月 arXiv 论文](https://arxiv.org/abs/2606.22022)：其 Wav2Vec2 CTC 语音属性方法联合建模普通话声母/韵母特征和声调，可产出属性级诊断；论文报告相对音素基线的 FAR 降低 10.1%、DER 降低 23.6%。这是目前候选表中与本项目“区分拼音音段与声调错误”最贴近的一项，列为**可申请复现的研究候选**，不表示已实测或接受。

关键边界：论文训练使用 Common Voice 13 普通话（67.2 小时、288 位说话人），AISHELL-1 作原生普通话评估（170 小时、400 位），另用 LATIC 学习者语料评估（4 小时、4 位俄语/韩语/法语/阿拉伯语 L1 学习者）。LATIC 只有四位非目标年龄学习者，明显达不到本项目至少 30 位 held-out 大陆一年级儿童的门槛；其结果也不能证明单字母、声韵母和 79 个课程朗读目标的效果。论文披露模型的声调 FAR 在不同表征下约为 8.11%–9.66%，高于本项目错误放行率 5% 的初始门槛口径；两者具体分母/任务定义不同，不能直接等同，但足以说明不得把论文整体收益当成项目门槛已满足。

论文给出[研究代码库](https://github.com/Evanchan1923/MDD_SpeechAttribute)，其[README](https://raw.githubusercontent.com/Evanchan1923/MDD_SpeechAttribute/main/mandarin_p2a_model/README.md)称评测仍是 work-in-progress，并只提供训练/研究评测命令，没有固定推理服务或已发布的评测模型包；根目录网页文件清单未显示 LICENSE。源码静态复核还发现，仓库[默认 Mandarin 配置](https://raw.githubusercontent.com/Evanchan1923/MDD_SpeechAttribute/main/mandarin_p2a_model/mandarin_setting.yaml)指定 `facebook/wav2vec2-large-robust`，而论文方法写的是 XLSR-53。该 Hugging Face 模型卡标记为 English、Apache-2.0；所以这份默认配置与论文报告的骨干不一致，不能据默认文件复现论文结果。仓库[requirements](https://raw.githubusercontent.com/Evanchan1923/MDD_SpeechAttribute/main/mandarin_p2a_model/requirements.txt)未完整锁定版本；默认配置还启用预处理数据保存与复用，会持久化研究音频衍生数据。虽然配置允许 CPU 模式，仍未验证 Apple Silicon 实际推理、作者训练检查点、其许可与摘要、依赖许可链、延迟/内存、断 WAN 或置信度校准。结论收紧为**条件性研究候选，暂不进入复现**：需先澄清 XLSR-53 与默认英文 checkpoint 的差异，并核实论文模型/训练数据/依赖的使用和再分发权利；再设计不会未经授权保留儿童音频的本地流程。本轮仅查看公开文本，没有克隆成功、安装依赖、下载语料或权重，也未接 API 或生成孩子可见评分。

## 本机实验环境记录

2026-09-26 在实际服务器 Mac Studio（M2 Ultra、64 GB、arm64、macOS 27.0）复跑 `npm run audio:doctor`：librosa 1.0.0 / NumPy 2.5.3 / SciPy 1.18.1 导入成功；合成 220 Hz 正弦的 YIN 中位数为 220.24 Hz。该检查没有录制或读取人声、没有加载语音模型，也没有测量模型延迟/内存或发音效果；只能证明 DSP 依赖当前可在目标硬件执行。

本轮另修复 PoC manifest 校验与 JSON Schema 不一致的问题：silence/noise/speaker-replay 现在必须引用 `challenge`/`syllable`，普通语音不能伪装成 challenge；`tests/server/test_assessment_benchmark.py` 使用元数据 fixture 验证该边界。测试 fixture 不是实验样本，不能计入有效研究数据。

评测器 v0.3.0 报告增加以 `speakerGroupId` 为聚类单位、固定种子 20260926 的 2,000 次说话人 bootstrap 95% 区间；保留的 Wilson 区间明确降为样本级描述统计。某项少于两位有效说话人时聚类区间返回 null 和原因，避免把重复录音误当独立个体或对单人子组假报窄区间。性能门槛现在仅以至少 30 位 held-out 儿童的测试指标判定；成人探索样本单独报告，不能平均掉儿童子组失败。manifest schema v2 记录两位独立匿名标注人和分歧后的第三裁决人引用。单测用两个各重复 10 次、表现完全相反的说话人验证聚类区间为 [0,1]，另用“30 成人全对、儿童错误”夹具验证成人结果无法掩盖儿童错误；所有人工 WAV 都仅用于校验逻辑，不是模型效果证据。

后续 v0.4.0 扩展 manifest 挑战类别，分别记录过短录音与近邻易混发音；前者要求 uncertain 裁决并单独计算拒判率，后者要求实际课程目标和 incorrect 裁决，并在报告按挑战类型分组。增加的 WAV/元数据均为合成测试 fixture，不构成模型或教学准确性证据。

之后的报告增加 held-out 目标年龄儿童的 study coverage 检查：分别报告清楚正确、声母/韵母错误、声调错误、静音、过短、噪声、扬声器回放与近邻易混的计数；任一项缺失即 coverage gate 失败并列出缺项。测试覆盖空缺与完整逻辑夹具，夹具不计入研究数据。

评测器 v0.5.0 还要求单独提供本地授权登记 schema。每个 manifest `consentRef` 必须唯一对应同一数据集及相同 cohort 的已批准 `retained-poc-audio-evaluation` 记录，记录须未过期并含受控本地证据的 SHA-256；授权引用和证据位置不写入汇总，只有匿名登记摘要。手工检查原同意/许可仍是必要条件，布尔批准字段本身不创造授权。

性能自测：在本机用 600 条/30 位虚构分组只测聚合函数，未读音频/真实样本；预聚合每位说话人的混淆计数后，`_rates` 约 0.042 秒（第一次简单实现约 2.36 秒）。该数据只验证统计代码的研究样本量计算开销，不是模型推理性能或 SPEC 的 3 秒评分预算证据。

## 数据与实验工具

新增 [manifest schema](../../research/assessment/manifest.schema.json) 和 [盲测汇总器](../../research/assessment/benchmark.py)。私有数据准备要求：

- 音频放到访问受限的本地目录中，以 `<sampleId>.wav` 命名。清单禁止路径、姓名、出生日期和转写；样本 ID/说话人组 ID 均为不含身份的随机代号，`consentRef` 指向 Mac 本机另行保管的授权证据及授权登记。授权登记 schema 见 [authorization-register.schema.json](../../research/assessment/authorization-register.schema.json)，仅记录匿名引用、队列、已批准的留存 PoC 评估用途、到期日和本地证据 SHA-256，不含同意书、姓名或联系方式。
- WAV 必须为单声道、16 kHz、PCM16，最长 10 秒、512 KiB；程序校验 SHA-256、路径边界、格式和文件名，不复制音频。原始音频和授权凭证不进 Git、导出报告或应用数据库。
- 开发集、校准集和测试集按 `speakerGroupId` 完全隔离；schema v2 要求两位不同的匿名审校人引用及独立标签；意见不合必须有不同于两人的第三裁决引用，意见一致时不得覆写共识。预测文件只能含测试集的 `pass/retry/uncertain`，不能附带原始音频、转写或个人数据。
- 输出只包含按目标类型、设备、环境、年龄队列聚合的说话人聚类 95% 置信区间、样本级描述 Wilson 区间、双标一致性及匿名说话人准确率分布。基准工具只汇总候选引擎给出的盲测类别，不训练、调阈值或生成预测。
- 即使分类指标通过，工具也固定返回 `continue-research`：它不验证 0–100 分的含义、校准、重测稳定性，也不能替教学审核人批准门槛。当前执行要求为至少 30 位 held-out 目标年龄儿童和总计 600 条按说话人隔离的裁决样本。

当前仓库没有这份清单、录音、预测文件或授权记录。评测命令必须显式提供与数据集一致的本地授权登记；工具逐条匹配队列、用途、批准状态和有效期，记录文件摘要但不输出任何 `consentRef`。这只是机器可检验的记录完整性，不能替代人工检查原始同意证据与数据使用许可。命令必须在有相应授权的本地数据后运行，不能用合成信号替代。实验通过条件仍依 [SPEC-000](../specs/SPEC-000-offline-assessment-poc.md)：目标覆盖、错误读法/声调、回灌、静音噪声拒判、分群 95% CI、真机性能、断 WAN 无外连、分数校准和许可逐项达标。

## 继续/停止决策

- **现在：继续研究，不开发会显示分数的 scorer。** 允许继续完善基准/采音处理的隐私与健壮性工具，但样本到位前不做任何效果承诺。
- **进入 DSP 对照实验：** 先取得合法成人开发样本和持权的参考音，调通本机 WAV/DSP 流程；其结果只用于发现信号处理问题。
- **进入儿童模型校准：** 必须获得监护人授权、至少 30 位 held-out 目标年龄儿童、双教师独立标注/分歧裁决和按说话人冻结测试集；另由教学负责人先签认指标定义。
- **若核心声母、ü/u、前后鼻音或四声错误放行过高：** 淘汰或限缩“可评目标”的产品契约并回到产品审批，不得调低 SPEC 门槛、让所有发音都返回鼓励分或引入第三方云。
- **版本/许可：** 只有运行时依赖当前已锁定；模型、权重、模板语料、标准音许可均未获批准。`librosa` 官方代码许可不覆盖任何未来数据/模型资产。
