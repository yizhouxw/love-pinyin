# ADR 0007：选定的家庭拼音示范音源

日期：2026-10-05；状态：采纳。用户在侧边会话明确指定使用[cmguo/PinYinSound](https://github.com/cmguo/PinYinSound)，由该会话转告当前实现。

固定上游提交62453b2a5ca6873eac1f4293b6e9794715d0fc8a，一次显式准备、全部运行时播放走家庭Mac同源API。归档共有1420个MP3、22885289字节，未附许可证或来源说明。只将当前课程需要的文件准备到private目录，代码的MIT不覆盖录音；不提交MP3、归档或伪造授权声明。

将文件可播放、家庭选用、教学审校、公开授权四种状态分开。用户此次选择允许家庭草稿模式采用该来源，不等于教师已审校或可公开分发。现有制作工具的两人核对规则继续用于从长录音裁切的标准音；选定来源新增独立适配器，不伪造该工具的确认记录。公开资产优先，其次已核对私有裁切，最后家庭选定来源。来源不可用时不联网回退。

content/pinyin-source.json显式记录每个课程目标、源文件、SHA-256和示范声调。整体认读的无调目标使用明确指定的带调示范；ri选择第四声，其余选第一声，不能假称上游有无调文件。ü显示保留Unicode；带调文件的v/nv只用于上游文件名。不得按浏览器传入文字猜文件名或拼接远程URL。

安装器校验固定归档摘要与逐文件摘要，在Mac实际解码检查时长和非静音后原子写入启用清单。运行时核对来源提交、目标签名、内容映射、文件摘要和私有目录边界，支持整体停用；坏文件只影响对应资源。API返回来源及pending教学审校状态，课程页面用“示范音”，家长处明确来源与许可状态。听辨仍须先听完整声音才允许答题，不产生发音评分。现有草稿内容提示及公开发布门禁保留。

此ADR覆盖SPEC-003把所有家庭未完成教师审核音源一概不可用的旧假设；不将家庭草稿练习的客观成绩宣称为经教学验证的发音能力。没有新增软件依赖。
