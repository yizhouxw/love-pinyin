# ADR 0007：选定的家庭拼音示范音源（已替代）

日期：2026-10-05。状态：历史决定，不作为现行实施要求。

原方案以家庭草稿来源接入cmguo/PinYinSound，并保留待审状态。后续用户明确直接信任该来源，草稿/审核状态及回退优先级已取消；固定来源和完整性校验继续适用。

当前遵守[ADR-0004](0004-defer-pronunciation-assessment.md)与[ADR-0008](0008-trusted-standard-audio.md)。外部声音许可与MIT代码分开管理，信任来源不授予再分发权。完整旧方案可从Git历史查看，本文仅保留决策沿革和引用入口。
