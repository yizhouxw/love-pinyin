# ADR 0015：按识别音节匹配提供自动跟读判定

2026-10-13。采纳。用户明确不训练模型，要求给识别模型增加拼音场景并依据识别结果判定。SPEC-009覆盖ADR-0003/0004中禁止儿童产品接ASR的范围，仅限每日跟读；原课程算法不变。

复用已安装Whisper small固定权重，懒加载于本家庭Mac，不训练，不自动下载，不远程降级。pypinyin固定0.55.0把模型真实转写转换为拼音，与内容目标的声母/韵母音节比较。判定名称为“识别匹配”，不是专业发音、四声或准确度评分；无分数，不计客观题成绩。静音、低置信、服务忙和失败拒判。

录音可由用户主动发送家庭Mac的内存识别端点，更新ADR-0014“不上传Mac”的限制；不落盘、不进入备份、不开儿童转写日志。浏览器16kHz单声道PCM WAV，服务端限制30秒和最大字节数，同源/CSRF/白名单，单模型无排队互斥。取消/换条/后台丢弃客户端旧响应，模型45秒超时回调中止。

运行依赖复用pywhispercpp==1.5.1与其已锁定numpy，新增pypinyin==0.55.0 MIT，来源https://pypi.org/project/pypinyin/0.55.0/。权重仍为scripts/asr_model.py的固定大小和SHA-256，只读取已安装文件，测试不会联网下载。模型提示只说明小学拼音场景，不加入当前条答案。

Whisper把ā/á都转成“啊”的本机实际结果说明本方法不判断实际四声；字典标调是识别文字的读法，不代表录音音高。此限制在学生/家长页明确展示，不能称为儿童真实准确率已验收。
