# ADR 0018：Kokoro 中文离线素材构建

2026-10-13采纳，依据用户要求和SPEC-011。选用hexgrad/Kokoro-82M-v1.1-zh，官方模型Apache-2.0；使用sherpa-onnx官方完整精度 ONNX转换与固定1.13.8/core CPU运行。参数、全部模型文件摘要和归档SHA固定在content/voice-build.json；维护组voice-build锁定，不让生产播放服务依赖TTS。

中文脚本是唯一输入，固定中文女声speaker3、speed0.95。离线生成去重WAV及1270中文声音ID登记（另有14课程录音ID），附模型许可。替换旧Tingting资源，原标准音仍来自PinYinSound，不把中文TTS当拼音标准音。实际声音输出随仓库提供，clone启动不需模型或系统音色；修改脚本才显式下载/校验/生成。课程MP3/PDF按用户授权入仓库，儿童录音、数据、模型权重不进入Git。

语音生成质量验证包含有效PCM、非静音、实际浏览器全量解码与本地转写抽查；机器转写不等同人工逐句听审，保留试听素材供用户确认。无训练、远程语音接口或运行时云降级。
