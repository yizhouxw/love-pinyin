# ADR 0002：持权示范音与 Mac 本地自动发音评分

- 日期：2026-09-25
- 状态：架构已采纳；评分器生产可用性待 PoC 门禁
- 约束：首版必须自动评分；录音可发送自家局域网 Mac Studio；禁止发送第三方云；本期支持浏览器，原生 App 后置

## 决定

1. 教学示范使用逐条授权、逐条审核的真人静态音频。音频内容与许可独立于 MIT 代码管理。缺失音频保持明确未就绪，不使用中文 TTS 或相近汉字自动替补。
2. 浏览器在明示操作后采集短时 PCM；通过同源 HTTPS API 发给 Mac，在受限本地 worker 中处理，返回结构化评分，立即释放录音。数据库只保存最小练习结果和引擎/内容版本。
3. 下一阶段第一项实施是本地评分 PoC：以授权多模板、MFCC/DTW、F0 为透明基线；必须在独立儿童测试集上校准。可换为通过权利和硬件审查的本地音素模型或 Mac 离线 SDK，保持同一领域接口。
4. 当前没有通过教学验收的生产评分器。API 明确返回 `unavailable` / `not_ready` 或对应错误，不能伪造分数。部署环境完成与评分能力完成是两个独立状态。
5. 产品反馈采用 `scored`、`uncertain`、`unsupported`、`unavailable` 状态；具体结构以 [API 契约](../api-contract.md) 和 `src/domain/contracts.ts` 为准。重录是界面动作，不新增为协议状态。只有 `scored` 且证据充足的结果才能计入发音掌握度。听辨、录音回放或成人手动确认不能替代自动评分验收。

## 理由

Mac B/S 架构保留电脑、平板、手机的统一浏览器界面，让声学依赖在同一受控环境运行。相比在每部手机加载模型，便于性能管理、版本固定和跨端一致性。真人示范能区分声母呼读/本音、韵母、音节和语境变调。

ASR 文字命中只表示识别结果，不等于发音准确；强制对齐也不能证明发音正确。儿童声音、设备及噪声差异使模板距离必须校准。公开商用离线 SDK 尚未核实 Mac arm64 服务端许可，不能作为已解决依赖。[证据及备选](../research/audio-and-assets.md)。

## 明确排除

- 第三方云评测、云 ASR、浏览器自动联网的语音识别。
- 把音量、波形长度、转写相等、成人模板相似度未经校准直接包装成 0–100 教学分数。
- 把系统 TTS、开源 TTS 代码许可当成标准音与声音权利已解决。
- 在评分器未就绪时用默认通过、随机分或录音次数完成发音学习目标。

## 代价与复审触发

需要维护开机的 Mac、客户端可信 HTTPS 和本地备份；离开局域网后评分不可用。真人音及校准语料需制作、审核；本地评分可能需要额外模型研发，不能承诺小模型按文档即可解决研究缺口。若 PoC 未通过，先修复声学/数据问题或评估授权离线引擎，保持用户已确定的隐私与自动评分要求。

重新决策的条件：儿童基准不达标、所选模型权利不能满足发行方式、Mac 内存/时延不达标，或用户明确改变部署/隐私约束。采音和制作执行细则见 [技术方案](../research/technology.md)、[音频制作](../content/audio-production.md)。
