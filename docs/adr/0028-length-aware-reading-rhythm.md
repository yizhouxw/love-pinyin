# ADR 0028：词句跟读节奏与学生设备间隔偏好

2026-10-20采纳，依据SPEC-012 READ-05/06。

连播设置保留原household/API/备份字段playbackGapSeconds与0.1～5秒范围，解释为基础间隔。content/playback.json登记每多一个音节增加0.5秒，由纯函数按刚播放完的条目音节数计算两条之间的跟读等待；最后一条不等待。完整中文示范内部时间轴不变，标准音内部接续与基础设置分离。

现有600份标准音MP3以约-54dB阈值检查，首尾低幅度留白中位约0.087秒、最长约0.323秒；逐音节重新装载媒体另有切换开销。多音节条目改为从当天编码池取白名单原始文件，只解码当前一条，在单个OfflineAudioContext内读取PCM，使用更保守的0.0005（约-66dB）阈值识别首尾留白并各保留40ms保护边界，将音节间留白补到约100ms，编码为临时WAV。阈值、保护边界与接续时间集中登记在content/playback.json；保留发音时长与内容，不改变语速或音高。全静音或无法可靠取得边界的片段不裁切。浏览器解码失败报告播放不可用，不以缺少音节的拼接冒充完整示范。

WAV仍由ADR-0025的已激活HTMLAudioElement播放，保留真实playing/currentTime/ended；高亮按拼接时记录的音节区间与实际currentTime通知。OfflineAudioContext只用于当前条目的解码，不通过Web Audio出声，不对整份批量解码或永久保留PCM；完成后释放临时WAV/对象URL，当前份原编码池预算不变。单音、课程和完整中文示范保持原播放路径与时间轴。异步解码完成后须检查取消状态，旧结果不能启动声音。使用浏览器内置能力，无新增依赖或服务器资源，不写录音、进度或派生音频到磁盘。

学生页使用与ADR-0016相同的设备偏好模式，选择值和选择时的家庭默认值一起保存；默认值变化时旧偏好失效。家庭设备只写本浏览器localStorage，访客写当前标签页sessionStorage并随退出清除，不修改家庭设置或扩大学习设备的家长权限。家长页继续维护家庭默认，学生页注明本设备范围。页面协调层统一计算有效值，所有小节共用；保存快捷设置主动中断旧队列，下一次播放读取新值。没有新增接口、数据库迁移或依赖。
