# ADR 0013：题实例冻结选项排列

日期：2026-10-05。状态：采纳。范围：SPEC-004 OPTION-ORDER-01。

听辨题正确答案在第一项的比例为116/204，当前界面直接沿用内容顺序，孩子可能记位置而非辨音。采用服务端纯函数按题实例生成排列，React仍只渲染API给定的选项，不重新生成候选或答案。

新客观题实例ID使用`op1_`加原有18字节随机数的24字符URL-safe编码，总长28；该前缀和长度标识选项排列v1。旧实例ID由原有18字节随机数产生，总长24，不会被误识别。ID保持不透明标识，客户端不得据此判分。无需新增数据库列、备份字段或依赖；既有备份已保留实例ID。

v1按SHA-256(`${instanceId}:${optionId}`)字节值升序排列，哈希相同以optionId排序。算法不读标准答案，选项ID、文字、图片、语音映射均不变，不修改content。随机性来自实例ID，重复创建可能碰巧得到同一排列，不承诺每次必不相同；同一实例重算必相同，不按请求时间重新随机。

开始普通/复习会话时把排列写入既有tasks_json，读取当前会话沿用冻结题单。备份恢复从历史内容版本取题，再按已保存实例ID重建同一排列；访客每请求重建内存库也走这条路径。没有v1标识的旧实例保持内容原顺序，旧数据库中的冻结题单保持原样。未来不得修改v1算法；若需变更要使用新标识并保持旧规则，以免破坏恢复。

声音按钮与答案按钮共享同一optionId；A/B/C只是当前屏幕位置。评分、提示、纠正、重试与幂等继续传稳定ID。纯函数验证不修改输入、顺序可复现、选项无增删及多实例位置覆盖；真实API验证创建/刷新/复习/家庭导出恢复/访客重建，真实GUI验证声音与选项对应和提交结果。

运维兼容：程序回滚也须核对题实例排列版本，不能仅凭数据库schema未变就认为旧程序能重建相同布局。运行中的旧冻结题单保持原样，不主动迁移家庭数据库。部署与回滚边界登记在本地部署文档。
