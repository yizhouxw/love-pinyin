# ADR-0036：可配置题量、游戏内设置与即时拼音画面

2026-10-27，采纳；SPEC-017 PLAY-01～04。

关卡目录继续维护二十四条三章节路线模板。新 gameRun version=2 将 3～20 个题实例均衡分配至三个章节，引用模板中的路线并生成唯一段 ID；冻结后的路线和题单随原 SQLite JSON 字段、schema5 备份与访客快照往返，无数据库迁移。version=1 严格保留三章各四段和十二绑定，不能用版本变更放宽旧数据校验。题量/接近航段长度/逐关速度倍率集中在 content/games.json；教学题与标准音仍来自 content/，按知识点分散选择。

通过 PATCH /sessions/{id}/game-settings 修改当前家庭活动游戏的物理难度和速度，保留启动时的学习进度推荐依据与整个 gameRun、题单、结果。事务校验归属、活动状态和游戏额度，设置随原字段保存；不使用客户端临时变量假装刷新可恢复。调整题量仅影响下次开局，不在游玩中截断或补造学习题目。

必要标准音在游戏开局直接播放，说明和故事按需听。SVG 预先呈现候选目标；运动接近阶段仍保留障碍/节拍，只有原碰撞规则产生选择。放大仅改变页面布局，显示偏好在本标签页跨检查点保存；设置用原生 dialog 管理焦点、Escape 和世界暂停。指针长按与键盘走同一动作函数，取消、失焦、卸载时释放输入。无新增依赖、远程素材或音频服务。
