# ADR-0030：天天练来源台账与本地一声派生

2026-10-25采纳，依据SPEC-008 DAILY-12及用户明确授权本机处理缺少的一声。

同一小节以NFC音节序列去重，保留首次ID；去重不能跨小节，也不能去掉声调或词句内部叠音。content/daily-reading-source.json保存本次完整840条来源台账和PDF摘要，内容规则按台账重新推导保留项，不固化某一版Word的删除位置。源Word未提供，不能把PDF重复推断为已确认Word错误。更换来源必须显式更新台账并重新复核。

无调音默认一声，词句轻声以显式位置登记；不按有没有音频来猜声调。已有固定PinYinSound未提供10个目标的一声，禁止继续以二三四声降级。用户授权在本机用时域PSOLA对已有固定源音的有声段重排音高周期，保留时长、辅音与未发声段；这是派生示范，不是上游原始录音或新的真实人声采样。目标、原音摘要、处理参数集中在content/daily-reading-policy.json。导入时用既有afconvert/ffmpeg解码，Python标准库处理，写入private/pinyinsound并登记结果摘要和配置摘要；运行端只读验证后的本地文件，不现场处理、不联网。缺失、损坏或配置变更则未就绪，由显式准备修复。

派生声音沿用原库unknown许可，不纳入代码MIT或Qwen Apache许可，不提交原音/派生音。数据结构与标准音接口增加派生来源信息，界面在播放这些音节时明确说明。课程原标准音、所有已标调声音及词句中文朗读保持原用途。没有新依赖或模型；工程音高检查只用于验证音频处理，不是儿童发音评分或真机听感验收。
