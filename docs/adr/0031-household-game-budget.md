# ADR-0031：家庭共享游戏额度与原成绩闭环

2026-10-25采纳，对应SPEC-017。游戏入口作为独立React模块，使用content/games.json配置玩法与模式；题目仍由原sessions/attempts事务创建和计分，sessions增加game_id区分来源，不复制答案或掌握算法。

家庭表增加游戏分钟设置与版本化game_state_json，时间结算为无I/O纯函数；服务端时钟和Asia/Shanghai业务日决定时长，所有设备共享同一授权区间，重叠不重复扣除。短租期限制后台/失联后的持续占用，浏览器用单调时钟在授权到期前锁界面，恢复先向服务器请求授权；请求6秒超时取消，暂停/离开取消悬挂请求，访客队列透传AbortSignal，失败不覆盖临时快照。单次用量仅在连续10分钟无授权后重置，普通退出或结束关卡不重置。时长用于健康休息，不参与正确率或学习难度。

SQLite增量迁移8。JSON备份v5允许可选的gameState、游戏设置与session.gameId，旧备份显式缺省；访客继续采用请求内存SQLite和标签页快照，不访问家庭时长。家庭额度并非防止清除访客缓存的安全控制；产品明确访客边界。不得将网络失败计为答错；已保存答案的幂等回执仍可查询，限时后拒绝新游戏作答。

不新增依赖、账号、外部服务或音频引擎。家长修改遵循既有loopback权限。真实设备/LAN与软件验收分别记录。
