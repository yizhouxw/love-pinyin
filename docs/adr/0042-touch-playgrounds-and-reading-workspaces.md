# ADR-0042：触屏游戏新引擎与阅读工作区

2026-11-13，采纳；SPEC-017 REDESIGN、SPEC-022 WORD-16、SPEC-012 READ-08。

四个标题对应四套新玩法，不再使用旧scene-game物理路线：横向跑跳、俯视导航、无时限节奏模仿、投递轨迹。新增纯TypeScript引擎和集中玩法参数，React只处理场景绘制、指针生命周期、真实音频和已有会话API。现有GameRun继续冻结课程任务、关卡主题和章节；旧路线数据仅用于旧备份兼容，不参与新玩法物理。未确认答案、声音保护、错答修正和家庭额度继续使用现有接口。操作失误与教学判断隔离。没有新增依赖。

阅读模块统一用有边界的独立滚动区与可见性校准hook，播放改变当前条目时只移动内层scrollTop，不改变窗口位置和键盘焦点。ResizeObserver负责屏幕旋转和文字尺寸变化后的再校准。主操作和情景图不放进词卡滚动区；极小视口仍允许外页滚动，避免裁掉必要控制。

WORD-17补充：字音标注统一用逐单元的双行网格，每个ruby只承载一个明确音节与对应汉字。标点放在单元边缘，不参与居中；儿化合并表位于content/hanzi-pinyin-alignment.json。天天练保留拼音大字在上、汉字小字在下的教学层级，词语听写保留汉字主层级。所有断行发生在完整单元之间；不对识字数量不匹配的说明图强行建立注音关系。
