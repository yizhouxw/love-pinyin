# ADR-0009：浏览器临时进度与无状态访客计算

状态：接受；2026-10-05。范围：SPEC-007。

访客缓存采用标签页 sessionStorage，区别于家庭 SQLite 持久化。浏览器串行发送操作与版本化进度快照，只有成功接收并缓存结果后才更新界面。服务器每个请求建立独立 SQLite `:memory:`，以现有备份校验/恢复及业务函数完成操作后返回结果与新快照，finally 关闭。ContextVar 隔离连接，不切换全局数据库路径、不接触家庭表。请求与响应限制大小，拒绝未知操作；不将访客数据放入导入预览缓存。

课程、标准音、中文引导与课程录音开放单独的只读访客路由，仍由现有白名单、摘要和 Range 适配器提供。家庭数据 API 继续要求配对与 CSRF；访客计算检查同源。家庭部署本来是可信局域网，开启访客意味着未配对的可达设备可以读取课程声音，但不能读取家庭数据。

不在 TypeScript 复制掌握度算法；不建立服务端长期访客账户；不采用可被误当家庭数据的模拟成功接口。请求期间允许把临时进度传到自有 Mac 计算，但只在浏览器保存跨请求状态。无需新增依赖。退出清除访客缓存，不自动迁移到家庭档案。
