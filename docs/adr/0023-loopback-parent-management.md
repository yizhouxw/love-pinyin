# ADR-0023：家长管理限定127.0.0.1入口

日期：2026-10-16。状态：采纳。依据：用户要求非127.0.0.1访问不得进入家长模式，SPEC-007 ACCESS-03。

管理入口要求连接来源为127.0.0.1且请求Host的hostname为127.0.0.1，使用原始ASGI连接地址而非信任转发头后的客户端地址。实际Uvicorn入口关闭代理头信任，避免LAN请求通过X-Forwarded-For伪装成本机。localhost、LAN IP、IPv6或主机名不授予家长能力。前端只根据服务端bootstrap的isLocalHost显示管理入口；服务端家长读写依赖另行强制检查，旧远程家长会话也被拒绝。

配对角色不再按“首台设备”分配，来自127.0.0.1的配对可建立家长角色，远程配对始终是学习角色。历史数据库角色不需迁移，bootstrap只向本机入口显示有效家长身份；身份Cookie仍用于学习，已保存记录和设备撤销机制保留。访客课程/设置变更仅在同样入口接受，临时学习计算保持原隔离。

不开放远程管理员替代入口，不增加账号/密码或依赖。Docker内管理命令继续走127.0.0.1；若未来支持反向代理管理，应另立明确的可信代理设计，不能重新启用任意转发头。此决定覆盖SPEC-007 ACCESS-02及相关文档此前允许远程家长管理的描述。
