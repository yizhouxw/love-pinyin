# ADR 0006：私有标准音的本地制作与启用

日期：2026-10-05；状态：采纳。延续ADR-0005的家庭资源边界，不改变公共发行许可与教师审校要求。

用户已有13份课程录音和427段候选，但CSV和ASR草稿不能直接成为准确拼音资产。提供仅监听Mac loopback的独立审音工具，不放到儿童页面，不调用第三方。工具显式导入课程源文件、保存摘要并转为可精确裁切的PCM；原文件保持不变。

操作者可按课程和候选时间定位、试听原音和裁切结果、填写content中的既有标准音ID。保存草稿不启用学习资源。只有显式填写两位不同的教学/音质核对者、确认目标和声音完整清晰后才写入私有标准音清单；工具不自动代签，不从ASR文本推定正确目标。改变裁切区间或来源会产生新草稿版本，即使PCM相同，旧确认也不能沿用。

运行时仍使用原 `/audio/{id}`：先读取合格公开资源，再读取该家庭已确认私有资源。私有清单绑定当前目标描述与文件摘要；课程API只新增实际可用标志，不篡改公开资源的授权/审核字段。源码内容包和公开发布门禁不因家庭启用而变为approved。未启用、撤下、目标变化或文件损坏均不可播放，也不能进入新听辨会话。

所有源音、裁切、草稿和核对记录留在private目录，不进入Git或公开包。该工具不录制儿童语音、不要求安装模型或新增外部依赖。
