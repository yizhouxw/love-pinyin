# ADR 0004：首版暂缓发音评测

- 日期：2026-09-27
- 状态：已采纳；覆盖 ADR 0002 中“首版必须自动发音评分”的产品范围决定

## 决定

1. 首版不提供浏览器录音、语音上传、发音评测、发音分数或跟读结果记录。B/S 与家庭 Mac 本地服务仍保留，用于课程、客观练习、家庭进度和资源播放。
2. 首版听说相关学习通过授权审校后的标准示范音播放与客观听辨题完成；资源未准备好时如实显示未就绪，不使用 TTS 或 ASR 替代。
3. Whisper 本机工具仅用于维护者整理本地素材，不随应用启动、不接儿童 API/界面。其拼音短音节识别试验已见明显错误，不可作为课程答案或评分证据。
4. SPEC-000 暂停为未来研究计划；SPEC-003 缩减至标准音资源、播放与客观听辨。任何重启发音评测都需要新 SPEC，说明用户价值、合法样本、数据处理、模型能力与真实设备验收，再更新架构和隐私说明。

## 理由

自动发音评测的实现与数据校准比当前产品阶段负担更大，且现有本机通用 ASR 在短拼音音节上出现错识。先交付完整、可审校的课程和客观游戏，避免把 ASR 转写误当成发音能力评价，并减少儿童麦克风权限、录音上传和数据清理流程。

## 影响

- R-017、R-021 移至 P2，不阻塞首版。
- 不采集儿童录音；首版能力清单、API 契约和 TypeScript 客户端契约均不包含评分端点或评分类型。
- 现存评分 PoC、校准及儿童样本方案作为未来研究资料保留，不属于首版研发路径。
- 标准音授权、教师审音、听辨题覆盖和真实跨端测试仍是首版发布门禁。
