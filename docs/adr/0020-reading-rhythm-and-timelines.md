# ADR 0020：跟读设置与实际音频时间轴

2026-10-14采纳，依据SPEC-012。连播间隔以整十分之一秒保存在household，SQLite迁移6补默认10，API和v5可携带JSON备份使用playbackGapSeconds。旧档案与旧备份缺字段时默认1秒；现有设置修改若未传该字段则保留。访客走既有临时快照，同步其间隔而不写家庭数据库。

标准音按HTMLAudioElement的真实playing事件高亮，完整中文示范按currentTime及requestAnimationFrame读取固定字音时间轴。维护时用本地Qwen3-ForcedAligner 0.6B对已知原创中文与现有WAV作强制对齐，输出逐汉字起止时间，按内容中的音节次序对应，摘要绑定音频；模型和MLX仅维护阶段使用，不在运行端加载/下载。参数、版本、官方来源及许可证登记；时间轴不同步拒绝发布，不均分时长。

新生活图片使用同源原创SVG，保持现有图片ID、冻结题目和标准音映射；扩充学习卡可以复用同一标准拼音描述不同生活对象。组词样例另存content目录，按音节复用文本和预生成Qwen中文朗读，默认折叠，展开主动播放优先于操作引导开关。所有新队列、等待和时间通知都继承AbortSignal，停止/换条/退出/后台取消并清除高亮；失败不影响儿童成绩。
