# ADR 0034：合成预训练的专用拼音匹配器

日期：2026-10-25。状态：采纳技术方向，模型效果与产品接入尚未验收。

## 背景

用户发现“选商品、读拼音、商品入篮”能吸引孩子，希望自动判断朗读结果；随后明确提出用两个中文开源 TTS、多年龄/性别风格与数据增强训练专用模型，家庭 Mac 只用 CPU 推理。该明确新需求允许重启 ADR-0004 暂缓的发音研究，入口为 SPEC-018，旧 SPEC-000 不恢复为原产品交付前置条件。

## 决定

1. 采用 Qwen3-TTS VoiceDesign 1.7B 与 CosyVoice3 0.5B 离线生成训练素材。音色风格、原始样本谱系及克隆参考来源分别登记；训练数据与教学标准音分开，标准音继续直接信任 PinYinSound。
2. 产品采用已知目标的有限任务声学匹配：共享小型卷积编码器、音素 CTC、独立音高/声调分支和目标/近邻对比。网络看不到当前目标答案；目标只在声学编码完成后的对齐和比较阶段参与，不用文本语言模型修正孩子声音。
3. 推理以独立 ONNX 模型经 CPU provider 在家庭 Mac 执行；TTS、训练框架与可选加速只属于离线工具。Mac 上两个生成模型的安装可行性、耗时与 CPU 匹配延迟均需实际验证，不用第三方演示延迟作本机证据。
4. 第一轮用小规模合成数据检验路线，样本量和增强量分别记账。真实家庭使用反馈可以渐进取得；只将已验证的能力提供为自动裁决，不声称合成童声证明真实儿童准确率。
5. 声调、音节内容、录音质量和模型可用性分别表达。没有可信判断时拒判；不以加噪音频充当发音错误、不以目标强制对齐充当正确证据，不把未验证的数值相似度显示成发音分数。
6. SPEC-009 的现有 Whisper 跟读匹配保持原契约。未来专用匹配接口独立，不将 Whisper 暗中用作专用模型的远程或本地成功降级；新游戏模型未就绪时如实提示或明确由家长放行。

## 取舍

2026-10-26 质量优化补充：声学编码改用逐帧归一化并在各时序块屏蔽填充，保证训练批次填充与单条推理边界一致。将既有标准音的非试验音节作为音素预训练，声母/韵母头可表达覆盖词表之外的组合，避免仅在32个候选中强迫归类；实际能力声明仍限定32目标。声调使用独立raw音频F0路径，保持内容与音高证据分离。样本/校准/新盲测谱系、阈值选择与门禁分别冻结，不用放宽门槛代替模型改进。

音高前端选择固定 SwiftF0 0.3.0（MIT，135090字节ONNX），解决旧YIN丢失低音下降尾部和倍频问题；本地显式准备，运行仅已有ORT/NumPy/SciPy，不下载或调用ASR。32×4相对音高轮廓的独立声调头与原始波形tracker分别绑定摘要和版本。内容、声调及自由CTC证据分别判定，旧网络中的声调输出不参与v3裁决。跨语言弱标签仅施加显式目标对比损失，不凭语言给两个音素分支伪造unknown转写。固定依赖和实际校准/CPU结果见 `docs/research/matcher-pitch-swift.md`，反例计数边界见 `docs/research/matcher-negative-coverage.md`。

声学训练v4与音高锚使用不同清单：标准音原按完整试验音素组排除，使舌尖元音两类在声学标准/VC训练中零覆盖；此限制继续用于独立音高研究，但不能替代声学训练的类别覆盖。声学分支显式迁移11个非公开、不同声调父记录及新训练家族转换，不使用校准家族音体；原校准退为诊断，新校准剔除所有迁移父源派生，原公开正例与盲源完整保留。声学源记录拆分不构成独立真人说话人验证，最终仍须报告同教师来源的相关性。

验收计数v2明确区分逐波形错误事件和父源跨声音联合压力事件。多个目标对同一声音的最难近邻事件仍取any-matched；整体负例不再因tone/near-phoneme等case重复分母。不同声音体的相关性进入来源覆盖与不确定性解释，不能简单用父源max替代单次事件点估计。父源压力按各指标独立计any事件，避免retry遮蔽另一声音的uncertain；它保留为附加指标。原v1结果完整保存，新留出开始前冻结修正协议与SHA，不依据盲测选择统计口径。

2026-10-25 实施补充：共享声调头暴露音节/声调相关性的捷径；仅以合成 ma 四声训练相对音高头的校准表现也不足。最终声调分支只输入相对有声 F0 轮廓，使用项目已授权、直接信任的 PinYinSound 标准音作锚；按音节分组划分，排除所有试验目标的音节组，保留独立许可状态。不得称同源留出记录为独立说话人验证。两个 ONNX 均显式 CPU 推理、分别绑定摘要；共享声调头与失败的纯合成轮廓实验保留作对照，新音色测试不参与选择阈值。

全量音节分类器实现简单，但对未见组合和局部错误的解释较弱；纯模板距离受音色与音高变化影响；通用 ASR 加语言模型会倾向把近似语音纠正成目标。选择音素/声调分支以便做近邻对比和拒判，其工程成本高于 ASR 文本比对。合成数据解决起步和覆盖问题，对真实发音错误的泛化仍需独立实验确认。

模型、数据、增强、评估及分阶段验收详见 [SPEC-018](../specs/SPEC-018-target-pronunciation-matcher.md) 和[技术方案](../research/target-pronunciation-matcher.md)。底层实装、CPU 测量及未通过的效果门禁见[实验记录](../research/target-pronunciation-matcher-results.md)；现有应用不接入本模型。
