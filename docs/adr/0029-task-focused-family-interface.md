# ADR-0029：按学习任务组织家庭界面

2026-10-24采纳，依据SPEC-016。保留React状态编排和ADR-0026模块边界，不引入路由或设计系统依赖。

首页展示当前学习与两类学习入口，课程内部按听/写/练切换，天天练按选材/练习切换。一次突出一个任务，共享的语音偏好仍由App计算并通过属性传入；子模块以回调修改，不各自建立冲突的家庭语音设置。练习和书写队列使用既有音频适配器和AbortSignal，不在组件推导教学规则，不修改题单和成绩算法。题目说明与标准示范复用已激活的HTMLAudioElement，顺序播放时保留原始playing/ended完成条件；停止、换题和后台取消整个队列，说明失败仍可继续标准音。展开低频设置不改变权限和数据校验。

产品版本以package.json为唯一当前版本，仓库内的变更记录提供面向家长的说明；课程contentVersion继续独立维护。版本入口在学习页与家长页可达，不调用外部服务，不影响离线和隐私边界。界面结构调整需要同步真实服务测试，测试结果仍与真机验收分开。
