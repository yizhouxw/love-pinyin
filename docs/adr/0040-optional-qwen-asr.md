# ADR-0040：可选本机 Qwen 识别与人工确认

2026-11-09，采纳，SPEC-019 SHOP-09～12。覆盖 ADR-0035 的模拟选择及 ADR-0015 的产品引擎选择。

复用已锁定的 MLX-Audio 0.5.8 / MLX 0.32.3，在 Apple Silicon 家庭服务和 Mac 应用的 Metal 环境运行。复用已实测的 mlx-community/Qwen3-ASR-0.6B-8bit 固定修订（Apache-2.0），文件大小及 SHA-256 随内容配置锁定。其他独立运行环境提供人工确认。安装包只分发运行库。家长显式下载并校验后启用，推理只加载本机目录。

天天练保留严格音节匹配。小卖部共用内存识别器、固定目标目录和 MATCH-10 请求关联，结果与购物车不持久化。前后鼻音、平翘舌容错仅用于小卖部。录音不可用、未启用或用户切换时，使用独立人工操作路径，听读完成后由人确认入车。
