# ADR-0032：四个场景游戏与学习成绩隔离

日期：2026-10-25；状态：采纳；关联：SPEC-017 SCENE-01～05、ADAPT-01～02，ADR-0031。

用户要求具有跑酷、划船、节奏和发射玩法的真实游戏。原题卡页面不足以满足需求。

采用原生 SVG 场景和 requestAnimationFrame；纯 TypeScript 状态转换负责移动、惯性、跳跃、节奏、弹道与碰撞，React 负责绘制和按钮，音效通过本机 Web Audio 适配器。无新增依赖、远程素材或模型。运动失误仅重试路段；只有玩家主动动作命中带选项 ID 的目标时，才向原作答 API 提交。标准音、网络租约、首次幂等成绩和学习掌握算法保持原边界。启蒙与辅助模式允许等待，不要求儿童抢答。

游戏题目来自 content/，服务器先限制课程范围及真实可用标准音，再依据掌握度和历史轮转选择最多六题。推荐阈值和场景参数统一放在 content/games.json。难度和速度分别设置并冻结；SQLite 迁移9增加 sessions.game_settings_json，备份schema5以可选gameSettings兼容旧档案。设备只保存各场景启动偏好，服务器负责可信的范围和实际会话设置；手动难度不提升课程范围。

暂停/音频/隐藏页面停止动画，卸载取消 RAF；限时仍由服务器共享时钟管控。允许随时辅助慢动作和显式放过音符，操作速度不进入掌握度。没有物理引擎依赖；代价是维护四套小型纯运动模型及其碰撞边界测试。
