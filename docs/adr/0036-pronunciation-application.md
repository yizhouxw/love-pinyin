# ADR 0036：拼读应用交互与独立记录

2026-10-26，采纳。对应 SPEC-020 / SPEC-018 MATCH-13～15。

学习路径和天天练共享 MATCH-10 端口、内存录音适配器和交互组件。课程目标来自 content/curriculum.json 的 readingTargets，每日目标来自 content/daily-reading.json，不从选项或组件推断答案。既有 Whisper 比较保持独立。

家庭同源 HTTP 适配器一次评估返回 match 和 recognize，服务端绑定可信目标目录并保存摘要，不接受客户端自报正确。默认后端不可用，真实声学实现另行通过模型门禁后替换；开发 mock 只能显式注入组件且不存库。访客不持久化。原音频不落盘。声学结果独立于客观题掌握度，拒判不进入准确情况分母。新摘要随 JSON 备份、恢复、家庭清除一起管理。

没有新依赖。工程测试证明交互和存储边界，不证明儿童发音识别质量。

2026-10-26 MATCH-15 补充：现有全局播放器增加可释放的输入占用，课程采音/权限请求与其他播放互斥。另一声音取得播放器时先取消输入；结束或退出只释放自身占用，不停止后来的播放。切听/写/练活动重建跟读生命周期。此变更不涉及模型或新增依赖。
