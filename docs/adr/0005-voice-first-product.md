# ADR 0005：语音优先的家庭可用产品

日期：2026-10-05。状态：采纳。依据：用户要求重新实现最终可运行产品，明确一年级初学儿童不能依靠识字读题。

1. 保留实际 FastAPI/SQLite 业务与 React 界面，修复断开的学习链路；不以模拟 API、默认 unavailable 或测试数量替代真实验收。首版继续排除录音和发音评测。
2. 分开三种资源：中文引导语（本机预生成，仅汉字，禁止朗读拼音作为示范）、家庭私有课程录音（用户提供，按原文件来源登记）、逐目标标准音（保留既有教学与发布审核）。中文引导和私人课录音均不假填标准音审核字段。
3. 当前 Mac 可用系统中文音色本地生成个人使用的指令文件，文件保存在 private/，不随 MIT 代码公开；不在浏览器调用 speechSynthesis，不远程合成、不自动下载声音。生成失败报告缺口。公共音频发行另选持权录音/允许再分发的声音。
4. content/narration.json 集中维护原创语音脚本和视觉目标；它不是动态生成答案。服务端只按白名单 ID 提供私有音频，检查目录边界、摘要和 MIME。浏览器全局单播放器负责停止、重播和顺序播放。
5. 真实验收必须连接真实服务与数据库，下载并解码实际人声文件，点击听题/听选项不得生成作答；网络/媒体失败不得计为孩子错误。模拟用例保留为故障边界测试。

此决定覆盖旧 SPEC 中禁止任何私有素材服务的过度限制，以及仅文字视觉题可视为首版完整学习流程的假设。不改变公共发行的许可/教师审校门禁，不把课程长录音或合成指令宣称成标准拼音单音。
