# ADR 0016：共享语音引导偏好

2026-10-13采纳。依据SPEC-008 DAILY-05及用户反馈：家长关闭自动朗读必须影响天天练，学习页面须有就近快捷开关。

应用层统一计算有效引导偏好并传入天天练，替代天天练的独立状态。家庭soundEnabled提供默认值；设备快捷选择以enabled和选择时的familyDefault保存到浏览器，只在家庭默认未变时生效。家庭设置变化覆盖基于旧值的设备选择；家长页直接操作同步当前设备偏好。快捷开关不提升孩子设备的服务端家长权限，不写家庭设置或成绩。旧天天练显式off迁移保留，旧on不覆盖家庭关闭。

原课程自动说明、天天练说明和识别反馈读取同一偏好，手动听题/标准音/词句示范保留。关闭正在播放的说明及时停止，录音识别不被取消。入口HTML不缓存，静态摘要资源继续缓存。无新增依赖。
