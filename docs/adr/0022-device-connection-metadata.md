# ADR-0022：家庭设备型号、已用配对码与连接时间

日期：2026-10-16。状态：采纳。依据：SPEC-007 DEVICE-01。

设备身份仍是现有HttpOnly会话Cookie，不用设备型号或配对码作为后续请求身份。SQLite迁移7为devices添加model、pairing_code和last_connected_at。成功配对保存已消耗的码，供家长辨认及复制，界面明确其不能重用；旧码因仅保存哈希不能恢复，保留空值。生成新邀请仍五分钟一次有效，不暴露登录令牌。

浏览器提供可编辑的类型提示，不执行硬件指纹或高熵设备探测；具体型号由家长填写，自动建议标明推测。[MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/User-agent_reduction)说明浏览器可能移除设备型号，不能据UA承诺精确硬件识别。家庭认证边界更新服务器记录的最后连接时间，只接受有有效会话的实际请求，不把页面打开状态、配对时间或客户端时钟冒充连接时间。访客计算仍不写家庭设备表。

列表及编辑沿用家长权限和CSRF；设备型号可用于识别列表，不参与鉴权。无新依赖，不向第三方发送设备信息；元数据只保留家庭Mac，现有SQLite运维备份包含它，便携学习JSON继续排除设备和凭据。旧程序不支持迁移7时应拒绝数据库；回滚需同时恢复升级前备份。
