# ADR-0026：按职责组织界面与API模块

日期：2026-10-17。状态：采纳。范围：SPEC-015。

大型App与API文件同时承担多个独立功能，使修改容易牵连其他流程。沿用React状态编排、FastAPI依赖注入和SQLite事务，按已有功能边界拆分，不更换技术栈。

前端由App编排学习状态，页面模块消费显式属性；共享学习API数据类型集中在domain层，界面属性类型留在app层，HTTP与待确认答题存储放在platform层。页面不反向导入App，不在组件复制领域算法或内容数据。样式入口按原顺序导入职责明确的文件，避免移动规则改变级联。

服务端api仅组装路由，routes包含配对设备、课程资源、家庭资料与学习会话；api_dependencies提供同一组认证依赖，learning_state共享选题/进度查询辅助，profile_backup提供备份校验、迁移和事务内恢复。底层模块不导入路由；访客显式调用同样的业务函数，在既有ContextVar内存数据库内执行。保留原始HTTP路径、错误码、校验、锁与事务边界。

测试对所属模块注入故障或时钟，避免通过旧聚合模块隐式替换全局变量。工程与真实服务浏览器回归验证等价行为；不代表家庭设备验收。
