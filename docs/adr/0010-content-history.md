# ADR 0010：按历史内容版本恢复和判分

日期：2026-10-05。状态：采纳。

课程连续升级时，旧会话仍在数据库中；现有备份要求其版本等于当前课程，且恢复与判分使用当前题目，破坏了冻结题单的语义。家庭与访客均受影响。

将已发布到本机的题目版本作为MIT内容快照保存在content/history，由明确版本清单、来源Git提交和SHA-256登记。运行时只读取本地已登记文件，不查Git、不联网、不从用户输入拼路径。快照不含儿童资料、声音或数据库。

保留备份schema v5，以会话/实例已有版本字段选择历史题目；只有header/profile更新为当前版本。家庭恢复保留预览与确认，访客继续使用请求内存库。未知版本不猜测迁移；缺失或损坏快照不得回退当前题目。每次内容版本升级前须保存旧版快照，使用npm run snapshot:content保存已提交的当前版后，才能编辑并提升内容版本；测试核验全部快照摘要，并在已有当前快照时验证其内容一致性。

历史提示揭晓、未完成题判分和恢复的结果使用原答案；现有中文语音ID保留，若未来更改题干/讲解语义，须同步设计版本化语音资源，不能重用ID覆盖。当前兼容范围只涵盖登记版本及其稳定的知识/课程ID。
