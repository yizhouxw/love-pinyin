# ADR 0014：每日跟读的浏览器录音边界

日期：2026-10-13。状态：由[ADR-0015](0015-asr-reading-match.md)更新上传与识别边界：用户要求以语音识别匹配判定，允许仅发送家庭Mac内存识别，依然不存录音。依据：用户明确提出PDF每日跟读与读音判定需求，见SPEC-008。

只在新增每日跟读页面引入浏览器录音适配器，覆盖ADR-0004/0005中本功能禁止麦克风的范围。录音仅留当前页面内存，不上传Mac、不持久化、不写日志；停止、换条、后台、退出立即释放设备，清除录音。Permissions-Policy允许同源麦克风，摄像头和定位继续禁用。用户点击录音才申请权限。

示范仍直接信任固定cmguo/PinYinSound，复用全局播放器。完整源归档的每日目标以独立白名单登记，不改变已有课程音频签名或冻结题单；中文引导复用Mac本地预生成音频。内容和规范集中于content，React只实现交互。

当前没有可靠评分器，不向产品接入已有Whisper或合成模板实验，不把录音完成判成发音正确。自动判音待本地专用模型、许可、儿童真实样本和拒判策略验证后另补决策。家长标记与客观题成绩隔离，不改变知识掌握算法。

无新增npm/uv运行依赖。PDF由外部工具只读提取，内容人工逐页核对；原PDF仍为用户未跟踪文件，不加入公开许可包。
