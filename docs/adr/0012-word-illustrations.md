# ADR 0012：版本化生活图片与拼音语境

日期：2026-10-05。状态：采纳。

content/illustrations.json保存版本化图片ID、中文描述、规范拼音、课程和现有标准音引用；public/illustrations中的SVG为项目原创MIT资产，不使用教材扫描图或平台emoji充当学习图片。渲染器仅接受目录内ID和固定同源路径，不接受题目提供任意URL/HTML。校验禁止SVG脚本、外链、事件属性或内嵌图片。

题目与选项增加可选pictureId，沿用listen-choice和blend-choice的可听、试选确认及服务端幂等判题。选项label仍保存规范拼音用于目标音一致性，图片选项只显示图像并提供中文辅助描述；对应语音仅朗读中文图片说明，不朗读label拼音。资源说明声音仍由Mac本地生成，标准音仍由PinYinSound适配器提供。图片学习卡共用全局播放器，浏览器退出/后台停止，不写成绩。

图片ID发布后不可覆盖图义，未来语义修改须新增ID并保留旧文件和说明；冻结题目保留引用，改版前保存旧题库。既有无图片的题目、旧备份和掌握算法不变。不增加新的儿童能力分数，不将图义选择当作发音评测。

图片加载状态按题目实例与重试次数隔离，旧图片事件不能放行新题。所需图片未全部加载时禁用选择和拼读确认，保留重试、中文故障说明与跳过；课程图片卡同样提供重试。不把图片或声音加载失败作为儿童答案，也不因听图片说明产生作答。
