# ADR 0011：内容驱动的书写观察

日期：2026-10-05。状态：采纳。

26个基础字母、笔顺、占格与14课63个明确组合保存在content/writing.json。课程API返回目录；React只渲染SVG路径和逐笔选择，不硬编码字母规则、不在浏览器推导合法音节。轨迹和中文说明原创，教材只作字形/笔顺依据；不使用教材扫描图或平台字体作为书写示范。

每个字形ID以v1前缀固定，图形题选项引用该ID及明确的垂直偏移；历史题会保留这些字段。未来更改轨迹语义必须增加新版本字形ID并保留旧条目及对应语音，不能覆盖旧题引用。文字选项继续按原逻辑，图形选项以字形与偏移一起校验唯一性。服务端答案仍为原选项ID；不会根据客户端图形自行算分。

书写步骤的中文语音由既有Mac本地生成器登记、合成与提供，不增加浏览器TTS或网络服务。共用全局播放器；课程录音、标准音与书写引导互斥。纸笔活动不产生掌握事件，不伪造书写检测。本切片无描红路径采样或轨迹评分，保留鼠标、触摸与键盘按钮等价操作。

WRITE-02扩展：声调符号作为独立版本化笔画保存在同一目录。每个带调目标显式保存markId、glyphIndex、offsetY及omitStrokeIndices；客户端仅按目录省略指定点画并在全部字母后追加声调，不推导标调规则。标调中文说明与目标绑定，避免复用含点的无调i占格说明。基础字形及旧图形题引用不变；所有新目标仍只用于观察和纸笔练习。
