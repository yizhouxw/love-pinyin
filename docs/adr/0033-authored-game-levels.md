# ADR-0033：关卡数据、运动引擎与教学绑定解耦

2026-10-25，采纳；SPEC-017 KEY-01、LEVEL-01～04。用户实测指出键盘焦点失效、单题场景不能作为完整关卡。

三层数据：content/game-levels.json保存24关、主题、章节、路线模式及障碍/补给/节拍；content/curriculum.json保留全部教学题和答案；服务器按已学范围把题实例绑定到12个任务槽。运动引擎仅接收模式、选项数量、时间和输入，发出碰撞结果，不导入课程/关卡JSON。React负责输入生命周期、真实声音、绘制和提交；键盘控制由独立适配器接管活动游戏，保留表单和普通按钮的键盘语义。

游戏一次会话是一整关，3章节12段，正确反馈后自动接续下一段。运动收集与练习记录隔离；网络未确认的选择锁定并幂等重放，错误修正不覆盖首次成绩。课堂练习仍最多6题。

SQLite迁移10增加sessions.game_run_json，冻结版本化关卡、引用的模式/主题与题实例绑定。备份schema5可选gameRun，旧会话为空对象并明确显示兼容旅程；恢复时验证路线结构及绑定恰好等于冻结题单顺序。数据校验器同时用于发布和后端加载/备份，所有布局坐标有界。不增加依赖或远程素材。

有限24关自由选择，学校当前课决定教学范围，推荐难度决定物理辅助；关卡号不意味着课程解锁。每次/每日上限仍由ADR-0031的家庭时钟控制，不保存儿童运动轨迹。刷新只重走当前尚未完成的一段，已完成检查点不重记。
