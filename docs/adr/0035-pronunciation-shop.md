# ADR-0035：小卖部使用拼读端口与独立临时购物篮

2026-10-26，采纳，SPEC-019 SHOP-01～03。

小卖部作为游戏乐园内独立场景，沿用 useGameClock 家庭授权，使用 MATCH-10 的 PronunciationService。它是口头练习，不构造客观题作答或伪造选择结果，不写原掌握度。篮子、录音与请求均只在内存；不增加数据库字段或依赖。

商品引用集中图卡目标与已有标准音，不在组件重新编写教材答案。首两课单韵母包装为拼音礼盒，不把联想图片名称冒充拼音读音。中文说明由现有固定本地 Qwen3-TTS 生成随包音频，保持独立许可。

默认端口 unavailable，真实服务通过组装处替换。只有关联有效的 acoustic matched 结果触发正式入篮；mock 仅允许 Vite 开发模式下通过显式查询参数启用，并在入口、场景、反馈及清单标记模拟。测试可注入受控端口覆盖分支，不将测试声音或 mock 作为模型有效性证据。识别超时取消，切商品、后台、额度暂停及退出失效所有旧请求；无自动成功降级。

## 2026-10-26 SHOP-04～06 修订

商品目录与练习目标拆开。content/pinyin-shop.json维护8×12商品、整数分价格、图集定位和时序参数；targetIds只引用独立教学目录，按当前已学课过滤。商品图像使用本地生成图集及明确来源记录，商品选择不改变教材能力或价格逻辑。

MATCH-10保持WAV Blob端口，不新增伪流式HTTP契约。专门的浏览器PCM采音适配器在本地持续收集单声道音频；串行发送越来越长的16kHz PCM16 WAV快照，最短采样和轮询周期由内容配置。五秒从麦克风就绪起算，包含推理等待；截止立刻取消，uncertain可以继续，明确retry结束本次、matched立即入篮。浏览器采音、匹配会话控制与React绘制分离，原天天练录音适配器保持原行为。

全局引导继承家庭默认及设备偏好，开关位置固定在店铺顶部；采音前停所有声音，成功/失败后才可自动反馈。mock仅显式开发模式，正式未配置时仍显示拼音与不可用提示，不请求无用麦克风、不自动成功。无新增依赖、数据库迁移或录音落盘。

## 2026-10-27 SHOP-07/08 用户修订

商品图集替换为无品牌写实商品摄影风格。用户明确要求Mock时也能完成购物，并接受清晰提示当前不是真实识别，因此小卖部的内容配置显式选择模拟体验，在生产构建中也可玩；界面和清单持续标明模拟。此配置是明确的游戏开发模拟模式，不代表真实声学判断，不向家庭成绩写入模拟数据。模拟按端口的固定成功契约运作，不依赖麦克风或合成声音；未来切换到真实服务需主动修改配置并完成模型验收，不根据失败自动降级为mock。保持取消、五秒、时长、篮子与价格规则。
