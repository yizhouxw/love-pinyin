# ADR-0040：iOS 发行内容边界

iOS 使用现有随包桥接服务。新版整课讲解使用独立稿件及音频清单，替换 iOS 内同一课堂播放 ID 的文件，家庭 Web 的历史录音入口按原契约运行。

公开构建与家庭构建从同一界面及规则编译，按明确的构建配置选择可随包分发的内容。家庭练习切换只在已安装对应资料的构建中提供，进度以资料标识隔离。公开构建须验证整个包，不能把隐藏入口视为移除资源。验收见 SPEC-024。

DIST-05 将投影与音频目录移到共享服务模块，由 HTTP 和 iOS 打包共同调用。素材包提供统一的练习数据、课程音频 ID 和标准音命名空间。课堂、游戏及播放缓存沿用原教学 ID，统一由音频 URL 适配器选择命名空间。服务端家长接口保存 B/S 家庭偏好，独立 iOS 通过本机偏好保存。切换重新加载页面，清理旧播放与缓存。

DIST-06、DAILY-13 和 WORD-10 共用拼读计划和客户端音频队列。声韵组件沿用当前素材包的标准音命名空间；完整带调音节优先用当前练习自带的录音，再从独立许可的普通话音节清单取用，完整词语朗读继续引用原练习音轨。HTTP 与 iOS 均从同一清单注册新增音节。

DIST-08 用同一固定修订的大陆普通话录音替换新版包的注音示范，资源清单继续按原教学 ID 注册。声母采用保留辅音和短元音的呼读示范，独立韵母按实际发音配对；裁切派生保留原录音许可和逐项溯源。家庭旧版独立保留。

DIST-09 将课序、单元和词表改为同一教材词语目录投影。新版在投影时以按稳定课 ID 登记的自编拓展短文替换旧版正文。公开构建仅从词表投影收录课名、生字和词目的合成语音，校验时拒绝旧版正文的音频摘要，包括转码前的摘要。
