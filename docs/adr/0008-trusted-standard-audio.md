# ADR 0008：直接信任 PinYinSound 标准音

日期：2026-10-05。状态：采纳。依据：用户明确要求去掉教学审校标准音机制，信任cmguo/PinYinSound，产品用户只有学生和家长。

1. cmguo/PinYinSound是本应用唯一标准音来源，替代ADR-0006的两人审音启用流程和ADR-0007的多来源优先级。固定版本、目标映射及文件摘要仍由content/pinyin-source.json维护。
2. 删除审音台、审核者、审核确认、待审状态、审核启用门槛及公共/私有已审音频回退。学生听标准音与做练习；家长选课、管理进度、设置声音和备份，无第三种用户角色。
3. 标准音是否可用只取决于已安装且启用、目标映射一致、文件存在及摘要正确。安装仍解码检查，运行时仍认证配对、限制路径、支持Range。缺失或损坏显示重试，不判孩子错误。
4. 去掉产品、API、当前内容格式及软件发布检查里的教师审核状态和草稿审核提示。旧家庭备份和冻结题单可继续读取，旧审核字段被忽略，不改孩子的答案、进度或会话版本。内容质量通过开发者的数据校验、参考资料核对与产品测试维护，不建立审核工作流。
5. 称为“标准音”，课程和家长页面只显示来源、可播放数量及实际声音故障。原长课程录音与中文指令保留各自用途，不能替代标准音。
6. 代码MIT不自动变更外部录音的许可；来源/许可事实留在维护者文档，不作为家庭安装和使用的交互门槛。不开源上传MP3，不新增依赖，不安装证书、不动家庭数据。
