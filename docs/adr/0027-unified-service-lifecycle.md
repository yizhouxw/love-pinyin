# ADR-0027：统一管理本机与家庭HTTPS入口

2026-10-17，采纳，依据SPEC-010 SETUP-05。此前run.sh只启动127.0.0.1:8000，手动启动的LAN进程停止后，lovepinyin仍会把HTTP正常视为完整可用，导致iPad连接失败。

保留两个独立Uvicorn进程和原有认证边界，统一由run.sh管理。HTTP仅监听127.0.0.1，HTTPS仅监听显式配置且通过TLS预检的本机IPv4；两进程共享同一数据和资源配置。私有server.env只解析白名单键的字面值，环境变量覆盖文件。不硬编码家庭IP或证书路径进源码，也不安装证书或LaunchAgent。

Bash配置和生命周期辅助脚本承担无依赖的status/stop与进程归属核验；启动复用现有Node TLS验证器和锁定Python环境。监督器只负责本次创建的进程，收到中断或任一子进程退出即清理同次创建的其他进程。已运行入口可复用，缺失入口补齐；restart在停止前校验配置，冲突检查在发送任何停止信号前完成。

lovepinyin的受版本管理包装器只协调后台运行、就绪等待、日志和浏览器打开，不再单独判断8000监听即成功。使用项目固定Python创建独立进程会话，避免终端或调用方清理进程组时终止后台服务；全新安装缺少该Python时先执行prepare-only。用户现有shell别名委托该包装器。无新增依赖；原独立serve:lan与LaunchAgent入口保留，家庭常用命令采用统一入口。
